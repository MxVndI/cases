# Глоссарий

## Роли

| Роль | Техническое значение | Описание |
|------|---------------------|----------|
| **Гость** | Пользователь без активной сессии | Может просматривать кейсы, главную страницу и публичные профили. Не может открывать кейсы, управлять инвентарём или заходить в защищённые разделы. |
| **Пользователь** | Авторизованный пользователь с `role = "user"` | Полный доступ ко всем функциям, кроме панели администрирования. |
| **Администратор** | Авторизованный пользователь с `role = "admin"` | Все права пользователя плюс доступ к панели управления (блокировка пользователей, CRUD кейсов). |

## Сущности

### Пользователь (User)

Основная сущность системы. Содержит информацию об аккаунте.

| Поле | Описание |
|------|----------|
| **id** | Уникальный идентификатор |
| **email** | Электронная почта (используется для входа) |
| **nickname** | Отображаемое имя |
| **status** | Статус аккаунта: `active` или `blocked` |
| **role** | Роль: `user` или `admin` |
| **balance** | Баланс в CaseHubCoin |
| **registeredAt** | Дата регистрации |

### Кейс (Case)

Виртуальный контейнер с набором предметов. Пользователь «открывает» кейс, получая случайный предмет.

| Поле | Описание |
|------|----------|
| **id** | Уникальный идентификатор |
| **name** | Название кейса |
| **description** | Краткое описание |
| **image** | Изображение-превью |
| **price** | Стоимость открытия в CaseHubCoin |
| **category** | Категория: Оружие, Ножи, Перчатки, Агенты, Наклейки |
| **items** | Список предметов, которые могут выпасть |

### Предмет (CaseItem)

Виртуальный предмет CS2, который может быть получен из кейса.

| Поле | Описание |
|------|----------|
| **id** | Уникальный идентификатор |
| **name** | Полное название (формат: «Оружие \| Скин») |
| **rarity** | Редкость: `common`, `rare`, `epic`, `legendary`, `exotic` |
| **price** | Стоимость в CaseHubCoin |

### Редкость предметов

| Значение | Название (RU) | Цветовая маркировка |
|----------|---------------|---------------------|
| `common` | Обычное | Серый |
| `rare` | Редкое | Синий |
| `epic` | Эпическое | Фиолетовый |
| `legendary` | Легендарное | Оранжевый |
| `exotic` | Экзотическое | Красный |

## Валюта

**CaseHubCoin** — внутренняя виртуальная валюта платформы. Используется для открытия кейсов. Может быть заработана через ферму (кликер) или получена при продаже предметов из инвентаря. Отображается с иконкой монеты.

## Термины

| Термин | Описание |
|--------|----------|
| **Открытие кейса** | Процесс «покупки» случайного предмета из кейса. Со счёта списывается стоимость кейса, запускается анимация рулетки, по окончании пользователь получает предмет. |
| **Рулетка (рил)** | Анимированная полоса с предметами, которая прокручивается при открытии кейса и останавливается на выигрышном предмете. |
| **Мульти-открытие** | Возможность открыть кейс сразу несколько раз (x3 или x5) за одно действие. |
| **Инвентарь** | Коллекция предметов, полученных пользователем при открытии кейсов. Предметы можно продать за CaseHubCoin. |
| **Ферма** | Мини-игра в жанре кликера. Позволяет зарабатывать CaseHubCoin нажатием на кнопку и покупкой улучшений. |
| **Защищённый маршрут** | Маршрут, доступный только авторизованным пользователям. При попытке доступа гостем происходит перенаправление на страницу входа. |
| **OAuth** | Авторизация через внешние сервисы (Discord, Яндекс) без ввода пароля на CaseHub. |
