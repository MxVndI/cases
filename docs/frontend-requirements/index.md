# CaseHub — Требования к фронтенду

## О проекте

CaseHub — веб-платформа для открытия виртуальных кейсов с предметами CS2. Пользователи могут просматривать кейсы, регистрироваться, открывать кейсы, управлять инвентарём, зарабатывать внутреннюю валюту через мини-игру (ферму) и настраивать профиль. Администраторы управляют контентом и пользователями.

## Роли

| Роль | Описание |
|------|----------|
| **Гость** | Неавторизованный посетитель. Может просматривать контент, но не может открывать кейсы и управлять профилем. |
| **Пользователь** | Авторизованный пользователь. Полный доступ к открытию кейсов, инвентарю, балансу, ферме и профилю. |
| **Администратор** | Пользователь с ролью `admin`. Дополнительно имеет доступ к панели управления (пользователи, кейсы). |

## Технологический стек

- **Фреймворк:** React + TypeScript
- **Маршрутизация:** TanStack Router (файловая маршрутизация)
- **Состояние сервера:** TanStack Query
- **Стили:** Tailwind CSS v4
- **Анимации:** Framer Motion
- **UI-компоненты:** shadcn/ui
- **Иконки:** Lucide React

## Карта маршрутов

| Маршрут | Страница | Доступ |
|---------|----------|--------|
| `/` | Главная (витрина кейсов) | Все |
| `/cases` | Каталог кейсов | Все |
| `/cases/$caseId` | Детали кейса | Все |
| `/cases/$caseId/open` | Альтернативное открытие кейса | Все |
| `/login` | Авторизация | Только гости |
| `/register` | Регистрация | Только гости |
| `/user/$userId` | Профиль другого игрока | Все |
| `/balance` | Баланс и статистика | Пользователь |
| `/farm` | Ферма (кликер) | Пользователь |
| `/profile` | Личный кабинет | Пользователь |
| `/admin` | Панель администратора | Администратор |
