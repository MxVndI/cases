# CaseHub — Требования к фронтенду

## О проекте

CaseHub — веб-платформа для открытия виртуальных кейсов с предметами CS2. Пользователи могут просматривать кейсы, авторизоваться через OAuth или email-код, открывать кейсы с анимацией рулетки, управлять инвентарём, зарабатывать внутреннюю валюту CHC через мини-игру (ферму) и кликер, получать ежедневный бонус, настраивать профиль. Администраторы управляют контентом (кейсы, предметы, справочники) и пользователями через панель администрирования.

## Роли

| Роль | Описание |
|------|----------|
| **Гость** | Неавторизованный посетитель. Может просматривать кейсы и публичные профили, но не может открывать кейсы, управлять инвентарём и профилем. |
| **Пользователь** | Авторизованный пользователь. Полный доступ к открытию кейсов, инвентарю, балансу, ферме, кликеру, ежедневному бонусу и профилю. |
| **Администратор** | Пользователь с ролью `admin`. Дополнительно имеет доступ к панели управления (пользователи, кейсы, предметы, редкости, оружие, теги). На публичных профилях видит расширенную информацию (баланс, транзакции, кнопку блокировки). |

## Технологический стек

- **Фреймворк:** React 18 + TypeScript
- **Сборка:** Vite
- **Маршрутизация:** TanStack Router (файловая маршрутизация с кодогенерацией)
- **Состояние сервера:** TanStack Query (React Query)
- **HTTP-клиент:** Axios (cookie credentials, глобальный перехватчик ошибок)
- **Стили:** Tailwind CSS v4
- **Анимации:** Framer Motion, GSAP (кастомный курсор)
- **UI-компоненты:** shadcn/ui (button, dialog, input, input-otp, checkbox, dropdown-menu, label)
- **Иконки:** Lucide React
- **Уведомления:** Sonner (тосты, тёмная тема, bottom-right)

## Карта маршрутов

| Маршрут | Страница | Доступ | Защита |
|---------|----------|--------|--------|
| `/` | Главная (витрина кейсов, фильтры, SSE-лента выигрышей) | Все | — |
| `/cases/$caseId` | Детали кейса + открытие (рулетка) | Все (открытие — пользователь) | — |
| `/login` | Авторизация (email-код + OAuth) | Только гости | Redirect → `/` для авторизованных |
| `/register` | Регистрация (email-код + никнейм) | Только гости | Redirect → `/` для авторизованных |
| `/user/$userName` | Публичный профиль игрока | Все | — |
| `/balance` | Баланс, статистика, ежедневный бонус | Пользователь | Inline `beforeLoad` |
| `/farm` | Ферма (кликер + улучшения) | Пользователь | Inline `beforeLoad` |
| `/profile` | Личный кабинет (4 вкладки) | Пользователь | `_protected` layout |
| `/admin` | Панель администратора (5 вкладок) | Администратор | `_protected` layout + role check |

> **Удалённые маршруты:** `/cases` (каталог интегрирован в `/`), `/cases/$caseId/open` (открытие на странице деталей).
