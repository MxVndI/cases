# US-4.1: Просмотр баланса и статистики

**Эпик:** [Epic 4: Инвентарь и баланс](../epics/epic-04-inventory-balance.md)  
**Роль:** Пользователь  
**Маршрут:** `/balance`

## User Story

**Как** пользователь, **я хочу** видеть свой текущий баланс и финансовую статистику, **чтобы** понимать своё финансовое положение на платформе.

## Описание

Страница баланса (`/balance`) — `BalancePage` — отображает текущий баланс пользователя в CHC (CaseHubCoin) и связанную статистику.

### API

- **Баланс:** `paymentApi.getBalance` — возвращает текущий баланс в CHC.
- **Транзакции:** `paymentApi.getTransactions` — возвращает историю операций.

### Блок статистики

4 плитки (stat tiles):

- **Потрачено** (Spent) — суммарная стоимость всех открытых кейсов.
- **Получено** (Received) — суммарная стоимость всех полученных предметов.
- **Прибыль** (Profit) — разница между полученным и потраченным.
- **Заработано на ферме** (Farm Earned) — сумма, полученная через ферму.

### Ежедневный бонус

Кнопка **«Получить ежедневный бонус»** начисляет **100 CHC** при нажатии. Кулдаун — **24 часа**. API: `paymentApi.claimDailyBonus`. Пока бонус недоступен, кнопка отображается как неактивная с таймером обратного отсчёта.

### История транзакций

Список **последних 10 транзакций** с иконками типов операций (открытие кейса, начисление с фермы, ежедневный бонус, продажа и т.д.). Каждая запись содержит тип, сумму и дату.
