# US-4.1: Просмотр баланса и статистики

**Эпик:** [Epic 4: Инвентарь и баланс](../epics/epic-04-inventory-balance.md)  
**Роль:** Пользователь  
**Маршрут:** `/balance`

## User Story

**Как** пользователь, **я хочу** видеть свой текущий баланс и финансовую статистику, **чтобы** понимать своё финансовое положение на платформе.

## Описание

Страница баланса (`/balance`) отображает текущий баланс пользователя в CaseHubCoin и блок статистики с четырьмя показателями:

- **Потрачено** — суммарная стоимость всех открытых кейсов.
- **Выиграно** — суммарная стоимость всех полученных предметов.
- **Заработано** — сумма, полученная через ферму.
- **Прибыль** — разница между заработком (выигрыш + ферма) и расходами.

Под статистикой расположен блок «Действия» со ссылками на ферму и на страницу получения бонуса.

Также на странице есть секция «Последние операции» — краткая история последних транзакций (открытие кейсов, продажи, начисления с фермы).
