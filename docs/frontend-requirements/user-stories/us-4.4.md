# US-4.4: Продажа предмета из инвентаря

**Эпик:** [Epic 4: Инвентарь и баланс](../epics/epic-04-inventory-balance.md)  
**Роль:** Пользователь  
**Маршрут:** `/profile` (вкладка «Инвентарь»)

## User Story

**Как** пользователь, **я хочу** продать предмет из инвентаря, **чтобы** получить CaseHubCoin на баланс.

## Описание

Каждая карточка предмета в инвентаре содержит кнопку «Продать». Продажа происходит в два шага для предотвращения случайных продаж:

1. **Первый клик** — пользователь нажимает кнопку «Продать». Вместо неё появляются две кнопки: подтверждение продажи с указанием суммы («Да, продать за N») и отмена.
2. **Второй клик** — пользователь подтверждает продажу. Вызывается `inventoryApi.sellItem(entryId)`, предмет удаляется из инвентаря с анимацией исчезновения, а его стоимость в CHC зачисляется на баланс.

Если пользователь нажимает отмену или кликает на другой предмет, подтверждение сбрасывается.

Дополнительно в инвентаре доступна кнопка «Продать всё» для массовой продажи всех предметов одним действием. При нажатии открывается диалог подтверждения, после чего вызывается `inventoryApi.sellAll()`.
