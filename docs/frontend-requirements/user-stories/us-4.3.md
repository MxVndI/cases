# US-4.3: Фильтрация и сортировка инвентаря

**Эпик:** [Epic 4: Инвентарь и баланс](../epics/epic-04-inventory-balance.md)  
**Роль:** Пользователь  
**Маршрут:** `/profile` (вкладка «Инвентарь»)

## User Story

**Как** пользователь, **я хочу** фильтровать и сортировать предметы в инвентаре, **чтобы** быстро находить нужные.

## Описание

В инвентаре доступна панель фильтров, которая раскрывается по нажатию кнопки «Фильтры».

Доступные опции сортировки:
- По умолчанию (порядок получения)
- По цене (возрастание/убывание)
- По дате (возрастание/убывание)

Доступные фильтры:
- **Редкость** — мультивыбор по уровням редкости. Можно выбрать несколько уровней одновременно.
- **Диапазон цен** — поля ввода минимальной и максимальной цены в CHC

Кнопка «Фильтры» показывает бейдж с количеством активных фильтров. При наличии активных фильтров появляется кнопка «Сбросить фильтры».

Если после применения фильтров предметы не найдены, отображается сообщение «Нет предметов по выбранным фильтрам».
