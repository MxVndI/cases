# US-6.3: Автоматический заработок

**Эпик:** [Epic 6: Ферма (кликер)](../epics/epic-06-farm.md)  
**Роль:** Пользователь  
**Маршрут:** `/farm`

## User Story

**Как** пользователь, **я хочу** зарабатывать монеты автоматически после покупки автокликера, **чтобы** получать доход, даже когда я не кликаю.

## Описание

После покупки улучшения «Автокликер» система автоматически начисляет монеты с заданным интервалом (по умолчанию — каждую секунду). Количество монет за тик зависит от уровня автокликера и множителя. Интервал тика зависит от уровня «Скорость».

Показатель «доход/сек» в верхней части страницы обновляется при покупке любого улучшения, чтобы пользователь видел актуальный пассивный доход.
