# US-6.3: Автоматический заработок

**Эпик:** [Epic 6: Ферма (кликер)](../epics/epic-06-farm.md)  
**Роль:** Пользователь  
**Маршрут:** `/farm`

## User Story

**Как** пользователь, **я хочу** зарабатывать монеты автоматически после покупки автокликера, **чтобы** получать доход, даже когда я не кликаю.

## Описание

После покупки улучшения «Автокликер» система автоматически начисляет монеты с заданным интервалом. Количество монет за тик зависит от уровня автокликера (`auto_clicker_level`). Интервал тика зависит от уровня «Скорость» (`speed_level`).

### Серверная синхронизация

Автокликер синхронизируется с сервером через `farmApi.syncFarm`, которая передаёт текущие `auto_clicker_level` и `speed_level`. Сервер рассчитывает накопленный пассивный доход.

### Pending-баланс и Claim

Накопленные автокликером монеты хранятся в **pending-балансе** (максимум **1000 CHC**). Когда pending-баланс достигает лимита или пользователь хочет забрать монеты, он нажимает кнопку **«Забрать»** (Claim). Кнопка вызывает `farmApi.claimFarm`, который переводит pending-монеты на реальный баланс пользователя через Payment Service.

Показатель «доход/сек» в верхней части страницы обновляется при покупке любого улучшения, чтобы пользователь видел актуальный пассивный доход.
