# US-2.1: Регистрация нового пользователя

**Эпик:** [Epic 2: Регистрация и авторизация](../epics/epic-02-auth.md)  
**Роль:** Гость  
**Маршрут:** `/register`

## User Story

**Как** гость, **я хочу** зарегистрироваться на платформе, **чтобы** создать личный профиль и получить возможность открывать кейсы.

## Описание

Страница регистрации (`/register`) содержит форму с тремя полями: никнейм, электронная почта и пароль (с подтверждением). Все поля обязательны для заполнения. Визуально страница оформлена в белых тонах (в отличие от оранжевой страницы входа).

Под формой расположены ссылки для навигации: «На главную» (ведёт на `/`) и «Уже есть аккаунт? Войти» (ведёт на `/login`).

Если пользователь уже авторизован и попадает на страницу регистрации, он автоматически перенаправляется на главную.
