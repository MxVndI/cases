# US-2.1: Регистрация нового пользователя

**Эпик:** [Epic 2: Регистрация и авторизация](../epics/epic-02-auth.md)  
**Роль:** Гость  
**Маршрут:** `/register`

## User Story

**Как** гость, **я хочу** зарегистрироваться на платформе, **чтобы** создать личный профиль и получить возможность открывать кейсы.

## Описание

Страница регистрации (`/register`) реализует двухшаговый поток на основе email OTP (без паролей).

### Шаг 1 — Ввод email

Пользователь вводит адрес электронной почты и нажимает кнопку **«Получить код»**. Фронтенд отправляет `POST /api/auth/email/login/start` с `{ email }`. Сервер отправляет 6-значный код на указанный email. Форма переходит к шагу 2.

### Шаг 2 — Никнейм и OTP-код

Пользователь вводит желаемый никнейм и 6-значный OTP-код. Для ввода кода используется компонент `input-otp` (6 отдельных полей). После заполнения всех полей фронтенд отправляет `POST /api/auth/email/login/finish` с `{ code }`. При успехе сервер устанавливает cookie `sid`, и пользователь перенаправляется на `/`.

Под формой расположена ссылка **«Уже есть аккаунт? Войти»** (ведёт на `/login`).

Если пользователь уже авторизован и попадает на страницу регистрации, он автоматически перенаправляется на главную.

> **OAuth:** Помимо email-кода, на странице доступны кнопки OAuth-входа через Discord и Яндекс (реализовано через fastapi-sso на бэкенде).
