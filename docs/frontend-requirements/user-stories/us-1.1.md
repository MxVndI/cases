## User Story

**Как** гость, **я хочу** видеть витрину доступных кейсов на главной странице, **чтобы** понять ассортимент и механику платформы до регистрации.

## Описание

Главная страница — это точка входа в платформу. Она содержит конвейер последних выигрышей (бегущую строку), систему фильтров и сетку карточек кейсов.

Конвейер в верхней части страницы автоматически прокручивает карточки с последними выигрышами всех пользователей. Каждая карточка показывает никнейм игрока, название выигранного предмета и его стоимость. Это создаёт ощущение живой активности на платформе.

Под конвейером располагается панель фильтров, позволяющая сузить отображаемый набор кейсов. Доступны следующие фильтры:

- **Диапазон цен** — ползунок (range slider) с минимальной и максимальной ценой
- **Сортировка** — по цене (возрастание/убывание), по популярности, по новизне
- **Категория** — Оружие, Ножи, Перчатки, Агенты, Наклейки
- **Редкость** — фильтр по уровням редкости предметов в кейсе

Основная часть страницы — сетка карточек кейсов. Каждая карточка содержит изображение, название, краткое описание, цену и кнопку для перехода к детальному просмотру. При наведении карточка слегка приподнимается с анимацией.
