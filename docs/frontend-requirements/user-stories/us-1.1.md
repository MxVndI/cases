# US-1.1: Просмотр главной страницы

**Эпик:** [Epic 1: Просмотр контента](../epics/epic-01-browsing.md)  
**Роль:** Гость, Пользователь, Администратор  
**Маршрут:** `/`

## User Story

**Как** гость, **я хочу** видеть витрину доступных кейсов на главной странице, **чтобы** понять ассортимент и механику платформы до регистрации.

## Описание

Главная страница — это точка входа в платформу. Она содержит ленту последних выигрышей в реальном времени (SSE), систему фильтров и сетку карточек кейсов.

В верхней части страницы расположена лента последних выигрышей, которая обновляется в реальном времени через SSE (Server-Sent Events). Подключение устанавливается через `EventSource` к эндпоинту потока выигрышей. Каждая карточка показывает никнейм игрока, название выигранного предмета и его стоимость в CHC. Новые выигрыши появляются автоматически без перезагрузки страницы.

Под лентой располагается панель фильтров, позволяющая сузить отображаемый набор кейсов. Доступны следующие фильтры:

- **Теги** — набор кнопок-тегов для фильтрации по тематике кейса (мультивыбор)
- **Редкость** — фильтр по уровням редкости предметов в кейсе (мультивыбор)
- **Диапазон цен** — поля ввода минимальной и максимальной цены в CHC
- **Сортировка** — по умолчанию, по цене (возрастание/убывание), по количеству предметов, по статусу
- **Статус** (только для администраторов) — фильтр по статусу кейса: Все, Активные, Отключённые. Отображается только если `user.role === "admin"`

Основная часть страницы — сетка карточек кейсов. Каждая карточка содержит изображение, название, цену в CHC и кнопку для перехода к детальному просмотру. При наведении карточка слегка приподнимается с анимацией.
