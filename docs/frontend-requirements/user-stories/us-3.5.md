# US-3.5: Альтернативная страница открытия

**Эпик:** [Epic 3: Открытие кейсов](../epics/epic-03-case-opening.md)  
**Роль:** Пользователь  
**Маршрут:** `/cases/$caseId/open`

## User Story

**Как** пользователь, **я хочу** открыть кейс на альтернативной странице с другим стилем рулетки, **чтобы** разнообразить процесс.

## Описание

Маршрут `/cases/$caseId/open` содержит альтернативную версию открытия кейса с другим визуальным оформлением рулетки. Механика и результат идентичны основной версии, но визуальная реализация отличается. Результат отображается в модальном окне.
