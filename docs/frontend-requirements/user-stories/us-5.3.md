# US-5.3: Редактирование профиля

**Эпик:** [Epic 5: Профиль пользователя](../epics/epic-05-profile.md)  
**Роль:** Пользователь, Администратор  
**Маршрут:** `/profile` (вкладка «Настройки»)

## User Story

**Как** пользователь, **я хочу** изменить свой никнейм и электронную почту, **чтобы** поддерживать актуальную информацию о себе.

## Описание

Вкладка «Настройки» в личном кабинете содержит форму редактирования профиля с двумя полями: никнейм и электронная почта. Поля предзаполнены текущими данными пользователя.

При нажатии кнопки «Сохранить» данные отправляются на сервер. После успешного сохранения кнопка на 2 секунды меняет текст на «Сохранено!» с иконкой галочки, давая визуальную обратную связь.
