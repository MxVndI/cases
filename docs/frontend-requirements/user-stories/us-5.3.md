# US-5.3: Редактирование никнейма с OTP-подтверждением

**Эпик:** [Epic 5: Профиль пользователя](../epics/epic-05-profile.md)  
**Роль:** Пользователь, Администратор  
**Маршрут:** `/profile` (вкладка «Настройки»)

## User Story

**Как** пользователь, **я хочу** изменить свой никнейм с подтверждением по email-коду, **чтобы** безопасно обновить отображаемое имя.

## Описание

Вкладка «Настройки» на странице `/profile` содержит форму редактирования никнейма. Поле предзаполнено текущим никнеймом пользователя.

### Поток изменения никнейма

1. Пользователь вводит новый никнейм в поле и нажимает кнопку **«Сохранить»**.
2. Открывается модальный диалог с полем ввода 6-значного OTP-кода (компонент `input-otp`). Одновременно фронтенд отправляет `POST /api/auth/profile/update/start` — сервер высылает код подтверждения на email пользователя.
3. Пользователь вводит полученный код. Фронтенд отправляет `POST /api/auth/profile/update/finish` с `{ code, nickname }`.
4. При успехе диалог закрывается, никнейм обновляется в `AuthContext`, кнопка на 2 секунды показывает **«Сохранено!»** с иконкой галочки.

Если код введён неверно, отображается ошибка внутри диалога. Кнопка «Сохранить» блокируется на время запроса.
