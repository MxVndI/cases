# US-5.4: Смена пароля

**Эпик:** [Epic 5: Профиль пользователя](../epics/epic-05-profile.md)  
**Роль:** Пользователь, Администратор  
**Маршрут:** `/profile` (вкладка «Настройки»)

## User Story

**Как** пользователь, **я хочу** сменить пароль, **чтобы** обеспечить безопасность аккаунта.

## Описание

На вкладке «Настройки», под формой редактирования профиля, расположена отдельная форма смены пароля. Она содержит три поля: текущий пароль, новый пароль и подтверждение нового пароля.

Валидация:
- Все три поля обязательны.
- Новый пароль и подтверждение должны совпадать. Если они не совпадают, под полем подтверждения отображается сообщение «Пароли не совпадают», а кнопка отправки блокируется.

После успешной смены пароля кнопка на 2 секунды меняет текст на «Пароль изменён!», все поля очищаются.

> **Совместимость с бэкендом:** В текущей архитектуре бэкенда пароли отсутствуют как концепция — вход осуществляется через email-код или OAuth. Данная форма применима только при использовании мок-режима либо при добавлении в бэкенд поддержки парольной аутентификации в будущем. При реальной интеграции этот раздел может быть заменён на управление способами входа (привязка/отвязка OAuth-провайдеров).
