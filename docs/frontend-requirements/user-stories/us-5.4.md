# US-5.4: Настройки интерфейса

**Эпик:** [Epic 5: Профиль пользователя](../epics/epic-05-profile.md)  
**Роль:** Пользователь, Администратор  
**Маршрут:** `/profile` (вкладка «Настройки»)

## User Story

**Как** пользователь, **я хочу** настраивать визуальные параметры интерфейса, **чтобы** адаптировать платформу под свои предпочтения.

## Описание

На вкладке «Настройки» страницы `/profile`, под формой редактирования никнейма, расположен блок **«Настройки интерфейса»** с двумя boolean-переключателями (toggle):

1. **Кастомный курсор** — включает/выключает кастомный GSAP-курсор в виде прицела (crosshair). По умолчанию **включён** (ON).
2. **CountUp-анимации** — включает/выключает анимированное появление чисел (CountUp-эффект для балансов, статистики и т.д.). По умолчанию **включён** (ON).

Настройки сохраняются в `localStorage` и управляются через `PreferencesContext`. Изменения применяются мгновенно без перезагрузки страницы. Серверная синхронизация не требуется.
