# US-7.9: CRUD справочников

**Эпик:** [Epic 7: Админ-панель](../epics/epic-07-admin.md)  
**Роль:** Администратор  
**Маршрут:** `/admin` (вкладки «Rarities» и «Weapons»)

## User Story

**Как** администратор, **я хочу** управлять справочниками (редкости, теги, типы оружия, оружие) через админ-панель, **чтобы** поддерживать актуальные данные для создания предметов и кейсов.

## Описание

Админ-панель (`/admin`) содержит две вкладки для управления справочниками:

### Вкладка «Rarities» — Редкости и теги

#### Редкости (Rarities)

Список всех редкостей с полями: название, цвет. CRUD-операции:

- **Создание / Редактирование** — диалог с полями: название (name), цвет (color).
- **Удаление** — с модальным подтверждением.

API: `adminApi.getRarities`, `adminApi.createRarity`, `adminApi.updateRarity`, `adminApi.deleteRarity`.

#### Теги (Tags)

Список всех тегов. CRUD-операции:

- **Создание / Редактирование** — диалог с полем: название (name).
- **Удаление** — с модальным подтверждением.

API: `adminApi.getTags`, `adminApi.createTag`, `adminApi.updateTag`, `adminApi.deleteTag`.

### Вкладка «Weapons» — Типы оружия и оружие

#### Типы оружия (Weapon Types)

Список типов оружия. CRUD-операции:

- **Создание / Редактирование** — диалог с полем: название (name).
- **Удаление** — с модальным подтверждением.

API: `adminApi.getWeaponTypes`, `adminApi.createWeaponType`, `adminApi.updateWeaponType`, `adminApi.deleteWeaponType`.

#### Оружие (Weapons)

Список оружия с привязкой к типу. CRUD-операции:

- **Создание / Редактирование** — диалог с полями: название (name), тип оружия (weapon_type — выпадающий список).
- **Удаление** — с модальным подтверждением.

API: `adminApi.getWeapons`, `adminApi.createWeapon`, `adminApi.updateWeapon`, `adminApi.deleteWeapon`.

### Общие паттерны

- Каждый справочник представлен списком/таблицей с кнопками «Создать», «Редактировать», «Удалить».
- Удаление всегда требует подтверждения через модальное окно.
- После успешной операции список обновляется автоматически.
