# US-2.3: Авторизация через OAuth

**Эпик:** [Epic 2: Регистрация и авторизация](../epics/epic-02-auth.md)  
**Роль:** Гость  
**Маршрут:** `/login`, `/register`

## User Story

**Как** гость, **я хочу** войти через Discord или Яндекс, **чтобы** не создавать отдельный пароль для CaseHub.

## Описание

На странице авторизации, помимо формы login/password, расположены кнопки быстрого входа через внешние сервисы: Discord и Яндекс. При нажатии на кнопку происходит перенаправление на страницу авторизации соответствующего провайдера. После подтверждения прав доступа пользователь возвращается на платформу уже авторизованным.

Кнопки OAuth также присутствуют на странице регистрации.
