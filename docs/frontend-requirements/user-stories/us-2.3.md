# US-2.3: Авторизация через OAuth

**Эпик:** [Epic 2: Регистрация и авторизация](../epics/epic-02-auth.md)  
**Роль:** Гость  
**Маршрут:** `/login`, `/register`

## User Story

**Как** гость, **я хочу** войти через Discord или Яндекс, **чтобы** быстро авторизоваться на CaseHub без создания пароля.

## Описание

На страницах авторизации (`/login`) и регистрации (`/register`), помимо формы входа по email + коду подтверждения, расположены кнопки быстрого входа через внешние сервисы: **Discord** и **Яндекс**. Пароли не используются — аутентификация происходит либо через OAuth, либо через одноразовый код, отправляемый на email.

При нажатии на кнопку OAuth-провайдера происходит перенаправление на страницу авторизации соответствующего сервиса. После подтверждения прав доступа пользователь возвращается на платформу уже авторизованным. Сессия управляется через HTTP-cookie.
