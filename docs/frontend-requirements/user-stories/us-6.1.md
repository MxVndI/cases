# US-6.1: Заработок монет кликами

**Эпик:** [Epic 6: Ферма (кликер)](../epics/epic-06-farm.md)  
**Роль:** Пользователь  
**Маршрут:** `/farm`

## User Story

**Как** пользователь, **я хочу** зарабатывать CaseHubCoin, нажимая на кнопку, **чтобы** накопить средства на открытие кейсов без вложений.

## Описание

Страница фермы (`/farm`) содержит центральную область с большой кнопкой для кликов. При каждом нажатии на баланс фермы начисляются монеты. Количество монет за клик зависит от текущего уровня улучшения «Сила клика» (базовое значение — 1 монета за клик).

В верхней части страницы отображается текущий баланс фермы и показатель дохода в секунду (от автокликера, если куплен).

При каждом клике на кнопке появляется кратковременная анимация — всплывающий текст с количеством заработанных монет (например, «+1»), который поднимается вверх и исчезает.

На странице также присутствует боковая ссылка «На главную».
