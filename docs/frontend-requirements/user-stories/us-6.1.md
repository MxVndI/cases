# US-6.1: Заработок монет кликами

**Эпик:** [Epic 6: Ферма (кликер)](../epics/epic-06-farm.md)  
**Роль:** Пользователь  
**Маршрут:** `/farm`

## User Story

**Как** пользователь, **я хочу** зарабатывать CHC (CaseHubCoin), нажимая на кнопку, **чтобы** накопить средства на открытие кейсов без вложений.

## Описание

Страница фермы (`/farm`) содержит центральную область с большой кнопкой для кликов. При каждом нажатии начисляются монеты. Количество монет за клик зависит от текущего уровня улучшения «Сила клика» (базовое значение — 1 CHC за клик).

### Серверная синхронизация кликов

Клики отправляются на сервер через `paymentApi.tap` (`POST /tap` к Payment Service). Для оптимизации клики **батчатся** (накапливаются) и отправляются пачкой каждые **1.5 секунды**. На бэкенде действует ограничение — не более **10 кликов в секунду** (rate limit).

### Отображение

В верхней части страницы отображается текущий баланс фермы и показатель дохода в секунду (от автокликера, если куплен).

### Анимация кликов

При каждом клике появляется всплывающая частица **«+N»** (где N — количество монет за клик). Анимация реализована с помощью `AnimatePresence` из framer-motion: текст поднимается вверх и плавно исчезает.

На странице также присутствует боковая ссылка «На главную».
