# US-7.6: Удаление кейса

**Эпик:** [Epic 7: Администрирование](../epics/epic-07-admin.md)  
**Роль:** Администратор  
**Маршрут:** `/admin` (вкладка «Кейсы»)

## User Story

**Как** администратор, **я хочу** удалить кейс, **чтобы** убрать неактуальный контент с платформы.

## Описание

При нажатии кнопки удаления (корзина) открывается диалог подтверждения. Заголовок: «Удалить кейс?». Описание предупреждает, что кейс будет удалён безвозвратно и действие нельзя отменить. В описании указано название удаляемого кейса. Кнопки: «Отмена» и «Удалить» (красная).

После подтверждения кейс удаляется из списка.
