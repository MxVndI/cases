# US-7.7: Ограничение доступа к панели

**Эпик:** [Epic 7: Администрирование](../epics/epic-07-admin.md)  
**Роль:** Система  
**Маршрут:** `/admin`

## User Story

**Как** система, **я хочу** ограничить доступ к панели администратора, **чтобы** только пользователи с ролью admin могли управлять контентом и пользователями.

## Описание

Страница `/admin` имеет два уровня защиты:

1. **Защита маршрута** — layout-маршрут `_protected` проверяет авторизацию. Неавторизованные пользователи перенаправляются на `/login`.

2. **Проверка роли** — компонент страницы проверяет `user.role === "admin"`. Если пользователь авторизован, но не является администратором, вместо панели управления отображается экран с иконкой щита, сообщением «Доступ запрещён», пояснением «У вас нет прав администратора» и ссылкой «На главную».
