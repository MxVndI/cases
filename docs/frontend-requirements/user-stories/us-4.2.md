# US-4.2: Просмотр инвентаря

**Эпик:** [Epic 4: Инвентарь и баланс](../epics/epic-04-inventory-balance.md)  
**Роль:** Пользователь  
**Маршрут:** `/profile` (вкладка «Инвентарь»)

## User Story

**Как** пользователь, **я хочу** видеть все предметы, полученные из кейсов, **чтобы** управлять своей коллекцией.

## Описание

Инвентарь доступен на вкладке «Инвентарь» в личном кабинете (`/profile`). Предметы отображаются в виде сетки карточек. Каждая карточка показывает название предмета, его визуальное представление (заглушка с цветом по редкости), источник получения (из какого кейса), стоимость, дату получения и кнопку продажи.

В верхней части инвентаря отображается общая стоимость всех предметов.
