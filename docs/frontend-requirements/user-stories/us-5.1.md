# US-5.1: Просмотр обзора профиля

**Эпик:** [Epic 5: Профиль пользователя](../epics/epic-05-profile.md)  
**Роль:** Пользователь, Администратор  
**Маршрут:** `/profile` (вкладка «Обзор»)

## User Story

**Как** пользователь, **я хочу** видеть сводку информации о своём аккаунте, **чтобы** быстро оценить текущее состояние дел.

## Описание

Личный кабинет (`/profile`) открывается на вкладке «Обзор» по умолчанию. В верхней части страницы расположена карточка профиля с аватаром, никнеймом, электронной почтой и датой регистрации. Если пользователь является администратором, рядом с никнеймом отображается красный бейдж «Администратор».

Вкладка «Обзор» содержит два блока:

1. **Статистика** — две карточки:
   - Количество предметов в инвентаре и их суммарная стоимость.
   - Общее количество открытых кейсов за всё время.

2. **Последние выигрыши** — три последних результата открытия кейсов. Каждая запись содержит название предмета (с цветовой маркировкой по редкости), название кейса и стоимость предмета.

Навигация между вкладками осуществляется через горизонтальную панель с четырьмя кнопками: Обзор, История, Инвентарь, Настройки.
