# US-5.2: Просмотр истории открытий

**Эпик:** [Epic 5: Профиль пользователя](../epics/epic-05-profile.md)  
**Роль:** Пользователь, Администратор  
**Маршрут:** `/profile` (вкладка «История»)

## User Story

**Как** пользователь, **я хочу** видеть полную историю всех своих открытий, **чтобы** отслеживать, что мне выпадало и сколько я потратил.

## Описание

Вкладка «История» в личном кабинете отображает полный хронологический список всех открытий кейсов. Данные загружаются с сервера через `casesApi.getMyWins`. Каждая запись в списке содержит:

- Название полученного предмета с цветовой маркировкой по редкости.
- Название кейса, из которого получен предмет.
- Дату открытия.
- Стоимость полученного предмета (доход).
- Стоимость открытия кейса (расход).

Если у пользователя ещё нет открытий, отображается сообщение «Пока нет открытий».
