# US-3.1: Одиночное открытие кейса

**Эпик:** [Epic 3: Открытие кейсов](../epics/epic-03-case-opening.md)  
**Роль:** Пользователь  
**Маршрут:** `/cases/$caseId`

## User Story

**Как** пользователь, **я хочу** открыть кейс и увидеть анимацию рулетки, **чтобы** получить случайный предмет и испытать азарт от процесса.

## Описание

На странице деталей кейса (`/cases/$caseId`) авторизованный пользователь видит кнопку «Открыть кейс» с указанием стоимости. При нажатии запускается анимация рулетки — горизонтальная полоса (рил) с предметами кейса, которая прокручивается и постепенно замедляется, останавливаясь на выигрышном предмете.

Параметры рулетки:
- Рил содержит **60 слотов** с предметами кейса, расставленными случайным образом.
- Выигрышный предмет заранее определяется и всегда оказывается на фиксированной **позиции 50**.
- Анимация длится **5 секунд** с функцией замедления `cubic-bezier(0.15, 0.85, 0.20, 1)`.
- По центру рила расположен указатель (маркер), на котором останавливается выигрышный предмет.
- Стоимость кейса списывается с баланса CHC через Payment Service.

После остановки рила система показывает **полноэкранный оверлей** с результатом: название предмета, его редкость, стоимость, анимированные частицы (партиклы) в цвете редкости предмета и две кнопки — «Забрать» (добавить в инвентарь) и «Продать» (конвертировать в CHC).
