# US-7.2: Блокировка и разблокировка пользователей

**Эпик:** [Epic 7: Администрирование](../epics/epic-07-admin.md)  
**Роль:** Администратор  
**Маршрут:** `/admin` (вкладка «Пользователи»)

## User Story

**Как** администратор, **я хочу** блокировать и разблокировать пользователей, **чтобы** поддерживать порядок на платформе и ограничивать доступ нарушителям.

## Описание

В списке пользователей для каждого пользователя (кроме администраторов) отображается кнопка действия. Если пользователь активен — это кнопка блокировки (красная иконка). Если заблокирован — кнопка разблокировки (зелёная иконка).

При нажатии на кнопку открывается диалог подтверждения. Содержимое диалога зависит от действия:

**Блокировка:**
- Заголовок: «Заблокировать пользователя?»
- Описание: Пользователь N будет заблокирован и потеряет доступ к сайту.
- Кнопки: «Отмена» и «Заблокировать» (красная).

**Разблокировка:**
- Заголовок: «Разблокировать пользователя?»
- Описание: Пользователь N будет разблокирован и сможет снова пользоваться сайтом.
- Кнопки: «Отмена» и «Разблокировать» (зелёная).

После подтверждения статус пользователя обновляется в списке. Блокировка выполняется через `adminApi.blockUser(userId)`, разблокировка — через `adminApi.unblockUser(userId)`. Кнопка блокировки/разблокировки не отображается для пользователей с ролью администратора — администраторов нельзя блокировать.
