# US-7.3: Просмотр списка кейсов

**Эпик:** [Epic 7: Администрирование](../epics/epic-07-admin.md)  
**Роль:** Администратор  
**Маршрут:** `/admin` (вкладка «Кейсы»)

## User Story

**Как** администратор, **я хочу** видеть список всех кейсов с их характеристиками, **чтобы** управлять контентом платформы.

## Описание

Вкладка «Кейсы» отображает список всех кейсов с заголовком «Кейсы (N)» и кнопкой «Добавить кейс» в правом верхнем углу.

Каждая запись в списке содержит:
- Иконку кейса.
- Название кейса.
- Категорию и количество предметов в кейсе.
- Стоимость в CaseHubCoin.
- Кнопку редактирования (иконка шестерёнки).
- Кнопку удаления (красная иконка корзины).
