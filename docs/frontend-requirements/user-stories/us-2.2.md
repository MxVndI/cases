# US-2.2: Авторизация по email OTP

**Эпик:** [Epic 2: Регистрация и авторизация](../epics/epic-02-auth.md)  
**Роль:** Гость  
**Маршрут:** `/login`

## User Story

**Как** гость, **я хочу** войти в свой аккаунт по email-коду, **чтобы** получить доступ к личному профилю, балансу и возможности открывать кейсы.

## Описание

Страница авторизации (`/login`) реализует двухшаговый поток входа на основе email OTP. Пароли отсутствуют.

### Шаг 1 — Ввод email

Пользователь вводит адрес электронной почты и нажимает кнопку **«Получить код»**. Фронтенд отправляет `POST /api/auth/email/login/start` с `{ email }`. Сервер отправляет 6-значный код на указанный email. Форма переходит к шагу 2.

### Шаг 2 — Ввод OTP-кода

Пользователь вводит 6-значный код из письма. Для ввода используется компонент `input-otp` (6 отдельных полей). После заполнения всех полей фронтенд отправляет `POST /api/auth/email/login/finish` с `{ code }`. При успехе сервер устанавливает cookie `sid`, и пользователь перенаправляется на `/`.

### OAuth

На странице также присутствуют кнопки OAuth-входа через **Discord** и **Яндекс** (реализовано через fastapi-sso на бэкенде). При нажатии пользователь перенаправляется на страницу провайдера, после авторизации — обратно на платформу.

Под формой расположена ссылка **«Нет аккаунта? Зарегистрируйтесь»** (ведёт на `/register`).

Если пользователь уже авторизован, при попытке зайти на страницу входа он автоматически перенаправляется на главную.
