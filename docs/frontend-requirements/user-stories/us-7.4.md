# US-7.4: Создание нового кейса

**Эпик:** [Epic 7: Администрирование](../epics/epic-07-admin.md)  
**Роль:** Администратор  
**Маршрут:** `/admin` (вкладка «Кейсы»)

## User Story

**Как** администратор, **я хочу** создать новый кейс с набором предметов, **чтобы** расширить ассортимент платформы.

## Описание

При нажатии кнопки «Добавить кейс» открывается диалоговое окно с формой создания кейса. Форма содержит следующие поля:

- **Название** — текстовое поле.
- **system_name** — автоматически генерируется из названия (транслитерация, snake_case). Можно редактировать вручную.
- **Цена** — числовое поле (в CHC). Доступна кнопка «Авторасчёт» для автоматического расчёта цены на основе выбранных предметов.
- **Тег** — выбор из существующих тегов (загружаются через `adminApi.getCaseTags`).
- **Статус** — active / disabled.
- **Изображение** — загрузка файла через `adminApi.uploadImage` (хранилище S3/RustFS, лимит 5 МБ). Превью изображения отображается после загрузки.
- **Предметы кейса** — компонент выбора предметов (ItemTreePicker).

Компонент выбора предметов поддерживает два режима отображения:

1. **Дерево** — предметы сгруппированы по типу оружия (AK-47, AWP, M4A4 и т.д.). Группы можно разворачивать/сворачивать. При наведении на предмет отображается превью с изображением, названием, редкостью и ценой.

2. **Галерея** — предметы отображаются в виде сетки карточек с изображением, названием и ценой.

В обоих режимах доступны фильтры:
- Поиск по названию.
- Фильтр по редкости.
- Фильтр по типу оружия (выпадающий список).
- Фильтр по диапазону цен (минимальная и максимальная).

Выбранные предметы отмечаются галочкой и подсвечиваются оранжевым. Счётчик выбранных предметов отображается под компонентом.

### Редактор дроп-шансов

Для каждого выбранного предмета отображается поле ввода шанса выпадения (drop chance, в процентах). Доступна кнопка «Авторасчёт шансов», которая вызывает `adminApi.calculateChances` и автоматически распределяет шансы между предметами.

Кнопка «Создать» активна только когда заполнены обязательные поля: название и цена.
