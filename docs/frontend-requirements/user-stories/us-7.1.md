# US-7.1: Просмотр списка пользователей

**Эпик:** [Epic 7: Администрирование](../epics/epic-07-admin.md)  
**Роль:** Администратор  
**Маршрут:** `/admin` (вкладка «Пользователи»)

## User Story

**Как** администратор, **я хочу** видеть список всех зарегистрированных пользователей с возможностью поиска и фильтрации, **чтобы** быстро находить нужных пользователей и отслеживать их активность.

## Описание

Панель администратора (`/admin`) содержит пять вкладок: «Пользователи», «Кейсы», «Предметы», «Оружие» и «Редкости». Вкладка «Пользователи» открывается по умолчанию.

В верхней части расположена панель фильтров:
- **Поиск** — текстовое поле для поиска по никнейму или email.
- **Фильтр по статусу** — три кнопки: Все, Активные, Заблокированные. Кнопка «Активные» подсвечивается зелёным, «Заблокированные» — красным.
- **Фильтр по роли** — три кнопки: Все роли, Пользователи, Администраторы.

Под фильтрами расположен список пользователей с заголовком «Пользователи (N)», где N — количество пользователей после фильтрации.

Каждая запись в списке содержит:
- Иконку с цветом по статусу (зелёный — активен, красный — заблокирован).
- Никнейм (является ссылкой на профиль пользователя `/user/$userName`).
- Бейдж роли «Администратор» (если применимо).
- Бейдж статуса: «Активен» или «Заблокирован».
- Email.
- Дату регистрации и дату последнего входа.
- Баланс в CaseHubCoin.
- Кнопку блокировки/разблокировки (не отображается для администраторов).

Если поиск и фильтры не дают результатов, отображается сообщение «Пользователи не найдены».
