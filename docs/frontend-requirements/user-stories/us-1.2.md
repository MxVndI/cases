# US-1.2: Просмотр каталога кейсов

**Эпик:** [Epic 1: Просмотр контента](../epics/epic-01-browsing.md)  
**Роль:** Гость, Пользователь, Администратор  
**Маршрут:** `/cases`

## User Story

**Как** гость, **я хочу** видеть полный список кейсов на отдельной странице-каталоге, **чтобы** быстро выбрать интересующий кейс.

## Описание

Каталог кейсов (`/cases`) — упрощённая страница по сравнению с главной. Она отображает сетку карточек всех доступных кейсов без конвейера и фильтров. Каждая карточка содержит изображение, название и цену. При клике на карточку пользователь переходит на страницу деталей кейса.

Если в URL присутствует параметр кейса (пользователь находится на вложенном маршруте, например `/cases/ak47`), вместо каталога отображается содержимое дочернего маршрута.
