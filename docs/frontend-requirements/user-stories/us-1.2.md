# US-1.2: Просмотр каталога кейсов

> **Статус: Удалено.** Отдельная страница-каталог (`/cases`) удалена из фронтенда. Просмотр кейсов доступен непосредственно с главной страницы (`/`), где уже реализована сетка с фильтрами. Переход к деталям кейса осуществляется по маршруту `/cases/$caseId`.

## User Story

~~**Как** гость, **я хочу** видеть полный список кейсов на отдельной странице-каталоге, **чтобы** быстро выбрать интересующий кейс.~~

## Описание

Функциональность каталога кейсов интегрирована в главную страницу (`/`). Отдельный маршрут `/cases` и соответствующий компонент-лейаут удалены. Маршрут `/cases/$caseId` остался — он теперь является прямым дочерним маршрутом корневого роутера.
