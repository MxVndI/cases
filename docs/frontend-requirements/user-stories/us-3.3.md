# US-3.3: Мульти-открытие кейсов

**Эпик:** [Epic 3: Открытие кейсов](../epics/epic-03-case-opening.md)  
**Роль:** Пользователь  
**Маршрут:** `/cases/$caseId`

## User Story

**Как** пользователь, **я хочу** открыть кейс сразу несколько раз за одно действие (x3 или x5), **чтобы** сэкономить время при массовом открытии.

## Описание

На странице деталей кейса, помимо кнопки одиночного открытия, расположены кнопки мульти-открытия: «x3» и «x5». При нажатии система одновременно списывает стоимость за соответствующее количество открытий и показывает результаты всех открытий в едином оверлее.

В режиме мульти-открытия анимация рулетки не проигрывается для каждого кейса — вместо этого сразу отображается общий экран результатов. Каждый предмет в результатах показывает свою редкость и стоимость. Пользователь может продать каждый предмет по отдельности или забрать все.

Кнопки мульти-открытия становятся неактивными, если на балансе недостаточно средств для соответствующего количества открытий (цена × количество).
