# US-2.4: Выход из системы

**Эпик:** [Epic 2: Регистрация и авторизация](../epics/epic-02-auth.md)  
**Роль:** Пользователь, Администратор  
**Маршрут:** —

## User Story

**Как** пользователь, **я хочу** выйти из аккаунта, **чтобы** завершить сессию и защитить свой аккаунт.

## Описание

Кнопка «Выйти» расположена в выпадающем меню хедера (подробнее в [layout.md](../layout.md)). При нажатии на кнопку сессия завершается, пользователь теряет авторизованный статус и перенаправляется на главную страницу как гость.
