# US-2.4: Выход из системы

**Эпик:** [Epic 2: Регистрация и авторизация](../epics/epic-02-auth.md)  
**Роль:** Пользователь, Администратор  
**Маршрут:** —

## User Story

**Как** пользователь, **я хочу** выйти из аккаунта, **чтобы** завершить сессию и защитить свой аккаунт.

## Описание

Кнопка «Выйти» расположена в выпадающем меню хедера (подробнее в [layout.md](../layout.md)). При нажатии на кнопку выполняется следующая последовательность:

1. Отправляется запрос `POST /auth/logout` через Axios (cookie-креденшиалы отправляются автоматически).
2. Сессионная cookie очищается на стороне сервера.
3. Вызывается `queryClient.clear()` для полной очистки кэша React Query.
4. Пользователь перенаправляется на главную страницу как гость.
