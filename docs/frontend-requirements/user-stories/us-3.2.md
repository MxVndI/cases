# US-3.2: Пропуск анимации

**Эпик:** [Epic 3: Открытие кейсов](../epics/epic-03-case-opening.md)  
**Роль:** Пользователь  
**Маршрут:** `/cases/$caseId`

## User Story

**Как** пользователь, **я хочу** пропустить анимацию рулетки, **чтобы** не ждать 5 секунд, если мне интересен только результат.

## Описание

Во время проигрывания анимации рулетки на экране появляется кнопка «Пропустить». При нажатии анимация мгновенно завершается — рил перемещается к выигрышному предмету, и сразу отображается экран результата.
