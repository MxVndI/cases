# US-6.4: Сохранение прогресса

**Эпик:** [Epic 6: Ферма (кликер)](../epics/epic-06-farm.md)  
**Роль:** Пользователь  
**Маршрут:** `/farm`

## User Story

**Как** пользователь, **я хочу** чтобы мой прогресс на ферме сохранялся между сессиями, **чтобы** не терять заработок при закрытии браузера.

## Описание

Весь прогресс фермы (баланс, уровни улучшений) сохраняется в локальном хранилище браузера (localStorage). При каждом изменении состояния (клик, покупка улучшения, тик автокликера) данные обновляются в хранилище. При открытии страницы фермы состояние восстанавливается из хранилища.
