# US-6.4: Серверная синхронизация прогресса

**Эпик:** [Epic 6: Ферма (кликер)](../epics/epic-06-farm.md)  
**Роль:** Пользователь  
**Маршрут:** `/farm`

## User Story

**Как** пользователь, **я хочу** чтобы мой прогресс на ферме сохранялся на сервере, **чтобы** не терять заработок при закрытии браузера и получать офлайн-доход.

## Описание

Прогресс фермы синхронизируется с сервером и дополнительно кэшируется в `localStorage`.

### Серверная синхронизация

Фронтенд периодически вызывает `farmApi.syncFarm`, передавая текущие уровни улучшений (`auto_clicker_level`, `speed_level`). Сервер сохраняет состояние в **Redis**.

### Офлайн-заработок

При открытии страницы фермы сервер рассчитывает офлайн-доход на основе сохранённых уровней и времени последней синхронизации. Накопленный доход отображается пользователю.

### Перевод на баланс

Вызов `farmApi.claimFarm` переводит накопленные pending-монеты на реальный баланс пользователя через Payment Service.

### Локальный кэш

`localStorage` используется как **вторичный кэш** для мгновенного восстановления UI при загрузке страницы (до ответа сервера). При получении серверных данных локальный кэш обновляется.
