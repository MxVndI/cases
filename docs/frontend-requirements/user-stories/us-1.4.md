# US-1.4: Просмотр профиля другого игрока

**Эпик:** [Epic 1: Просмотр контента](../epics/epic-01-browsing.md)  
**Роль:** Гость, Пользователь, Администратор  
**Маршрут:** `/user/$userName`

## User Story

**Как** гость, **я хочу** просматривать публичный профиль другого игрока, **чтобы** видеть его статистику и последние выигрыши.

## Описание

Публичный профиль игрока (`/user/$userName`) доступен для всех ролей. Страница отображает никнейм, дату регистрации, баланс, количество открытых кейсов и список последних выигрышей.

> **Параметр маршрута:** `$userName` — никнейм игрока (поле `nickname`). Бэкенд на текущий момент не предоставляет публичного эндпоинта для поиска пользователя по нику; поиск реализован на моке.

Каждый элемент в списке выигрышей показывает название полученного предмета, название кейса и стоимость предмета.

Если пользователь с указанным ID не найден, отображается экран с сообщением «Пользователь не найден» и ссылкой на главную страницу.

На странице также присутствует информационное сообщение о том, что это страница-заглушка и полная версия профиля будет доступна после подключения бэкенда.
