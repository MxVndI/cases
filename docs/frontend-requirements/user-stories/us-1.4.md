# US-1.4: Просмотр профиля другого игрока

**Эпик:** [Epic 1: Просмотр контента](../epics/epic-01-browsing.md)  
**Роль:** Гость, Пользователь, Администратор  
**Маршрут:** `/user/$userName`

## User Story

**Как** гость, **я хочу** просматривать публичный профиль другого игрока, **чтобы** видеть его инвентарь и последние выигрыши.

## Описание

Публичный профиль игрока доступен по маршруту `/user/$userName`, где `$userName` — никнейм пользователя. Страница доступна для всех ролей.

### Основное содержимое (все роли)

- Карточка профиля: аватар, никнейм, дата регистрации.
- **Инвентарь** с фильтрами (по редкости, оружию, цене и т.д.).
- **Последние 10 выигрышей** — название предмета, название кейса, стоимость.

### Дополнительно для администратора

Если текущий пользователь — администратор, на странице также отображаются:

- **Бейдж роли** (Администратор / Пользователь).
- **Бейдж статуса** (Активен / Заблокирован).
- **User ID** пользователя.
- **Баланс** (через `paymentApi.getUserBalance`).
- **История транзакций** (через `paymentApi.getUserTransactions`).
- **Кнопка блокировки/разблокировки** (`adminApi.blockUser` / `adminApi.unblockUser`) с модальным окном подтверждения.
- **Полная история выигрышей** — до **200 записей** (вместо 10 для обычных пользователей).

### Автоперенаправление

Если авторизованный пользователь открывает `/user/$userName`, где `$userName` совпадает с его собственным никнеймом, происходит автоматический редирект на `/profile`.

### Пользователь не найден

Если пользователь с указанным никнеймом не найден, отображается экран с сообщением «Пользователь не найден» и ссылкой на главную страницу.
