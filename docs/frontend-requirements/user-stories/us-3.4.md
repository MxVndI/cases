# US-3.4: Продажа предмета из результата

**Эпик:** [Epic 3: Открытие кейсов](../epics/epic-03-case-opening.md)  
**Роль:** Пользователь  
**Маршрут:** `/cases/$caseId`

## User Story

**Как** пользователь, **я хочу** сразу продать выпавший предмет, не переходя в инвентарь, **чтобы** быстро вернуть средства на баланс и продолжить открытие.

## Описание

На экране результата (как одиночного, так и мульти-открытия) для каждого предмета доступна кнопка «Продать». При нажатии предмет конвертируется в CaseHubCoin по его номинальной стоимости, и баланс обновляется. Предмет при этом не попадает в инвентарь.

Если пользователь нажимает «Забрать», предмет добавляется в инвентарь и его можно продать позже (см. [Epic 4: Инвентарь и баланс](../epics/epic-04-inventory-balance.md)).
