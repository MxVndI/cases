# US-7.8: CRUD предметов (Items)

**Эпик:** [Epic 7: Админ-панель](../epics/epic-07-admin.md)  
**Роль:** Администратор  
**Маршрут:** `/admin` (вкладка «Items»)

## User Story

**Как** администратор, **я хочу** управлять предметами (Items) через админ-панель, **чтобы** добавлять, редактировать и удалять предметы, доступные в кейсах.

## Описание

Вкладка **«Items»** в админ-панели (`/admin`) предоставляет полный CRUD для предметов.

### Список предметов

Таблица/список всех предметов с колонками: название, цена (CHC), редкость, оружие, изображение. Поддерживаются **фильтры**:

- По редкости (rarity).
- По оружию (weapon).
- По цене (диапазон).

### Создание / Редактирование

Диалоговое окно с полями:

- **Название** (name) — текстовое поле, обязательное.
- **Цена** (price) — числовое поле в CHC, обязательное.
- **Изображение** — загрузка файла (upload в S3 через API).
- **Редкость** (rarity) — выпадающий список из справочника редкостей.
- **Оружие** (weapon) — выпадающий список из справочника оружия.

При создании используется `adminApi.createItem`, при редактировании — `adminApi.updateItem`.

### Удаление

Удаление предмета с **модальным окном подтверждения**. API: `adminApi.deleteItem`.

### API

| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| GET | adminApi.getItems | Получить список предметов (с фильтрами) |
| POST | adminApi.createItem | Создать предмет |
| PUT | adminApi.updateItem | Обновить предмет |
| DELETE | adminApi.deleteItem | Удалить предмет |
