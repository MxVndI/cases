# US-1.5: Дополнительная информация для администратора

**Эпик:** [Epic 1: Просмотр контента](../epics/epic-01-browsing.md)  
**Роль:** Администратор  
**Маршрут:** `/user/$userId`

## User Story

**Как** администратор, **я хочу** видеть статус и роль другого игрока на его странице профиля, **чтобы** быстро оценивать состояние аккаунта без перехода в панель управления.

## Описание

Если текущий пользователь является администратором, на странице профиля другого игрока дополнительно отображаются:
- Бейдж статуса рядом с никнеймом: «Активен» (зелёный) или «Заблокирован» (красный)
- Карточка с ролью пользователя в блоке статистики: «Администратор» или «Пользователь»

Эти элементы видны **только** администратору и не отображаются для обычных пользователей или гостей.
