# US-1.5: Дополнительная информация для администратора

**Эпик:** [Epic 1: Просмотр контента](../epics/epic-01-browsing.md)  
**Роль:** Администратор  
**Маршрут:** `/user/$userName`

## User Story

**Как** администратор, **я хочу** видеть полную информацию о другом игроке на его странице профиля, **чтобы** управлять аккаунтом без перехода в панель управления.

## Описание

Если текущий пользователь является администратором, на странице профиля другого игрока (`/user/$userName`) дополнительно отображаются следующие элементы (видны **только** администратору):

### Информационные бейджи

- **Бейдж роли** рядом с никнеймом: «Администратор» или «Пользователь».
- **Бейдж статуса**: «Активен» (зелёный) или «Заблокирован» (красный).
- **User ID** пользователя.

### Баланс

Отображение баланса пользователя в CHC. API: `paymentApi.getUserBalance(userId)`.

### История транзакций

Полная история транзакций пользователя с возможностью поиска и фильтрации. API: `paymentApi.getUserTransactions(userId)`. Включает фильтры по типу операции и поиск по сумме/описанию.

### Блокировка / Разблокировка

Кнопка **«Заблокировать»** (или **«Разблокировать»**, если пользователь уже заблокирован). При нажатии открывается **модальное окно подтверждения**. API:
- `adminApi.blockUser(userId)` — блокировка.
- `adminApi.unblockUser(userId)` — разблокировка.

После действия бейдж статуса обновляется.

### Полная история выигрышей

Администратор видит до **200 записей** выигрышей (вместо 10 для обычных пользователей).
