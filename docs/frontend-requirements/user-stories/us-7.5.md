# US-7.5: Редактирование кейса

**Эпик:** [Epic 7: Администрирование](../epics/epic-07-admin.md)  
**Роль:** Администратор  
**Маршрут:** `/admin` (вкладка «Кейсы»)

## User Story

**Как** администратор, **я хочу** изменить параметры существующего кейса, **чтобы** обновить его содержимое, цену или описание.

## Описание

При нажатии кнопки редактирования (шестерёнка) на карточке кейса открывается диалоговое окно, идентичное по структуре диалогу создания (см. [US-7.4](us-7.4.md)), но все поля предзаполнены текущими данными кейса. Заголовок диалога — «Редактировать кейс».

Предметы, которые уже входят в состав кейса, отмечены галочками в компоненте выбора. Администратор может добавлять и убирать предметы.

Кнопка «Сохранить» обновляет кейс.
