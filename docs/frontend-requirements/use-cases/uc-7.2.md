# UC-7.2: Управление кейсами

**Эпик:** [Epic 7: Администрирование](../epics/epic-07-admin.md)

## Описание

Процесс создания, редактирования и удаления кейсов.

## Акторы

- **Основной:** Администратор

## Предусловия

- Администратор авторизован.
- Администратор находится на вкладке «Кейсы» панели управления.

## Основной сценарий (создание)

1. Администратор нажимает «Добавить кейс».
2. Система отображает диалог создания с формой.
3. Администратор заполняет название, цену, описание и выбирает категорию.
4. Администратор выбирает предметы из каталога (через дерево или галерею).
5. Администратор нажимает «Создать».
6. Система добавляет новый кейс в начало списка.
7. Диалог закрывается.

## Основной сценарий (редактирование)

1. Администратор нажимает кнопку редактирования на карточке кейса.
2. Система отображает диалог с предзаполненной формой.
3. Администратор вносит изменения.
4. Администратор нажимает «Сохранить».
5. Система обновляет данные кейса в списке.

## Основной сценарий (удаление)

1. Администратор нажимает кнопку удаления на карточке кейса.
2. Система отображает диалог подтверждения с названием кейса.
3. Администратор подтверждает удаление.
4. Система удаляет кейс из списка.

## Постусловия

- Список кейсов обновлён (кейс создан / изменён / удалён).

## Альтернативные потоки

- **5a (создание).** Обязательные поля не заполнены — кнопка «Создать» неактивна.
- **3a (удаление).** Администратор нажимает «Отмена» — кейс не удаляется.
