# UC-7.2: Управление кейсами и сущностями

**Эпик:** [Epic 7: Администрирование](../epics/epic-07-admin.md)

## Описание

Процесс полного управления кейсами (CRUD) на вкладке «Cases» панели администратора `/admin`. Также описывает наличие вкладок для управления связанными сущностями: Items, Rarities, Weapons, Weapon Types, Tags.

## Акторы

- **Основной:** Администратор
- **Вторичный:** Admin Service (API), Storage Service (S3/RustFS)

## Предусловия

- Администратор авторизован с ролью `admin`.
- Администратор находится на вкладке «Cases» панели `/admin`.

## Основной сценарий (создание кейса)

1. Администратор нажимает «Добавить кейс».
2. Система отображает диалог создания с формой: название, цена, описание.
3. Администратор загружает изображение кейса (до 5 МБ, загрузка в S3/RustFS).
4. Поле `system_name` генерируется автоматически на основе названия.
5. Администратор выбирает теги через селектор тегов.
6. Администратор выбирает предметы из каталога через Item Picker:
   - Режим «Дерево» — иерархический выбор по категориям.
   - Режим «Галерея» — визуальный выбор с превью.
7. Для каждого выбранного предмета администратор задаёт шанс выпадения (drop chance). Доступна кнопка «Авто-расчёт» для автоматического распределения шансов.
8. Администратор нажимает «Создать».
9. Система валидирует данные (сумма шансов = 100%) и отправляет запрос в Admin Service.
10. Новый кейс появляется в начале списка. Диалог закрывается.

## Основной сценарий (редактирование кейса)

1. Администратор нажимает кнопку редактирования на карточке кейса.
2. Система отображает диалог с предзаполненной формой.
3. Администратор вносит изменения (включая замену изображения, добавление/удаление предметов, изменение шансов).
4. Администратор нажимает «Сохранить».
5. Система обновляет данные кейса через Admin Service.

## Основной сценарий (удаление кейса)

1. Администратор нажимает кнопку удаления на карточке кейса.
2. Система отображает диалог подтверждения с названием кейса.
3. Администратор подтверждает удаление.
4. Система удаляет кейс через Admin Service.

## Управление связанными сущностями

Панель администратора `/admin` содержит 5 вкладок с полным CRUD для каждой сущности:

- **Items** — создание, редактирование, удаление предметов. Загрузка изображений (S3/RustFS, до 5 МБ). Привязка к редкости и оружию.
- **Rarities** — управление уровнями редкости (название, цвет).
- **Weapons** — управление оружием (название, тип оружия, изображение).
- **Weapon Types** — управление типами оружия (название).
- **Tags** — управление тегами для категоризации кейсов.

## Постусловия

- Список кейсов / сущностей обновлён (создан / изменён / удалён).
- Изображения загружены в S3/RustFS.

## Альтернативные потоки

- **8a (создание).** Обязательные поля не заполнены или сумма шансов ≠ 100% — кнопка «Создать» неактивна.
- **3a (удаление).** Администратор нажимает «Отмена» — кейс не удаляется.
- **3a (изображение).** Файл превышает 5 МБ — система отображает ошибку валидации.
