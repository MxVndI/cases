# UC-5.2: Редактирование профиля

**Эпик:** [Epic 5: Профиль пользователя](../epics/epic-05-profile.md)

## Описание

Процесс изменения персональных данных пользователя.

## Акторы

- **Основной:** Пользователь

## Предусловия

- Пользователь авторизован.
- Пользователь находится на вкладке «Настройки» личного кабинета.

## Основной сценарий

1. Пользователь изменяет никнейм и/или электронную почту в форме.
2. Пользователь нажимает «Сохранить».
3. Система отправляет обновлённые данные на сервер.
4. При успехе — кнопка показывает «Сохранено!» на 2 секунды.
5. Данные в карточке профиля обновляются.

## Постусловия

- Данные профиля обновлены.

## Альтернативные потоки

- **3a.** Ошибка сервера — система уведомляет об ошибке.
