# UC-5.2: Редактирование профиля

**Эпик:** [Epic 5: Профиль пользователя](../epics/epic-05-profile.md)

## Описание

Процесс изменения никнейма пользователя с подтверждением через OTP-код на email. Выполняется на вкладке «Настройки» страницы `/profile`.

## Акторы

- **Основной:** Пользователь
- **Вторичный:** Auth Service (API), почтовый сервис

## Предусловия

- Пользователь авторизован.
- Пользователь находится на вкладке «Настройки» в `/profile`.

## Основной сценарий

1. Пользователь вводит новый никнейм в поле формы.
2. Пользователь нажимает кнопку «Сохранить».
3. Система отправляет запрос `POST /profile/update/start`.
4. Auth Service отправляет 6-значный OTP-код на email пользователя.
5. Система отображает модальный диалог с полем ввода OTP-кода.
6. Пользователь вводит полученный код и нажимает «Подтвердить».
7. Система отправляет запрос `POST /profile/update/finish` с новым никнеймом и OTP-кодом.
8. Auth Service проверяет код и обновляет никнейм.
9. Диалог закрывается, кнопка показывает «Сохранено!» на 2 секунды.
10. Никнейм в карточке профиля и хедере обновляется.

## Постусловия

- Никнейм пользователя обновлён.

## Альтернативные потоки

- **5a.** Пользователь закрывает OTP-диалог — изменение отменяется, никнейм не меняется.
- **7a.** Неверный или просроченный OTP-код — система отображает ошибку в диалоге, предлагает запросить код повторно.
- **7b.** Никнейм уже занят — сервер возвращает ошибку, система отображает уведомление.
- **3a.** Ошибка сервера при запуске — система уведомляет об ошибке.
