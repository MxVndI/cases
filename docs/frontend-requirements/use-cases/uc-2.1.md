# UC-2.1: Регистрация пользователя

**Эпик:** [Epic 2: Регистрация и авторизация](../epics/epic-02-auth.md)

## Описание

Процесс создания нового аккаунта на платформе CaseHub.

## Акторы

- **Основной:** Гость
- **Вторичный:** Система аутентификации

## Предусловия

- Гость находится на сайте CaseHub.
- Гость не авторизован.

## Основной сценарий

1. Гость переходит на страницу регистрации (по кнопке «Войти» → ссылка «Нет аккаунта?» или напрямую по `/register`).
2. Система отображает форму регистрации с полями: никнейм, email, пароль, подтверждение пароля.
3. Гость заполняет все поля и нажимает кнопку «Зарегистрироваться».
4. Система проверяет корректность данных (заполненность всех полей, совпадение паролей, уникальность email).
5. При успешной проверке система создаёт аккаунт.
6. Система автоматически авторизует пользователя и перенаправляет на главную страницу.

## Постусловия

- Создан новый аккаунт.
- Пользователь авторизован и видит авторизованный интерфейс.

## Альтернативные потоки

- **4a.** Если пароли не совпадают — система отображает сообщение об ошибке.
- **4b.** Если email уже занят — система уведомляет об ошибке.
- **4c.** Если обязательные поля не заполнены — кнопка отправки неактивна.
