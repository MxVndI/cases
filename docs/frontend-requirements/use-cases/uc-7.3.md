# UC-7.3: Ограничение доступа

**Эпик:** [Epic 7: Администрирование](../epics/epic-07-admin.md)

## Описание

Система ограничивает доступ к защищённым маршрутам (включая `/admin`) через layout-маршрут `_protected`. Проверка авторизации и роли выполняется в хуке `beforeLoad`.

## Акторы

- **Основной:** Гость или Пользователь (не admin)
- **Вторичный:** Router (`_protected` layout route), Auth Service

## Предусловия

- Посетитель пытается перейти на защищённый маршрут (например, `/admin`, `/profile`, `/balance`, `/farm`).

## Сценарий для гостя (не авторизован)

1. Гость переходит на защищённый маршрут (например, `/admin`).
2. Layout-маршрут `_protected` выполняет проверку авторизации в `beforeLoad`.
3. Система обнаруживает отсутствие cookie-сессии / неавторизованное состояние.
4. Система перенаправляет на `/login`.

## Сценарий для обычного пользователя (авторизован, роль ≠ admin)

1. Пользователь переходит на `/admin`.
2. Layout-маршрут `_protected` выполняет проверку авторизации в `beforeLoad` — пользователь авторизован.
3. Система дополнительно проверяет роль пользователя.
4. Роль = `user` (не `admin`) — система отображает экран «Доступ запрещён» (Access Denied) со ссылкой на главную страницу `/`.

## Сценарий для администратора

1. Администратор переходит на `/admin`.
2. Layout-маршрут `_protected` подтверждает авторизацию и роль `admin` в `beforeLoad`.
3. Система отображает панель администратора.

## Постусловия

- Гость перенаправлен на `/login`.
- Обычный пользователь видит экран «Доступ запрещён».
- Администратор получает доступ к панели управления.
