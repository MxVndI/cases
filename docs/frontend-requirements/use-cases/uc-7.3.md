# UC-7.3: Ограничение доступа

**Эпик:** [Epic 7: Администрирование](../epics/epic-07-admin.md)

## Описание

Система ограничивает доступ к панели администратора для неавторизованных пользователей и обычных пользователей.

## Акторы

- **Основной:** Гость или Пользователь (не admin)

## Предусловия

- Посетитель пытается перейти на `/admin`.

## Сценарий для гостя

1. Гость переходит на `/admin`.
2. Система обнаруживает отсутствие авторизации.
3. Система перенаправляет на `/login`.

## Сценарий для обычного пользователя

1. Пользователь переходит на `/admin`.
2. Система подтверждает авторизацию.
3. Система проверяет роль — `user` (не admin).
4. Система отображает экран «Доступ запрещён» со ссылкой на главную.

## Постусловия

- Доступ к панели управления не предоставлен.
