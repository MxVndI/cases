# UC-3.2: Мульти-открытие кейса

**Эпик:** [Epic 3: Открытие кейсов](../epics/epic-03-case-opening.md)

## Описание

Процесс одновременного открытия нескольких экземпляров одного кейса.

## Акторы

- **Основной:** Пользователь
- **Вторичный:** Система генерации выпадений

## Предусловия

- Пользователь авторизован.
- На балансе достаточно средств для нескольких открытий (цена × количество).

## Основной сценарий

1. Пользователь нажимает кнопку «x3» или «x5».
2. Система проверяет баланс (стоимость × количество).
3. Система списывает полную стоимость.
4. Система генерирует выигрышные предметы для каждого открытия.
5. Система отображает экран результатов со всеми выпавшими предметами.
6. Пользователь может продать каждый предмет по отдельности или забрать все.

## Постусловия

- Баланс уменьшен на суммарную стоимость.
- Каждый предмет обработан индивидуально (инвентарь или продажа).

## Альтернативные потоки

- **2a.** Недостаточно средств для выбранного количества — кнопка неактивна.
