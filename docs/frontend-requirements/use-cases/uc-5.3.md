# UC-5.3: Смена пароля

**Эпик:** [Epic 5: Профиль пользователя](../epics/epic-05-profile.md)

## Описание

Процесс изменения пароля пользователя.

## Акторы

- **Основной:** Пользователь

## Предусловия

- Пользователь авторизован.
- Пользователь знает текущий пароль.

## Основной сценарий

1. Пользователь вводит текущий пароль, новый пароль и подтверждение.
2. Система проверяет совпадение нового пароля и подтверждения.
3. Пользователь нажимает «Изменить пароль».
4. Система проверяет текущий пароль и обновляет его.
5. Кнопка показывает «Пароль изменён!» на 2 секунды.
6. Все поля очищаются.

## Постусловия

- Пароль обновлён.

## Альтернативные потоки

- **2a.** Пароли не совпадают — отображается ошибка, кнопка заблокирована.
- **4a.** Текущий пароль неверен — система уведомляет об ошибке.
