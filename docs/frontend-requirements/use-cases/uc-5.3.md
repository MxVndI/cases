# UC-5.3: Настройки интерфейса

**Эпик:** [Epic 5: Профиль пользователя](../epics/epic-05-profile.md)

## Описание

Управление визуальными настройками интерфейса через переключатели на вкладке «Настройки» страницы `/profile`. Настройки сохраняются локально в `localStorage` через `PreferencesContext`.

## Акторы

- **Основной:** Пользователь

## Предусловия

- Пользователь авторизован.
- Пользователь находится на вкладке «Настройки» в `/profile`.

## Основной сценарий

1. Система отображает раздел «Настройки интерфейса» с двумя переключателями (toggle):
   - **Кастомный курсор** — включает/выключает пользовательский курсор с анимацией GSAP.
   - **CountUp-анимации** — включает/выключает анимации счётчиков (числа плавно «накручиваются» при изменении).
2. Пользователь переключает нужную настройку.
3. Система мгновенно сохраняет состояние в `localStorage` через `PreferencesContext`.
4. Изменение применяется немедленно без перезагрузки страницы:
   - Кастомный курсор появляется/скрывается в реальном времени.
   - CountUp-анимации активируются/деактивируются для всех числовых значений.

## Постусловия

- Настройки сохранены в `localStorage`.
- Визуальные эффекты применены в соответствии с выбранными настройками.
- Настройки сохраняются между сессиями (persisted в `localStorage`).

## Альтернативные потоки

- **1a.** При первом посещении — все настройки имеют значения по умолчанию (определяются `PreferencesContext`).
- **3a.** `localStorage` недоступен — настройки работают только в рамках текущей сессии (в памяти).
