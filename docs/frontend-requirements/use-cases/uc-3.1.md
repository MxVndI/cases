# UC-3.1: Открытие кейса

**Эпик:** [Epic 3: Открытие кейсов](../epics/epic-03-case-opening.md)

## Описание

Процесс открытия кейса авторизованным пользователем с получением случайного предмета.

## Акторы

- **Основной:** Пользователь
- **Вторичный:** Система генерации выпадений

## Предусловия

- Пользователь авторизован.
- Пользователь находится на странице деталей кейса.
- На балансе достаточно средств для открытия.

## Основной сценарий

1. Пользователь нажимает кнопку «Открыть кейс».
2. Система проверяет достаточность баланса.
3. Система списывает стоимость кейса с баланса.
4. Система случайным образом определяет выигрышный предмет.
5. Система генерирует рил из 60 слотов и запускает анимацию прокрутки (5 секунд).
6. Рулетка останавливается на выигрышном предмете.
7. Система отображает полноэкранный оверлей с результатом.
8. Пользователь выбирает: «Забрать» (предмет → инвентарь) или «Продать» (предмет → CaseHubCoin на баланс).
9. Оверлей закрывается, пользователь может открыть кейс снова.

## Постусловия

- Баланс уменьшен на стоимость кейса.
- Предмет либо добавлен в инвентарь, либо конвертирован в CaseHubCoin.
- Открытие записано в историю.

## Альтернативные потоки

- **2a.** Недостаточно средств — кнопка неактивна, открытие невозможно.
- **5a.** Пользователь нажимает «Пропустить» — анимация мгновенно завершается, сразу отображается результат.
