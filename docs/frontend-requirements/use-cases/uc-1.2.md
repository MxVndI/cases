# UC-1.2: Просмотр профиля игрока

**Эпик:** [Epic 1: Просмотр контента](../epics/epic-01-browsing.md)

## Описание

Сценарий описывает просмотр публичного профиля другого игрока.

## Акторы

- **Основной:** Гость (или Пользователь, или Администратор)

## Предусловия

- Посетитель перешёл по ссылке `/user/$userId`.

## Основной сценарий

1. Посетитель открывает страницу профиля игрока.
2. Система ищет пользователя по идентификатору.
3. Система отображает карточку профиля: никнейм, дата регистрации, баланс, статистику.
4. Система отображает список последних выигрышей пользователя.

## Постусловия

- Посетитель просмотрел публичную информацию о другом игроке.

## Альтернативные потоки

- **2a.** Пользователь с указанным ID не найден — система отображает экран «Пользователь не найден» со ссылкой на главную.
- **3a.** Если посетитель — администратор, дополнительно отображаются статус и роль просматриваемого игрока.
