# UC-1.2: Просмотр профиля игрока

**Эпик:** [Epic 1: Просмотр контента](../epics/epic-01-browsing.md)

## Описание

Сценарий описывает просмотр публичного профиля другого игрока по маршруту `/user/$userName`.

## Акторы

- **Основной:** Гость (или Пользователь, или Администратор)
- **Вторичный:** User Service (API), Cases Service (API), Payment Service (API — только для администратора)

## Предусловия

- Посетитель перешёл по ссылке `/user/$userName`.

## Основной сценарий

1. Посетитель открывает маршрут `/user/$userName`.
2. Система проверяет, совпадает ли `$userName` с никнеймом текущего авторизованного пользователя.
3. Система ищет пользователя по никнейму через User Service.
4. Система отображает карточку профиля: аватар, никнейм, дата регистрации.
5. Система отображает инвентарь пользователя с фильтрами (по редкости, по оружию).
6. Система отображает список последних 10 выигрышей.
7. Если посетитель — администратор, система дополнительно отображает:
   - Баланс пользователя (CHC) через Payment Service.
   - Историю транзакций.
   - Кнопку блокировки/разблокировки с диалогом подтверждения.
   - Расширенный список до 200 последних выигрышей.

## Постусловия

- Посетитель просмотрел публичную информацию о другом игроке.

## Альтернативные потоки

- **2a.** Если `$userName` совпадает с никнеймом текущего пользователя — система автоматически перенаправляет на `/profile`.
- **3a.** Пользователь с указанным никнеймом не найден — система отображает экран «Пользователь не найден» со ссылкой на главную.
