# UC-2.2: Авторизация пользователя

**Эпик:** [Epic 2: Регистрация и авторизация](../epics/epic-02-auth.md)

## Описание

Процесс входа зарегистрированного пользователя в систему.

## Акторы

- **Основной:** Гость
- **Вторичный:** Система аутентификации

## Предусловия

- Гость находится на сайте CaseHub.
- Аккаунт с указанными данными существует.

## Основной сценарий

1. Гость переходит на страницу авторизации (по кнопке «Войти» в хедере или по `/login`).
2. Система отображает форму входа с полями: email, пароль.
3. Гость вводит данные и нажимает «Войти».
4. Система проверяет корректность введённых данных.
5. Система создаёт активную сессию.
6. Система перенаправляет пользователя на главную страницу.
7. Хедер обновляется: отображаются баланс и меню пользователя.

## Постусловия

- Пользователь авторизован.
- Создана активная сессия.
- Доступны все функции для авторизованного пользователя.

## Альтернативные потоки

- **4a.** Неверный email или пароль — система отображает сообщение об ошибке.
- **4b.** Аккаунт заблокирован — система сообщает о блокировке.
