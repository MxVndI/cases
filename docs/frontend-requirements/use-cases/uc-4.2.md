# UC-4.2: Просмотр баланса

**Эпик:** [Epic 4: Инвентарь и баланс](../epics/epic-04-inventory-balance.md)

## Описание

Просмотр текущего баланса и финансовой статистики.

## Акторы

- **Основной:** Пользователь

## Предусловия

- Пользователь авторизован.

## Основной сценарий

1. Пользователь переходит на страницу баланса (`/balance`).
2. Система отображает текущий баланс, статистику (потрачено, выиграно, заработано, прибыль) и историю последних операций.
3. Пользователь может перейти к ферме или бонусу через ссылки в разделе «Действия».

## Постусловия

- Пользователь ознакомился со своим финансовым состоянием.
