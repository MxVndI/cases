# UC-4.2: Просмотр баланса

**Эпик:** [Epic 4: Инвентарь и баланс](../epics/epic-04-inventory-balance.md)

## Описание

Просмотр текущего баланса в CHC (CaseHubCoin), финансовой статистики, истории транзакций и получение ежедневного бонуса на странице `/balance`.

## Акторы

- **Основной:** Пользователь
- **Вторичный:** Payment Service (API)

## Предусловия

- Пользователь авторизован.

## Основной сценарий

1. Пользователь переходит на страницу баланса `/balance`.
2. Система загружает данные через `paymentApi.getBalance`.
3. Система отображает 4 плитки статистики: текущий баланс (CHC), потрачено, выиграно, заработано на ферме.
4. Система отображает блок ежедневного бонуса:
   - Если прошло ≥ 24 часов с последнего получения — кнопка «Получить бонус» активна.
   - Если бонус уже получен — отображается таймер до следующего доступного бонуса.
5. Система отображает историю последних 10 транзакций (тип, сумма, дата).
6. Система отображает карточки действий со ссылками на ферму `/farm` и каталог кейсов `/`.

## Сценарий получения ежедневного бонуса

1. Пользователь нажимает кнопку «Получить бонус».
2. Система вызывает `paymentApi.dailyBonus`.
3. Payment Service начисляет 100 CHC на баланс.
4. Плитка баланса обновляется, кнопка бонуса переходит в состояние ожидания с таймером 24 часа.

## Постусловия

- Пользователь ознакомился со своим финансовым состоянием.
- При получении бонуса баланс увеличен на 100 CHC.

## Альтернативные потоки

- **2a.** Ошибка загрузки данных — система отображает уведомление об ошибке с возможностью повторить.
- **2b (бонус).** Бонус уже был получен менее 24 часов назад — сервер возвращает ошибку, система отображает оставшееся время.
