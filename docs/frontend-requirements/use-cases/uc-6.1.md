# UC-6.1: Фарм монет

**Эпик:** [Epic 6: Ферма (кликер)](../epics/epic-06-farm.md)

## Описание

Процесс заработка CHC (CaseHubCoin) через кликер на странице `/farm`. Прогресс синхронизируется с сервером. Клики отправляются батчами, автокликер синхронизируется периодически, накопленный банк забирается по достижении лимита.

## Акторы

- **Основной:** Пользователь
- **Вторичный:** Payment Service (Farm API)

## Предусловия

- Пользователь авторизован.

## Основной сценарий

1. Пользователь открывает страницу `/farm`.
2. Система загружает сохранённый прогресс с сервера через `farmApi.syncFarm` (или инициализирует начальное состояние).
3. Если у пользователя были офлайн-заработки (автокликер работал) — система отображает сумму офлайн-дохода.
4. Пользователь нажимает на кнопку кликера.
5. Система локально начисляет монеты с учётом силы клика (Click Power) и множителя (Multiplier).
6. Клики накапливаются и отправляются на сервер батчами через `farmApi.tap` каждые 1.5 секунды.
7. Пользователь покупает улучшения (4 типа):
   - **Click Power** — увеличивает количество CHC за клик.
   - **Multiplier** — множитель для всех начислений.
   - **Auto-Clicker** — автоматические клики без участия пользователя.
   - **Auto-Speed** — увеличивает скорость автокликера.
8. Система списывает стоимость улучшения, повышает уровень, пересчитывает параметры.
9. Если куплен Auto-Clicker — система начинает автоматическое начисление и периодическую синхронизацию через `farmApi.syncFarm`.
10. Pending bank (накопленный банк) имеет максимум 1000 CHC. При достижении лимита пользователь нажимает «Забрать» — система вызывает `farmApi.claimFarm`, средства переводятся на основной баланс.

## Постусловия

- Баланс фермы (pending bank) увеличен.
- При claimFarm средства переведены на основной баланс CHC.
- Улучшения приобретены.
- Прогресс синхронизирован с сервером.

## Альтернативные потоки

- **6a.** Ошибка сети при отправке батча — клики сохраняются локально и отправляются при следующей попытке.
- **8a.** Недостаточно монет для улучшения — кнопка покупки неактивна.
- **2a.** Нет сохранённого прогресса на сервере — система создаёт начальное состояние (0 монет, все улучшения на 1 уровне).
- **10a.** Pending bank не достиг лимита — кнопка «Забрать» активна, но пользователь может забрать в любой момент.
