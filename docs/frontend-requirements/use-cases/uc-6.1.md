# UC-6.1: Фарм монет

**Эпик:** [Epic 6: Ферма (кликер)](../epics/epic-06-farm.md)

## Описание

Процесс заработка CaseHubCoin через кликер и улучшения.

## Акторы

- **Основной:** Пользователь

## Предусловия

- Пользователь авторизован.

## Основной сценарий

1. Пользователь открывает страницу фермы.
2. Система загружает сохранённый прогресс (или инициализирует начальное состояние).
3. Пользователь нажимает на кнопку кликера.
4. Система начисляет монеты с учётом силы клика и множителя.
5. Пользователь накапливает достаточно монет и покупает улучшение.
6. Система списывает стоимость, повышает уровень улучшения, пересчитывает параметры.
7. Если куплен автокликер — система начинает автоматическое начисление.
8. Прогресс сохраняется при каждом изменении.

## Постусловия

- Баланс фермы увеличен.
- Улучшения приобретены.
- Прогресс сохранён.

## Альтернативные потоки

- **5a.** Недостаточно монет для улучшения — кнопка покупки неактивна.
- **2a.** Нет сохранённого прогресса — система создаёт начальное состояние (0 монет, все улучшения на 1 уровне).
