# UC-7.1: Управление пользователями

**Эпик:** [Epic 7: Администрирование](../epics/epic-07-admin.md)

## Описание

Процесс просмотра, поиска и изменения статуса пользователей на вкладке «Users» панели администратора `/admin`.

## Акторы

- **Основной:** Администратор
- **Вторичный:** Admin Service (API), User Service

## Предусловия

- Администратор авторизован.
- Администратор имеет роль `admin`.
- Администратор находится на маршруте `/admin`.

## Основной сценарий

1. Администратор переходит на панель управления `/admin`.
2. Система отображает вкладку «Users» со списком всех пользователей.
3. Администратор использует строку поиска для нахождения пользователя по никнейму или email.
4. Администратор использует фильтры: по статусу (активный/заблокированный), по роли (user/admin).
5. Система отображает отфильтрованный список пользователей.
6. Каждая строка пользователя содержит ссылку на `/user/$userName` для просмотра публичного профиля.
7. Администратор нажимает кнопку блокировки/разблокировки на строке пользователя.
8. Система отображает диалог подтверждения с указанием никнейма пользователя.
9. Администратор подтверждает действие.
10. Система обновляет статус пользователя через Admin Service.
11. Список обновляется, отражая новый статус.

## Постусловия

- Статус пользователя изменён (заблокирован/разблокирован).

## Альтернативные потоки

- **7a.** Пользователь является администратором — кнопка блокировки не отображается.
- **9a.** Администратор нажимает «Отмена» — диалог закрывается, ничего не меняется.
- **5a.** Поиск/фильтры не дали результатов — отображается «Пользователи не найдены».
