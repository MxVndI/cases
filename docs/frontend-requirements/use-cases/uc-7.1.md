# UC-7.1: Управление пользователями

**Эпик:** [Epic 7: Администрирование](../epics/epic-07-admin.md)

## Описание

Процесс просмотра, поиска и изменения статуса пользователей.

## Акторы

- **Основной:** Администратор

## Предусловия

- Администратор авторизован.
- Администратор имеет роль `admin`.

## Основной сценарий

1. Администратор переходит на панель управления (`/admin`).
2. Система отображает вкладку «Пользователи» со списком всех пользователей.
3. Администратор может использовать поиск и фильтры для нахождения нужного пользователя.
4. Администратор нажимает кнопку блокировки/разблокировки.
5. Система отображает диалог подтверждения.
6. Администратор подтверждает действие.
7. Система обновляет статус пользователя.
8. Список обновляется, отражая новый статус.

## Постусловия

- Статус пользователя изменён (заблокирован/разблокирован).

## Альтернативные потоки

- **4a.** Пользователь является администратором — кнопка блокировки не отображается.
- **6a.** Администратор нажимает «Отмена» — диалог закрывается, ничего не меняется.
- **3a.** Поиск не дал результатов — отображается «Пользователи не найдены».
