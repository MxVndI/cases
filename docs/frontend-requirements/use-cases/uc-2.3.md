# UC-2.3: Авторизация через OAuth

**Эпик:** [Epic 2: Регистрация и авторизация](../epics/epic-02-auth.md)

## Описание

Процесс входа или регистрации через внешний провайдер (Discord, Яндекс).

## Акторы

- **Основной:** Гость
- **Вторичные:** OAuth-провайдер (Discord / Яндекс), Система аутентификации

## Предусловия

- Гость находится на странице авторизации или регистрации.

## Основной сценарий

1. Гость нажимает кнопку «Войти через Discord» (или «Войти через Яндекс»).
2. Система перенаправляет на страницу авторизации провайдера.
3. Гость подтверждает доступ для CaseHub.
4. Провайдер перенаправляет обратно на CaseHub с токеном.
5. Система создаёт сессию (при первом входе — также создаёт аккаунт).
6. Пользователь попадает на главную страницу в авторизованном состоянии.

## Постусловия

- Пользователь авторизован.

## Альтернативные потоки

- **3a.** Гость отклоняет запрос на доступ — возвращается на страницу авторизации CaseHub.
- **4a.** Ошибка провайдера — система отображает сообщение об ошибке.
