# UC-5.1: Просмотр профиля

**Эпик:** [Epic 5: Профиль пользователя](../epics/epic-05-profile.md)

## Описание

Просмотр пользователем информации о своём аккаунте, статистике и последних действиях.

## Акторы

- **Основной:** Пользователь

## Предусловия

- Пользователь авторизован.

## Основной сценарий

1. Пользователь переходит в раздел «Профиль» (через меню в хедере).
2. Система отображает карточку профиля и вкладку «Обзор» с краткой статистикой и последними выигрышами.
3. Пользователь может переключаться между вкладками: Обзор, История, Инвентарь, Настройки.
4. Система отображает содержимое выбранной вкладки.

## Постусловия

- Пользователь просмотрел актуальные данные о своём аккаунте.

## Альтернативные потоки

- **1a.** Если пользователь не авторизован — система перенаправляет на страницу входа.
