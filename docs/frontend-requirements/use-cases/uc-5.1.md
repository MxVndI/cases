# UC-5.1: Просмотр профиля

**Эпик:** [Epic 5: Профиль пользователя](../epics/epic-05-profile.md)

## Описание

Просмотр пользователем информации о своём аккаунте, инвентаре, истории и настройках на странице `/profile` с 4 вкладками.

## Акторы

- **Основной:** Пользователь
- **Вторичный:** User Service (API), Cases Service (API)

## Предусловия

- Пользователь авторизован.

## Основной сценарий

1. Пользователь переходит на маршрут `/profile` (через меню в хедере).
2. Система отображает карточку профиля (аватар, никнейм, email, дата регистрации) и 4 вкладки.
3. **Вкладка «Обзор» (по умолчанию):**
   - Количество предметов в инвентаре и их суммарная стоимость (CHC).
   - Количество открытых кейсов.
   - Последние 3 выигрыша с карточками предметов.
4. **Вкладка «Инвентарь»:**
   - Сетка карточек предметов с фильтрами.
   - Кнопки «Продать» и «Продать всё» (см. UC-4.1).
5. **Вкладка «История»:**
   - Список открытий кейсов с датой, названием кейса и выпавшим предметом.
6. **Вкладка «Настройки»:**
   - Редактирование никнейма (см. UC-5.2).
   - Настройки интерфейса (см. UC-5.3).
7. Пользователь переключается между вкладками, система отображает соответствующее содержимое.

## Постусловия

- Пользователь просмотрел актуальные данные о своём аккаунте.

## Альтернативные потоки

- **1a.** Если пользователь не авторизован — защищённый маршрут `_protected` перенаправляет на `/login`.
