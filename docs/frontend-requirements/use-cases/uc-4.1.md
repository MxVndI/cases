# UC-4.1: Продажа предмета

**Эпик:** [Epic 4: Инвентарь и баланс](../epics/epic-04-inventory-balance.md)

## Описание

Процесс конвертации предмета из инвентаря в CaseHubCoin.

## Акторы

- **Основной:** Пользователь
- **Вторичный:** Сервис баланса

## Предусловия

- Пользователь авторизован.
- В инвентаре есть хотя бы один предмет.

## Основной сценарий

1. Пользователь открывает инвентарь (вкладка «Инвентарь» в личном кабинете).
2. Пользователь нажимает кнопку «Продать» на карточке предмета.
3. Система отображает подтверждение с указанием суммы.
4. Пользователь подтверждает продажу.
5. Система удаляет предмет из инвентаря.
6. Система зачисляет стоимость предмета на баланс.
7. Карточка предмета исчезает с анимацией.
8. Суммарная стоимость инвентаря пересчитывается.

## Постусловия

- Предмет удалён из инвентаря.
- Баланс увеличен на стоимость предмета.

## Альтернативные потоки

- **3a.** Пользователь нажимает отмену — подтверждение закрывается, предмет остаётся в инвентаре.
- **3b.** Пользователь нажимает «Продать» на другом предмете — предыдущее подтверждение сбрасывается, открывается новое.
