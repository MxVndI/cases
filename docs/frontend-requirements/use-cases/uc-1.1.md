# UC-1.1: Просмотр кейсов

**Эпик:** [Epic 1: Просмотр контента](../epics/epic-01-browsing.md)

## Описание

Сценарий описывает просмотр каталога кейсов на главной странице `/` любым посетителем (гость, пользователь, администратор) без необходимости авторизации.

## Акторы

- **Основной:** Гость (или Пользователь, или Администратор)
- **Вторичный:** Cases Service (API), SSE-канал последних выигрышей

## Предусловия

- Посетитель открыл сайт CaseHub.
- В системе существует хотя бы один кейс.

## Основной сценарий

1. Посетитель открывает маршрут `/` (главная страница).
2. Система устанавливает SSE-соединение и отображает живую ленту последних выигрышей (бегущая строка).
3. Система загружает список кейсов из Cases Service и отображает сетку карточек кейсов.
4. Посетитель использует панель фильтров: сортировка по цене (возрастание/убывание), фильтр по редкости, фильтр по тегам.
5. Если посетитель — администратор, дополнительно доступен фильтр по статусу кейса (активный/неактивный).
6. Система фильтрует и отображает карточки кейсов, соответствующие выбранным фильтрам.
7. Посетитель нажимает на карточку кейса.
8. Система выполняет переход на маршрут `/cases/$caseId` — страницу деталей кейса с полным списком предметов.

## Постусловия

- Посетитель ознакомился с доступными кейсами и их содержимым.
- SSE-соединение активно, пока пользователь на главной странице.

## Альтернативные потоки

- **2a.** Ошибка SSE-соединения — лента выигрышей скрывается, каталог кейсов продолжает работать.
- **3a.** Если кейсы отсутствуют — система отображает пустое состояние с сообщением.
- **6a.** Если фильтры не дают результатов — система показывает сообщение «Ничего не найдено» и предлагает сбросить фильтры.
