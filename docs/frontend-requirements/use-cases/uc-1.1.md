# UC-1.1: Просмотр кейсов

**Эпик:** [Epic 1: Просмотр контента](../epics/epic-01-browsing.md)

## Описание

Сценарий описывает просмотр доступных кейсов гостем без необходимости регистрации.

## Акторы

- **Основной:** Гость
- **Вторичный:** Система отображения контента

## Предусловия

- Гость находится на сайте CaseHub.
- В системе существует хотя бы один кейс.

## Основной сценарий

1. Гость открывает главную страницу сайта.
2. Система отображает конвейер последних выигрышей и сетку всех доступных кейсов.
3. Гость может использовать фильтры для сужения выборки кейсов.
4. Гость нажимает на карточку кейса.
5. Система отображает страницу деталей кейса с полным списком предметов.

## Постусловия

- Гость ознакомился с доступными кейсами и их содержимым.

## Альтернативные потоки

- **2a.** Если кейсы отсутствуют — система отображает пустое состояние.
- **3a.** Если фильтры не дают результатов — система показывает сообщение «Ничего не найдено» и предлагает сбросить фильтры.
