# Epic 1: Просмотр контента

**Описание:** Пользователь (включая гостя) может просматривать доступные кейсы на главной странице, изучать содержимое конкретного кейса и смотреть публичные профили других игроков. Главная страница включает SSE-ленту последних выигрышей (автообновление в реальном времени), панель фильтров (диапазон цен, сортировка, редкость, тег; фильтр статуса для администраторов) и адаптивную сетку карточек кейсов. Администратор видит отключённые кейсы с бейджем «Отключен». Это основной путь знакомства с платформой до регистрации.

**Роли:** Гость, Пользователь, Администратор  
**Связанные маршруты:** `/` (главная + каталог), `/cases/$caseId` (детали кейса), `/user/$userName` (профиль игрока)
