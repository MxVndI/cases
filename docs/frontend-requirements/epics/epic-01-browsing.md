# Epic 1: Просмотр контента

**Описание:** Пользователь (включая гостя) может просматривать доступные кейсы на главной странице, в каталоге, изучать содержимое конкретного кейса и смотреть публичные профили других игроков. Это основной путь знакомства с платформой до регистрации.

**Роли:** Гость, Пользователь, Администратор  
**Связанные маршруты:** `/`, `/cases`, `/cases/$caseId`, `/user/$userId`
