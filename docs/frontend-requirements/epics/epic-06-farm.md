# Epic 6: Ферма (кликер)

**Описание:** Пользователь может зарабатывать CaseHubCoin через мини-игру — кликер. Нажимая на кнопку, пользователь получает монеты. Заработанные монеты можно вкладывать в улучшения, которые увеличивают доход за клик, добавляют автоматический заработок и множитель. Прогресс сохраняется между сессиями.

**Роли:** Пользователь  
**Связанные маршруты:** `/farm`
