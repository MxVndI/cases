# Epic 6: Ферма (кликер)

**Описание:** Пользователь может зарабатывать CHC (CaseHubCoin) через мини-игру — кликер. Нажимая на центральную кнопку-монету, пользователь получает CHC. Клики отправляются на сервер батчами каждые 1.5 секунды через `farmApi.tap`. Заработанные монеты можно вкладывать в 4 улучшения: Click Power (сила клика), Multiplier (множитель), Auto-Clicker (автокликер), Auto-Speed (скорость автокликера). Прогресс синхронизируется с сервером (`farmApi.syncFarm`), поддерживается офлайн-заработок. Накопленные монеты собираются через `farmApi.claimFarm` (макс. накопление 1000 CHC). Статистика отображается в сетке из 4 плиток.

**Роли:** Пользователь  
**Связанные маршруты:** `/farm`
