# Epic 3: Открытие кейсов

**Описание:** Авторизованный пользователь может открывать кейсы прямо на странице деталей (`/cases/$caseId`), получая случайные предметы. Рулетка содержит 60 слотов с анимацией прокрутки 5 секунд (cubic-bezier), центральным маркером и выигрышным предметом на позиции 50. После остановки отображается полноэкранный оверлей с результатом и эффектом разлёта частиц (particle burst). Поддерживается мульти-открытие (x3, x5). Пользователь может продать или забрать выигранные предметы.

**Роли:** Пользователь  
**Связанные маршруты:** `/cases/$caseId` (открытие на странице деталей кейса)  
**Зависимости:** [Epic 1: Просмотр контента](epic-01-browsing.md) — пользователь сначала выбирает кейс из каталога.
