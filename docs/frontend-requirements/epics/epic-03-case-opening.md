# Epic 3: Открытие кейсов

**Описание:** Авторизованный пользователь может открывать кейсы, получая случайные предметы. Поддерживается одиночное открытие с анимацией рулетки, а также мульти-открытие (x3, x5). После открытия пользователь видит результат и может продать полученный предмет или оставить его в инвентаре.

**Роли:** Пользователь  
**Связанные маршруты:** `/cases/$caseId`  
**Зависимости:** [Epic 1: Просмотр контента](epic-01-browsing.md) — пользователь сначала выбирает кейс из каталога.
