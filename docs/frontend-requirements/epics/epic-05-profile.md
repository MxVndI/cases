# Epic 5: Профиль пользователя

**Описание:** Авторизованный пользователь может просматривать свой личный кабинет с четырьмя вкладками: Обзор (статистика инвентаря, открытые кейсы, последние 3 выигрыша), Инвентарь (фильтруемая сетка с продажей), История (полная история выигрышей) и Настройки (редактирование никнейма с подтверждением по OTP, настройки интерфейса). Паролей нет — авторизация через OTP-код. Страница защищена — неавторизованные пользователи перенаправляются на страницу входа.

**Роли:** Пользователь, Администратор  
**Связанные маршруты:** `/profile` (защищённый)  
**Зависимости:** [Epic 4: Инвентарь и баланс](epic-04-inventory-balance.md) — вкладка «Инвентарь» описана в Epic 4.
