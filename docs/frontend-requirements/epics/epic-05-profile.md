# Epic 5: Профиль пользователя

**Описание:** Авторизованный пользователь может просматривать свой личный кабинет с несколькими вкладками: обзор (статистика), история открытий, инвентарь и настройки (редактирование профиля, смена пароля). Страница защищена — неавторизованные пользователи перенаправляются на страницу входа.

**Роли:** Пользователь, Администратор  
**Связанные маршруты:** `/profile` (защищённый)  
**Зависимости:** [Epic 4: Инвентарь и баланс](epic-04-inventory-balance.md) — вкладка «Инвентарь» описана в Epic 4.

> **Текущее состояние:** Данные профиля читаются из `AuthContext` (мок-режим, `localStorage`). При интеграции с бэкендом редактирование отправляет `PATCH /api/user/v1/users/me` с `{email, nickname}` (эндпоинт в разработке). Смена пароля несовместима с текущей архитектурой бэкенда (вход через email-код), применима только в мок-режиме.
