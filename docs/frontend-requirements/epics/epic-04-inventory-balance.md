# Epic 4: Инвентарь и баланс

**Описание:** Авторизованный пользователь может просматривать свой баланс, статистику доходов и расходов, а также управлять инвентарём — просматривать полученные предметы, фильтровать их и продавать за CaseHubCoin.

**Роли:** Пользователь  
**Связанные маршруты:** `/balance`, `/profile` (вкладка «Инвентарь»)  
**Зависимости:** [Epic 3: Открытие кейсов](epic-03-case-opening.md) — предметы попадают в инвентарь после открытия кейса.

> **Интеграция с бэкендом:**
> - **Баланс** управляется отдельным Rust-сервисом (Payment Service): `GET /payment/balance/{user_id}` → `{wallet: {RUB, USD, EUR}}`, `GET /payment/transaction/{user_id}` → история транзакций.
> - **Инвентарь** — бэкенд пока не реализован (Epic B4 в разработке). Фронтенд использует мок-данные.
> - **Продажа предметов** — бэкенд не реализован.
