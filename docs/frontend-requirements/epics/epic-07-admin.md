# Epic 7: Администрирование

**Описание:** Администратор имеет доступ к панели управления, где может просматривать и управлять пользователями (блокировка/разблокировка, поиск, фильтрация) и кейсами (создание, редактирование, удаление). Доступ к панели ограничен — обычные пользователи видят экран «Доступ запрещён», а гости перенаправляются на страницу входа.

**Роли:** Администратор  
**Связанные маршруты:** `/admin` (защищённый)
