# Epic 7: Администрирование

**Описание:** Администратор имеет доступ к панели управления с 5 вкладками: Пользователи (поиск, фильтрация, блокировка/разблокировка), Кейсы (полный CRUD с выбором предметов, редактором шансов, авторасчётом цены, загрузкой изображений в S3/RustFS, селектором тегов, автогенерацией system_name), Предметы (полный CRUD с привязкой к редкости и оружию), Редкости (CRUD редкостей и тегов), Оружие (CRUD типов оружия и оружий). Доступ ограничен — обычные пользователи видят экран «Доступ запрещён», гости перенаправляются на страницу входа.

**Роли:** Администратор  
**Связанные маршруты:** `/admin` (защищённый)
