# Epic 2: Регистрация и авторизация

**Описание:** Гость может создать аккаунт (регистрация) или войти в существующий (авторизация), чтобы получить доступ к функциональности, недоступной без авторизации: открытие кейсов, управление инвентарём, ферма, профиль. Поддерживается вход по email/паролю и через OAuth-провайдеры (Discord, Яндекс).

**Роли:** Гость  
**Связанные маршруты:** `/login`, `/register`
