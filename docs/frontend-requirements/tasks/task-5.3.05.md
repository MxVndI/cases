# TASK-5.3.05

**Название:** Блокировать кнопку во время сохранения  
**Эпик:** [Epic 5: Профиль пользователя](../epics/epic-05-profile.md)  
**User Story:** [US-5.3: Редактирование профиля](../user-stories/us-5.3.md)  
**Статус:** Не начата  
**Исполнитель:** Иван Бачурин

## Описание

Во время отправки данных на сервер заблокировать кнопку «Сохранить» для предотвращения повторных отправок.

## Детали реализации

- Кнопка disabled и показывает спиннер при отправке
- Разблокировать после получения ответа (или таймаута)

## Критерии приёмки

1. Кнопка заблокирована во время сохранения
2. Спиннер виден в кнопке
