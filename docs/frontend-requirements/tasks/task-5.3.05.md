# TASK-5.3.05

**Название:** Блокировать кнопку «Сохранить» во время API-запросов и OTP-верификации  
**Эпик:** [Epic 5: Профиль пользователя](../epics/epic-05-profile.md)  
**User Story:** [US-5.3: Редактирование профиля](../user-stories/us-5.3.md)  
**Статус:** Не начата  
**Исполнитель:** Иван Бачурин

## Описание

Во время отправки `POST /api/user/profile/update/start` и во время OTP-верификации (`POST /api/user/profile/update/finish`) блокировать кнопку «Сохранить» и кнопку «Подтвердить» в диалоге.

## Детали реализации

- Кнопка «Сохранить»: disabled + спиннер при отправке start-запроса
- Кнопка «Подтвердить» в OTP-диалоге: disabled + спиннер при отправке finish-запроса
- Разблокировать после получения ответа (или ошибки)

## Критерии приёмки

1. Кнопка «Сохранить» заблокирована во время запроса
2. Кнопка «Подтвердить» заблокирована при OTP-верификации
3. Спиннер виден в кнопках при загрузке
