# TASK-5.1.05

**Название:** Реализовать блок последних выигрышей (3 записи)  
**Эпик:** [Epic 5: Профиль пользователя](../epics/epic-05-profile.md)  
**User Story:** [US-5.1: Просмотр обзора профиля](../user-stories/us-5.1.md)  
**Статус:** Не начата  
**Исполнитель:** Иван Бачурин

## Описание

На вкладке «Обзор» показать последние 3 выигрыша пользователя в компактном виде.

## Детали реализации

- Список из максимум 3 записей
- Каждая: предмет (иконка + название), кейс, дата
- Цветовая маркировка по редкости
- Ссылка «Посмотреть все» → вкладка «История»

## Критерии приёмки

1. Отображаются последние 3 выигрыша
2. Ссылка на полную историю работает
