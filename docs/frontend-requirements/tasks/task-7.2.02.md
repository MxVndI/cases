# TASK-7.2.02

**Название:** Скрыть кнопку для пользователей с ролью admin  
**Эпик:** [Epic 7: Администрирование](../epics/epic-07-admin.md)  
**User Story:** [US-7.2: Блокировка и разблокировка пользователей](../user-stories/us-7.2.md)  
**Статус:** Не начата  
**Исполнитель:** Максим Небывалов

## Описание

Кнопка блокировки/разблокировки не должна отображаться для пользователей с ролью admin — администратоов нельзя блокировать.

## Детали реализации

- Проверить роль пользователя
- Если role = admin — не рендерить кнопку

## Критерии приёмки

1. Кнопка блокировки не видна для администраторов
