# TASK-7.8.02: Диалог создания/редактирования предмета

**User Story:** [US-7.8: CRUD предметов](../user-stories/us-7.8.md)

## Описание

Реализовать модальный диалог для создания и редактирования предмета. Поля формы: название (обязательно), цена в CHC (обязательно, число), изображение (загрузка через `adminApi.uploadImage` на S3/RustFS, до 5 МБ, png/jpeg/webp/gif), селектор редкости (из справочника `adminApi.getRarities`), селектор оружия (из справочника `adminApi.getWeapons`). При редактировании — форма предзаполнена текущими данными. Сохранение: `adminApi.createItem` / `adminApi.updateItem`.

## Критерии приёмки

- [ ] Диалог открывается по кнопке «Добавить предмет» и по кнопке «Редактировать» в строке предмета
- [ ] Все обязательные поля валидируются
- [ ] Изображение загружается на S3 и URL сохраняется
- [ ] Селекторы редкости и оружия подтягивают данные из API
- [ ] При редактировании форма предзаполнена
- [ ] После сохранения список обновляется, показывается тост
