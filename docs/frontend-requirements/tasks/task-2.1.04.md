# TASK-2.1.04

**Название:** Добавить навигационные ссылки (на главную и на страницу входа)  
**Эпик:** [Epic 2: Регистрация и авторизация](../epics/epic-02-auth.md)  
**User Story:** [US-2.1: Регистрация нового пользователя](../user-stories/us-2.1.md)

## Описание

Добавить на страницу регистрации ссылки для навигации: переход на главную страницу и на страницу входа для уже зарегистрированных пользователей.

## Детали реализации

- Добавить ссылку «Уже есть аккаунт? Войти» под формой, ведущую на `/login`
- Добавить ссылку или кнопку «На главную» для возврата на `/`
- Использовать компонент `<Link>` из TanStack Router

## Критерии приёмки

1. Ссылка «Войти» ведёт на `/login`
2. Ссылка на главную страницу работает корректно
3. Навигация осуществляется без перезагрузки страницы
