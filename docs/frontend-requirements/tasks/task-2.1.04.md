## Описание

Добавить на страницу регистрации ссылки для навигации: «Уже есть аккаунт?» на `/login` и ссылку на главную `/`.

## Детали реализации

- Ссылка «Уже есть аккаунт? Войти» под формой → `/login`
- Ссылка или кнопка «На главную» → `/`
- Использовать компонент `<Link>` из TanStack Router

## Критерии приёмки

1. Ссылка «Уже есть аккаунт? Войти» ведёт на `/login`
2. Ссылка на главную страницу работает корректно
3. Навигация осуществляется без перезагрузки страницы
