# TASK-4.1.04

**Название:** Реализовать список последних операций  
**Эпик:** [Epic 4: Инвентарь и баланс](../epics/epic-04-inventory-balance.md)  
**User Story:** [US-4.1: Просмотр баланса и статистики](../user-stories/us-4.1.md)  
**Статус:** Не начата  
**Исполнитель:** Данил Косенко

## Описание

Отобразить список последних финансовых операций пользователя: открытия кейсов, продажи предметов, начисления с фермы.

## Детали реализации

- Создать компонент списка транзакций
- Каждая запись: тип операции (иконка), описание, сумма (±), дата
- Зелёный цвет для доходов, красный для расходов
- Ограничить отображение 10-20 последними записями
- Пустое состояние при отсутствии операций

## Критерии приёмки

1. Список операций отображается на странице баланса
2. Доход и расход маркированы разными цветами
3. Операции содержат тип, описание, сумму и дату
