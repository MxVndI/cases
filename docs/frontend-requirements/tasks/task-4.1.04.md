# TASK-4.1.04

**Название:** Реализовать список последних операций  
**Эпик:** [Epic 4: Инвентарь и баланс](../epics/epic-04-inventory-balance.md)  
**User Story:** [US-4.1: Просмотр баланса и статистики](../user-stories/us-4.1.md)  
**Статус:** Не начата  
**Исполнитель:** Данил Косенко

## Описание

Отобразить список последних 10 транзакций пользователя с иконками типов, временными метками и суммами.

## Детали реализации

- Данные из `paymentApi.getTransactions` (последние 10 записей)
- Каждая запись содержит:
  - Иконка типа операции: farm (🌾), bonus (🎁), поступление (in), расход (out)
  - Временная метка (timestamp)
  - Сумма в CHC (±)
- Зелёный цвет для доходов, красный для расходов
- Пустое состояние при отсутствии операций

## Критерии приёмки

1. Список последних 10 транзакций отображается, данные из `paymentApi.getTransactions`
2. Иконки типов (farm/bonus/in/out), timestamps и суммы отображаются
3. Доход и расход маркированы разными цветами
