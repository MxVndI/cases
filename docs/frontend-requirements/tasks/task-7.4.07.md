# TASK-7.4.07

**Название:** Добавлять новый кейс в начало списка  
**Эпик:** [Epic 7: Администрирование](../epics/epic-07-admin.md)  
**User Story:** [US-7.4: Создание нового кейса](../user-stories/us-7.4.md)  
**Статус:** Не начата  
**Исполнитель:** Данил Косенко

## Описание

После успешного создания кейса отправить данные через `adminApi.createCase`, обновить список кейсов и показать toast-уведомление.

## Детали реализации

- POST запрос через `adminApi.createCase` с данными формы и выбранными предметами
- После успешного создания закрыть диалог
- Обновить (refresh) список кейсов на вкладке «Кейсы»
- Показать toast-уведомление об успешном создании (shadcn/ui Toast)
- При ошибке показать toast с описанием ошибки

## Критерии приёмки

1. Кейс создаётся через `adminApi.createCase`
2. Список кейсов обновляется после создания
3. Toast-уведомление появляется (успех/ошибка)
4. Диалог закрывается после успешного создания
