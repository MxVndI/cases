# TASK-7.4.07

**Название:** Добавлять новый кейс в начало списка  
**Эпик:** [Epic 7: Администрирование](../epics/epic-07-admin.md)  
**User Story:** [US-7.4: Создание нового кейса](../user-stories/us-7.4.md)  
**Статус:** Не начата  
**Исполнитель:** Данил Косенко

## Описание

После успешного создания кейса добавить его в начало списка на вкладке «Кейсы».

## Детали реализации

- Закрыть диалог после создания
- Добавить новый кейс в начало массива данных
- Обновить отображение списка
- Анимация появления нового элемента

## Критерии приёмки

1. Новый кейс появляется в начале списка
2. Диалог закрывается после создания
