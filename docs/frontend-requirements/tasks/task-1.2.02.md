# TASK-1.2.02

**Название:** Обеспечить переход на детали кейса при клике  
**Эпик:** [Epic 1: Просмотр контента](../epics/epic-01-browsing.md)  
**User Story:** [US-1.2: Просмотр каталога кейсов](../user-stories/us-1.2.md)  
**Статус:** Не начата  
**Исполнитель:** Иван Бачурин

## Описание

Реализовать навигацию с каталога на страницу деталей конкретного кейса. Клик по карточке должен направлять пользователя на маршрут `/cases/$caseId`.

## Детали реализации

- Обернуть карточку кейса в `<Link>` из TanStack Router с параметром `caseId`
- Передать ID кейса в параметр маршрута
- Обеспечить визуальную индикацию кликабельности (cursor: pointer)
- Навигация должна работать без перезагрузки страницы (SPA)

## Критерии приёмки

1. Клик по карточке навигирует на `/cases/{id}` без перезагрузки страницы
2. ID кейса корректно передаётся в параметр маршрута
3. Карточки визуально индицируют кликабельность
