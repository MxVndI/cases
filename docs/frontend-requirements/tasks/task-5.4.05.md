**Название:** Применять предпочтения по всему приложению  
**Эпик:** [Epic 5: Профиль пользователя](../epics/epic-05-profile.md)  
**User Story:** [US-5.4: Настройки предпочтений](../user-stories/us-5.4.md)  
**Статус:** Не начата  
**Исполнитель:** Иван Бачурин

## Описание

Предпочтения из `PreferencesContext` должны применяться в соответствующих компонентах: GSAP-курсор в `__root.tsx`, анимация CountUp в компоненте `CountUp`.

## Детали реализации

- В `__root.tsx`: читать `preferences.cursor` — если OFF, не рендерить кастомный курсор и восстановить стандартный
- В компоненте `CountUp`: читать `preferences.countup` — если OFF, показывать число статически без анимации
- Изменения применяются мгновенно без перезагрузки

## Критерии приёмки

1. Отключение курсора убирает GSAP-курсор, восстанавливает стандартный
2. Отключение CountUp показывает числа статически
3. Изменения применяются мгновенно по всему приложению
