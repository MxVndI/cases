# TASK-6.1.04

**Название:** Анимировать всплывающий текст «+N» при каждом клике  
**Эпик:** [Epic 6: Ферма (кликер)](../epics/epic-06-farm.md)  
**User Story:** [US-6.1: Заработок монет кликами](../user-stories/us-6.1.md)  
**Статус:** Не начата  
**Исполнитель:** Николай Сгонник

## Описание

При каждом клике показывать анимированные частицы «+N» (сумма начисления), которые всплывают от позиции клика вверх и исчезают.

## Детали реализации

- Использовать Framer Motion `AnimatePresence` для управления жизненным циклом частиц
- При клике создавать элемент-частицу «+N» в позиции курсора (координаты клика)
- Анимация частицы: всплытие вверх (float up) + fade-out
- Каждая частица имеет уникальный key для корректной работы `AnimatePresence`
- Поддерживать множественные одновременные частицы при быстрых кликах
- Частицы удаляются из DOM после завершения анимации (`onAnimationComplete`)

## Критерии приёмки

1. При каждом клике появляются частицы «+N» через `AnimatePresence`
2. Частицы всплывают вверх от позиции клика и плавно исчезают
3. Множественные быстрые клики генерируют множественные частицы корректно
