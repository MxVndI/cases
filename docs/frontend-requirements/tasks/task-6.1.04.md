# TASK-6.1.04

**Название:** Анимировать всплывающий текст «+N» при каждом клике  
**Эпик:** [Epic 6: Ферма (кликер)](../epics/epic-06-farm.md)  
**User Story:** [US-6.1: Заработок монет кликами](../user-stories/us-6.1.md)  
**Статус:** Не начата  
**Исполнитель:** Николай Сгонник

## Описание

При каждом клике показывать всплывающий текст с суммой начисления (например, «+5»), который плавно поднимается и исчезает.

## Детали реализации

- При клике на кнопку создавать элемент «+N» в позиции курсора (или над кнопкой)
- Анимация: подъём вверх на 50-100px + fade-out за 0.5-1 секунду
- Использовать Framer Motion или CSS-анимацию
- Поддерживать множественные одновременные анимации (быстрые клики)

## Критерии приёмки

1. При каждом клике появляется текст «+N»
2. Текст плавно поднимается и исчезает
3. Множественные быстрые клики обрабатываются корректно
