# TASK-3.1.05

**Название:** Реализовать полноэкранный оверлей с результатом открытия  
**Эпик:** [Epic 3: Открытие кейсов](../epics/epic-03-case-opening.md)  
**User Story:** [US-3.1: Одиночное открытие кейса](../user-stories/us-3.1.md)  
**Статус:** Не начата  
**Исполнитель:** Максим Небывалов

## Описание

После завершения анимации рулетки показать полноэкранный оверлей с информацией о выигранном предмете.

## Детали реализации

- Оверлей появляется после завершения анимации (onComplete callback)
- Содержит: крупное изображение предмета, название, редкость, стоимость
- Фон оверлея затемнён, цветовая подсветка по редкости
- Анимация появления: масштабирование + fade-in
- Использовать Framer Motion для анимации оверлея

## Критерии приёмки

1. Оверлей появляется после остановки рулетки
2. Отображаются: изображение, название, редкость и стоимость предмета
3. Анимация появления плавная
4. Фон затемнён
