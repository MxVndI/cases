# TASK-7.2.05

**Название:** Обновлять статус пользователя в списке после подтверждения  
**Эпик:** [Epic 7: Администрирование](../epics/epic-07-admin.md)  
**User Story:** [US-7.2: Блокировка и разблокировка пользователей](../user-stories/us-7.2.md)  
**Статус:** Не начата  
**Исполнитель:** Максим Небывалов

## Описание

После подтверждения блокировки/разблокировки обновить статус пользователя в списке без перезагрузки.

## Детали реализации

- Обновить поле status в массиве пользователей
- Обновить бейдж статуса в строке пользователя
- Обновить текст кнопки (блокировать ↔ разблокировать)
- Закрыть диалог

## Критерии приёмки

1. Статус обновляется мгновенно в списке
2. Бейдж и кнопка корректно меняются
3. Диалог закрывается
