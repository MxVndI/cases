# TASK-6.3.01

**Название:** Реализовать таймер автоматического начисления  
**Эпик:** [Epic 6: Ферма (кликер)](../epics/epic-06-farm.md)  
**User Story:** [US-6.3: Автоматический заработок](../user-stories/us-6.3.md)  
**Статус:** Не начата  
**Исполнитель:** Николай Сгонник

## Описание

Реализовать пассивное автоматическое начисление монет через setInterval, работающее пока страница фермы открыта.

## Детали реализации

- Запускать setInterval при монтировании компонента фермы
- Интервал: 1 секунда
- Начислять доход_в_секунду на каждом тике
- Очищать interval при размонтировании компонента

## Критерии приёмки

1. Монеты начисляются автоматически каждую секунду
2. Начисление корректное (соответствует рассчитанному доходу/с)
3. Таймер очищается при уходе со страницы
