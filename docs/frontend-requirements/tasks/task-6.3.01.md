# TASK-6.3.01

**Название:** Реализовать таймер автоматического начисления  
**Эпик:** [Epic 6: Ферма (кликер)](../epics/epic-06-farm.md)  
**User Story:** [US-6.3: Автоматический заработок](../user-stories/us-6.3.md)  
**Статус:** Не начата  
**Исполнитель:** Николай Сгонник

## Описание

Реализовать автоматическое начисление монет на основе уровней `auto_clicker_level` и `speed_level`. Заработанные монеты накапливаются в pending bank.

## Детали реализации

- Автокликер работает на основе `auto_clicker_level` и `speed_level`
- Интервал срабатывания зависит от `speed_level`
- Начисленные монеты накапливаются в pending bank (ожидающий банк)
- Пользователь забирает накопленное через `farmApi.claimFarm`
- Очищать interval при размонтировании компонента

## Критерии приёмки

1. Автокликер начисляет монеты в pending bank на основе `auto_clicker_level` и `speed_level`
2. Начисление корректное
3. Таймер очищается при уходе со страницы
