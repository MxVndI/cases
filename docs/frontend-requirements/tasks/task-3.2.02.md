# TASK-3.2.02

**Название:** Реализовать мгновенное завершение анимации с корректной позицией рила  
**Эпик:** [Epic 3: Открытие кейсов](../epics/epic-03-case-opening.md)  
**User Story:** [US-3.2: Пропуск анимации](../user-stories/us-3.2.md)  
**Статус:** Не начата  
**Исполнитель:** Максим Небывалов

## Описание

При нажатии «Пропустить» анимация рила мгновенно завершается, рил перемещается на итоговую позицию (выигрышный предмет по центру).

## Детали реализации

- При клике на «Пропустить» остановить текущую анимацию Framer Motion
- Мгновенно установить итоговый offset (позиция 50 по центру)
- Гарантировать, что выигрышный предмет по центру указателя
- Вызвать onComplete callback для показа оверлея результата

## Критерии приёмки

1. Рил мгновенно перемещается на финальную позицию
2. Выигрышный предмет по центру
3. Оверлей результата появляется
