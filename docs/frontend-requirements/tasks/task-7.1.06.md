# TASK-7.1.06

**Название:** Сделать никнейм ссылкой на профиль пользователя  
**Эпик:** [Epic 7: Администрирование](../epics/epic-07-admin.md)  
**User Story:** [US-7.1: Просмотр списка пользователей](../user-stories/us-7.1.md)  
**Статус:** Не начата  
**Исполнитель:** Максим Небывалов

## Описание

В списке пользователей сделать никнейм кликабельной ссылкой, ведущей на публичный профиль пользователя.

## Детали реализации

- Обернуть никнейм в `<Link to="/user/$userId">`
- Стилизовать как ссылку: underline при наведении, синий/акцентный цвет

## Критерии приёмки

1. Никнейм кликабелен и ведёт на `/user/{userId}`
2. Стилизация ссылки заметна
