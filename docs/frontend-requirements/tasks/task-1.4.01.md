# TASK-1.4.01

**Название:** Реализовать карточку профиля с аватаром, никнеймом и датой регистрации  
**Эпик:** [Epic 1: Просмотр контента](../epics/epic-01-browsing.md)  
**User Story:** [US-1.4: Просмотр профиля другого игрока](../user-stories/us-1.4.md)  
**Статус:** Не начата  
**Исполнитель:** Иван Бачурин

## Описание

Создать компонент карточки профиля для страницы публичного профиля пользователя (`/user/$userId`). Карточка отображает основную информацию: аватар, никнейм и дату регистрации.

## Детали реализации

- Извлечь `userId` из параметров маршрута
- Найти пользователя в dummy-data по ID
- Отобразить аватар (заглушка или первая буква никнейма), никнейм, дату регистрации
- Стилизовать карточку: тёмный фон, скруглённые углы, тень
- Дата форматируется в читаемый формат (например, `12 мая 2024`)

## Критерии приёмки

1. Карточка отображает аватар (или заглушку), никнейм и дату регистрации
2. Данные корректно загружаются по `userId` из маршрута
3. Дата форматирована в читаемый вид
4. Стиль карточки соответствует общему дизайну платформы
