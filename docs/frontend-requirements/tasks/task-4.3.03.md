## Описание

Добавить фильтр по редкости предметов с возможностью мультивыбора (чекбоксы для каждого уровня редкости).

## Детали реализации

- Чекбоксы: common, rare, epic, legendary, exotic
- Мультивыбор — фильтрация по OR (показывать все выбранные)
- Цветовые индикаторы рядом с чекбоксами
- Без выбора — показать все предметы

## Критерии приёмки

1. Фильтр по редкости работает с мультивыбором
2. Цветовые индикаторы корректны
3. Без выбора отображаются все предметы
