# TASK-7.6.01

**Название:** Реализовать диалог подтверждения удаления  
**Эпик:** [Epic 7: Администрирование](../epics/epic-07-admin.md)  
**User Story:** [US-7.6: Удаление кейса](../user-stories/us-7.6.md)  
**Статус:** Не начата  
**Исполнитель:** Данил Косенко

## Описание

При нажатии «Удалить» показать диалог подтверждения с предупреждением о необратимости действия.

## Детали реализации

- Dialog из shadcn/ui
- Текст: «Вы уверены, что хотите удалить кейс {название}? Это действие нельзя отменить.»
- Кнопки «Удалить» (красная) и «Отмена»

## Критерии приёмки

1. Диалог подтверждения появляется
2. Предупреждение о необратимости
