# TASK-4.4.03

**Название:** Анимировать исчезновение проданного предмета из сетки  
**Эпик:** [Epic 4: Инвентарь и баланс](../epics/epic-04-inventory-balance.md)  
**User Story:** [US-4.4: Продажа предмета из инвентаря](../user-stories/us-4.4.md)  
**Статус:** Не начата  
**Исполнитель:** Данил Косенко

## Описание

После успешной продажи предмет плавно исчезает из сетки инвентаря с анимацией.

## Детали реализации

- Использовать Framer Motion `AnimatePresence` + `exit`-анимацию
- Анимация: fade-out + scale-down или slide-out
- Остальные карточки сдвигаются, заполняя пустое место
- Анимация длится 300-500ms

## Критерии приёмки

1. Проданный предмет исчезает с анимацией
2. Остальные карточки сдвигаются на место проданного
3. Анимация плавная и не приводит к рывкам
