**Исполнитель:** Николай Сгонник

## Описание

Создать страницу фермы (`/farm`) с центральной интерактивной кнопкой, нажатие на которую генерирует монеты.

## Детали реализации

- Создать страницу-компонент для маршрута `/farm`
- Центральная кнопка: крупная, круглая, с иконкой монеты
- Масштабирование при нажатии (animation: scale down → up)
- Тактильный эффект: лёгкое уменьшение при mousedown, возврат при mouseup
- Кнопка доступна только для авторизованных пользователей

## Критерии приёмки

1. Кнопка кликера крупная и заметная по центру страницы
2. Анимация нажатия работает
3. Кнопка реагирует на клики
