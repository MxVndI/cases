# TASK-6.1.01

**Название:** Реализовать центральную кнопку кликера  
**Эпик:** [Epic 6: Ферма (кликер)](../epics/epic-06-farm.md)  
**User Story:** [US-6.1: Заработок монет кликами](../user-stories/us-6.1.md)  
**Статус:** Не начата  
**Исполнитель:** Николай Сгонник

## Описание

Создать страницу фермы (`/farm`) с центральной интерактивной кнопкой 48×48 округлой формы оранжевого цвета. При нажатии кнопка воспроизводит анимацию масштабирования (motion scale effect).

## Детали реализации

- Создать страницу-компонент для маршрута `/farm`
- Центральная кнопка: 48×48, круглая, оранжевый цвет (accent)
- Анимация нажатия через Framer Motion: `whileTap={{ scale: 0.9 }}` — эффект motion scale при клике
- Иконка монеты внутри кнопки
- Кнопка доступна только для авторизованных пользователей

## Критерии приёмки

1. Кнопка кликера 48×48 округлая оранжевая по центру страницы
2. При клике срабатывает motion scale-анимация (сжатие → возврат)
3. Кнопка реагирует на клики и визуально отзывчива
