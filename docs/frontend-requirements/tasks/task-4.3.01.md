# TASK-4.3.01

**Название:** Реализовать раскрывающуюся панель фильтров с анимацией  
**Эпик:** [Epic 4: Инвентарь и баланс](../epics/epic-04-inventory-balance.md)  
**User Story:** [US-4.3: Фильтрация и сортировка инвентаря](../user-stories/us-4.3.md)  
**Статус:** Не начата  
**Исполнитель:** Данил Косенко

## Описание

Создать раскрывающуюся панель фильтров для инвентаря с плавной анимацией открытия/закрытия.

## Детали реализации

- Кнопка «Фильтры» с иконкой, раскрывающая/сворачивающая панель
- Анимация раскрытия — Framer Motion `AnimatePresence`
- Панель содержит элементы управления фильтрами
- Плавная анимация высоты

## Критерии приёмки

1. Панель раскрывается/сворачивается с плавной анимацией
2. Кнопка переключает состояние панели
