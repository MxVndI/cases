## Описание

Добавить блок статистики в профиль пользователя, показывающий ключевые метрики: текущий баланс и количество открытых кейсов.

## Детали реализации

- Создать компонент статистики под карточкой профиля
- Отобразить: баланс в CaseHubCoin, общее количество открытых кейсов
- Использовать иконки из Lucide React для наглядности
- Числа форматировать с разделителями тысяч при необходимости

## Критерии приёмки

1. Блок статистики отображает баланс и количество открытых кейсов
2. Значения корректно берутся из данных пользователя
3. Числа форматированы и читаемы
