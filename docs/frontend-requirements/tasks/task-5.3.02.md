# TASK-5.3.02

**Название:** Предзаполнить поля текущими данными  
**Эпик:** [Epic 5: Профиль пользователя](../epics/epic-05-profile.md)  
**User Story:** [US-5.3: Редактирование профиля](../user-stories/us-5.3.md)  
**Статус:** Не начата  
**Исполнитель:** Иван Бачурин

## Описание

При загрузке формы предзаполнить поля текущими значениями никнейма и email пользователя.

## Детали реализации

- Получить данные из AuthContext
- Установить defaultValue/value для полей
- Управляемые поля (controlled) для отслеживания изменений

## Критерии приёмки

1. Поля предзаполнены текущими данными
2. Пользователь может изменить значения
