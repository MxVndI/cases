# TASK-5.3.02

**Название:** Предзаполнить поля текущими данными из контекста пользователя  
**Эпик:** [Epic 5: Профиль пользователя](../epics/epic-05-profile.md)  
**User Story:** [US-5.3: Редактирование профиля](../user-stories/us-5.3.md)  
**Статус:** Не начата  
**Исполнитель:** Иван Бачурин

## Описание

При загрузке формы предзаполнить поле никнейма текущим значением из `AuthContext` (данные `GET /api/auth/me`). Поле email также заполняется из контекста (только чтение).

## Детали реализации

- Получить данные пользователя из `AuthContext` (`user.nickname`, `user.email`)
- Установить `defaultValue`/`value` для поля никнейма
- Управляемое поле (controlled) для отслеживания изменений
- Email показывается информативно (readOnly)

## Критерии приёмки

1. Никнейм предзаполнен текущим значением
2. Email предзаполнен и недоступен для редактирования
3. Пользователь может изменить никнейм
