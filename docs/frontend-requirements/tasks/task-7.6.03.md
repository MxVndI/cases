# TASK-7.6.03

**Название:** Удалить кейс из списка после подтверждения  
**Эпик:** [Epic 7: Администрирование](../epics/epic-07-admin.md)  
**User Story:** [US-7.6: Удаление кейса](../user-stories/us-7.6.md)  
**Статус:** Не начата  
**Исполнитель:** Данил Косенко

## Описание

После подтверждения удаления убрать кейс из списка с анимацией.

## Детали реализации

- Удалить кейс из массива данных
- Анимация исчезновения (Framer Motion exit)
- Закрыть диалог

## Критерии приёмки

1. Кейс исчезает из списка с анимацией
2. Диалог закрывается
