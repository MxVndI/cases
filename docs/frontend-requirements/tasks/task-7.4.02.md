## Описание

В диалоге создания кейса реализовать форму: name, system_name (автогенерация), price в CHC, селектор тегов, статус.

## Детали реализации

- Поле **name** — text input, название кейса
- Поле **system_name** — автоматически генерируется из name (slug-формат), редактируемое
- Поле **price** — number input, цена в CHC
- **Tag selector** — выбор тегов из списка (multi-select)
- **Status** — select: active / disabled
- Использовать компоненты shadcn/ui

## Критерии приёмки

1. Форма содержит поля: name, system_name, price, tag selector, status
2. system_name автоматически генерируется из name
3. Поля имеют корректные типы и подписи
