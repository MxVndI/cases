## Описание

В диалоге создания кейса реализовать форму с полями: название, цена (в CaseHubCoin), описание, категория.

## Детали реализации

- Поле «Название» — text input
- Поле «Цена» — number input
- Поле «Описание» — textarea
- Поле «Категория» — select из предопределённых вариантов
- Использовать компоненты shadcn/ui

## Критерии приёмки

1. Форма содержит все 4 поля
2. Поля имеют корректные типы и подписи
