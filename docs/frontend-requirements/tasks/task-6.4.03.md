# TASK-6.4.03

**Название:** Обрабатывать случай отсутствия сохранённых данных (первый вход)  
**Эпик:** [Epic 6: Ферма (кликер)](../epics/epic-06-farm.md)

**Статус:** Не начата

## Описание

Если в localStorage нет сохранённых данных (первый визит), инициализировать ферму значениями по умолчанию.

## Детали реализации

- Проверить наличие ключа в localStorage
- Если отсутствует — установить значения по умолчанию: баланс = 0, все уровни = 0
- Сохранить начальное состояние

## Критерии приёмки

1. Первый визит на ферму не вызывает ошибок
2. Баланс и уровни инициализированы нулями
