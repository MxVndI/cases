# TASK-6.4.03

**Название:** Обрабатывать случай первого визита (серверная инициализация)  
**Эпик:** [Epic 6: Ферма (кликер)](../epics/epic-06-farm.md)  
**User Story:** [US-6.4: Сохранение прогресса](../user-stories/us-6.4.md)  
**Статус:** Не начата  
**Исполнитель:** Николай Сгонник

## Описание

При первом визите пользователя на ферму сервер автоматически создаёт дефолтное состояние фермы (все значения = 0). Фронтенд получает эти данные через `farmApi.syncFarm`.

## Детали реализации

- Сервер создаёт дефолтное состояние для новых пользователей: баланс = 0, все уровни = 0
- Фронтенд получает дефолтное состояние через `farmApi.syncFarm` как обычно
- Не требуется специальной обработки на клиенте — логика на сервере

## Критерии приёмки

1. Первый визит на ферму не вызывает ошибок
2. Баланс и уровни инициализированы нулями (серверный дефолт)
