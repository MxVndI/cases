## Описание

Если после применения фильтров/поиска нет подходящих пользователей, показать информативное сообщение.

## Детали реализации

- Проверить пустоту отфильтрованного списка
- Показать: «Нет пользователей по заданным критериям»
- Кнопка «Сбросить фильтры»

## Критерии приёмки

1. Пустое состояние отображается при отсутствии результатов
2. Предлагается сброс фильтров
