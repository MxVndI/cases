# TASK-2.2.03

**Название:** Реализовать отправку данных и обработку ответа (успех/ошибка)  
**Эпик:** [Epic 2: Регистрация и авторизация](../epics/epic-02-auth.md)  
**User Story:** [US-2.2: Авторизация по email и паролю](../user-stories/us-2.2.md)  
**Статус:** Не начата  
**Исполнитель:** Николай Сгонник

## Описание

Реализовать логику отправки данных формы входа и обработку ответа.

## Детали реализации

**Текущее (мок-режим):**
- Установить состояние авторизации: `mockAuth.login(email, password)` — никнейм из email, баланс по умолчанию
- Вызвать `refetchUser()` для обновления `AuthContext`
- Перенаправить на главную
- При ошибке: отобразить сообщение «Неверный email или пароль»
- Добавить индикатор загрузки на кнопку

**При интеграции с реальным бэкендом (еmail-код):**
- Отправить `POST /api/auth/email/login/start` с `{email}` — бэкенд устанавливает cookies `email` + `cvid` и отправляет 6-символьный код на почту
- Перенаправить на страницу ввода кода (6 символов, TTL 10 мин)
- Отправить `POST /api/auth/email/login/finish` с `{code}` — бэкенд проверяет код и устанавливает cookie `sid`
- Бэкенд перенаправляет на `/welcome`, фронтенд считывает `GET /api/auth/me` и обновляет `AuthContext`
- Паролей бэкенд не использует — поле пароля в текущей версии только для мока

## Критерии приёмки

1. При корректных данных пользователь авторизуется
2. При некорректных данных отображается сообщение об ошибке
3. Кнопка блокируется и показывает индикатор при отправке
