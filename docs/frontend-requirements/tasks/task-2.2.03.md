# TASK-2.2.03

**Название:** Реализовать шаг 2 входа — 6-значный OTP-код и кнопка «Войти»  
**Эпик:** [Epic 2: Регистрация и авторизация](../epics/epic-02-auth.md)  
**User Story:** [US-2.2: Авторизация по email](../user-stories/us-2.2.md)  
**Статус:** Не начата  
**Исполнитель:** Николай Сгонник

## Описание

После отправки email (шаг 1) отобразить шаг 2: ввод 6-значного OTP-кода и кнопка «Войти». При нажатии отправляется `POST /api/auth/email/login/finish` с `{code}`. Бэкенд проверяет код и устанавливает cookie `sid`.

## Детали реализации

- Компонент `input-otp` (shadcn/ui) для ввода 6-значного кода
- Кнопка «Войти» — отправляет `POST /api/auth/email/login/finish` с кодом
- Индикатор загрузки на кнопке при отправке
- При успехе — обновить `AuthContext` через `GET /api/auth/me` + `refetchUser()`
- При ошибке — отобразить сообщение «Неверный код»
- TTL кода — 10 минут

## Критерии приёмки

1. Шаг 2 отображает 6-значный OTP-ввод и кнопку «Войти»
2. При корректном коде пользователь авторизуется
3. При некорректном коде отображается сообщение об ошибке
4. Кнопка блокируется и показывает индикатор при отправке
