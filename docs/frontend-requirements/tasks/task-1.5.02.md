# TASK-1.5.02

**Название:** Добавить карточку роли в статистику (только для admin)  
**Эпик:** [Epic 1: Просмотр контента](../epics/epic-01-browsing.md)  
**User Story:** [US-1.5: Дополнительная информация для администратора](../user-stories/us-1.5.md)  
**Статус:** Не начата  
**Исполнитель:** Иван Бачурин

## Описание

Дополнить блок статистики на странице профиля пользователя карточкой с ролью (user/admin), видимой только для просматривающего администратора.

## Детали реализации

- Добавить в блок статистики дополнительную карточку «Роль»
- Условный рендеринг: только если текущий пользователь имеет role = admin
- Отобразить роль просматриваемого пользователя: «Пользователь» или «Администратор»
- Стилизовать карточку в общем стиле с остальной статистикой

## Критерии приёмки

1. Администратор видит карточку роли в статистике профиля
2. Обычный пользователь/гость не видит эту карточку
3. Роль отображается корректно
