**Исполнитель:** Максим Небывалов

## Описание

Создать анимацию горизонтальной прокрутки рулетки (рила), которая плавно замедляется и останавливается на выигрышном предмете за 5 секунд.

## Детали реализации

- Использовать Framer Motion `animate` для управления позицией рила
- Вычислить итоговый offset так, чтобы позиция 50 оказалась по центру экрана
- Применить easing-функцию (ease-out) для эффекта замедления
- Длительность анимации — 5 секунд
- После завершения анимации отправить callback (onComplete)
- Рил визуально представлен как горизонтальная лента карточек предметов

## Критерии приёмки

1. Анимация рила длится ~5 секунд
2. Рил плавно замедляется и останавливается на выигрышном слоте
3. Нет рывков или дёрганий при анимации
4. После остановки вызывается callback завершения
