# TASK-5.2.04

**Название:** Обработать пустое состояние: «Пока нет открытий»  
**Эпик:** [Epic 5: Профиль пользователя](../epics/epic-05-profile.md)  
**User Story:** [US-5.2: Просмотр истории открытий](../user-stories/us-5.2.md)  
**Статус:** Не начата  
**Исполнитель:** Иван Бачурин

## Описание

Если пользователь ещё не открывал кейсы, на вкладке «История» показать информативное сообщение.

## Детали реализации

- Проверить массив истории на пустоту
- Показать EmptyState: «Пока нет открытий»
- Кнопка «Открыть кейс» → `/cases`

## Критерии приёмки

1. При пустой истории отображается сообщение
2. Предлагается действие — перейти к кейсам
