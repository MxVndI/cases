# TASK-3.1.06

**User Story:** [US-3.1: Одиночное открытие кейса](../user-stories/us-3.1.md)  
**Статус:** Не начата  
**Исполнитель:** Максим Небывалов

## Описание

На оверлее результата добавить две кнопки действий: «Забрать» (добавить в инвентарь) и «Продать» (сразу продать за CaseHubCoin).

## Детали реализации

- Кнопка «Забрать» — закрывает оверлей, предмет остаётся в инвентаре
- Кнопка «Продать» — продаёт предмет, начисляет стоимость на баланс
- Стилизация: «Забрать» — основная (primary), «Продать» — вторичная
- На кнопке «Продать» отобразить сумму продажи

## Критерии приёмки

1. Обе кнопки видны на экране результата
2. «Забрать» закрывает оверлей
3. «Продать» начисляет стоимость и закрывает оверлей
4. Баланс обновляется после продажи
