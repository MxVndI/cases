# TASK-7.2.04

**Название:** Реализовать диалог подтверждения разблокировки  
**Эпик:** [Epic 7: Администрирование](../epics/epic-07-admin.md)  
**User Story:** [US-7.2: Блокировка и разблокировка пользователей](../user-stories/us-7.2.md)  
**Статус:** Не начата  
**Исполнитель:** Максим Небывалов

## Описание

При нажатии «Разблокировать» показать диалог подтверждения.

## Детали реализации

- Диалог: «Вы уверены, что хотите разблокировать пользователя {nickname}?»
- Кнопки «Разблокировать» и «Отмена»

## Критерии приёмки

1. Диалог подтверждения появляется
2. Действие выполняется только после подтверждения
