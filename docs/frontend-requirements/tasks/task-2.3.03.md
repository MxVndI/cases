## Описание

Обработать возврат пользователя после успешной авторизации через OAuth-провайдер. Backend устанавливает cookie при callback, фронтенд должен обработать перенаправление.

## Детали реализации

- Backend перенаправляет пользователя на `/welcome` после успешного OAuth
- Фронтенд на странице `/welcome` проверяет наличие сессии (cookie)
- Обновить состояние авторизации в AuthContext
- Перенаправить пользователя на главную страницу
- Обработать ошибку OAuth: показать сообщение и ссылку на повторную попытку

## Критерии приёмки

1. После успешного OAuth пользователь оказывается авторизован
2. Состояние AuthContext обновляется корректно
3. При ошибке OAuth отображается информативное сообщение
