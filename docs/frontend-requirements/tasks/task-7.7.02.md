# TASK-7.7.02

**Название:** Реализовать экран «Доступ запрещён» для неадминистраторов  
**Эпик:** [Epic 7: Администрирование](../epics/epic-07-admin.md)  
**User Story:** [US-7.7: Ограничение доступа к панели](../user-stories/us-7.7.md)  
**Статус:** Не начата  
**Исполнитель:** Данил Косенко

## Описание

Создать компонент, отображаемый при попытке доступа к `/admin` пользователем без прав администратора.

## Детали реализации

- Крупный заголовок: «Доступ запрещён»
- Иконка запрета (Lucide: ShieldX или Lock)
- Описание: «У вас нет прав для доступа к панели администратора»
- Кнопка «На главную» → `/`

## Критерии приёмки

1. Экран «Доступ запрещён» отображается для обычных пользователей
2. Содержит иконку, заголовок, описание и ссылку на главную
