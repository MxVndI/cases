# TASK-2.2.04

**Название:** После успешного входа выполнить перенаправление на главную  
**Эпик:** [Epic 2: Регистрация и авторизация](../epics/epic-02-auth.md)  
**User Story:** [US-2.2: Авторизация по email и паролю](../user-stories/us-2.2.md)  
**Статус:** Не начата  
**Исполнитель:** Николай Сгонник

## Описание

После успешной авторизации автоматически перенаправить пользователя на главную страницу.

## Детали реализации

- После установки состояния авторизации вызвать `navigate({ to: "/" })`
- Перенаправление должно произойти без задержки
- Состояние хедера должно обновиться (переключение на авторизованный вид)

## Критерии приёмки

1. Пользователь автоматически перенаправляется на главную после входа
2. Хедер отображает авторизованный вид (имя, баланс, кнопки)
