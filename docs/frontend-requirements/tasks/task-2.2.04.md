# TASK-2.2.04

**Название:** После успешного входа выполнить перенаправление на главную или сохранённый путь  
**Эпик:** [Epic 2: Регистрация и авторизация](../epics/epic-02-auth.md)  
**User Story:** [US-2.2: Авторизация по email](../user-stories/us-2.2.md)  
**Статус:** Не начата  
**Исполнитель:** Николай Сгонник

## Описание

После успешной авторизации (OTP подтверждён) перенаправить пользователя на `/` или на сохранённый путь redirect, если он был перенаправлен на логин.

## Детали реализации

- После установки состояния авторизации — `navigate({ to: redirect || "/" })`
- Проверить наличие сохранённого redirect path (если пользователь был перенаправлен на `/login` с защищённой страницы)
- Перенаправление без задержки
- Хедер должен обновиться (авторизованный вид: имя, баланс CHC)

## Критерии приёмки

1. Пользователь перенаправляется на `/` после входа
2. Если был сохранён redirect path — перенаправляется туда
3. Хедер отображает авторизованный вид (имя, баланс CHC)
