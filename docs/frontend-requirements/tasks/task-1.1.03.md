**User Story:** [US-1.1: Просмотр главной страницы](../user-stories/us-1.1.md)  
**Статус:** Не начата  
**Исполнитель:** Иван Бачурин

## Описание

Создать адаптивную сетку карточек кейсов для главной страницы. Каждая карточка отображает превью кейса с основной информацией: изображение, название и стоимость.

## Детали реализации

- Использовать CSS Grid или Flexbox для адаптивной сетки
- Настроить брейкпоинты Tailwind: 1 колонка (мобильный), 2 колонки (sm), 3 колонки (md), 4 колонки (lg)
- Карточка содержит: изображение кейса, название, стоимость в CaseHubCoin
- Карточка является ссылкой — клик ведёт на `/cases/$caseId`
- Использовать компонент Card из shadcn/ui или кастомный с Tailwind
- Данные берутся из dummy-data.ts

## Критерии приёмки

1. Сетка адаптивно меняет количество колонок в зависимости от ширины экрана
2. Карточки имеют одинаковую высоту в пределах строки
3. Каждая карточка содержит изображение, название и цену
4. Клик по карточке навигирует на страницу деталей кейса
5. На мобильных устройствах сетка корректно перестраивается в одну колонку
