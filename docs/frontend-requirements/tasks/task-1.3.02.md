# TASK-1.3.02

**Название:** Отобразить список предметов кейса с цветовой маркировкой по редкости  
**Эпик:** [Epic 1: Просмотр контента](../epics/epic-01-browsing.md)  
**User Story:** [US-1.3: Просмотр деталей кейса](../user-stories/us-1.3.md)  
**Статус:** Не начата  
**Исполнитель:** Иван Бачурин

## Описание

На странице деталей кейса отобразить полный список предметов, которые могут выпасть при открытии. Каждый предмет визуально маркирован цветом в соответствии с его редкостью.

## Детали реализации

- Создать компонент списка предметов под основной информацией о кейсе
- Для каждого предмета отобразить: иконку, название, редкость
- Использовать цветовую систему редкости: common (серый), rare (синий), epic (фиолетовый), legendary (оранжевый), exotic (красный)
- Цвет применяется к рамке карточки предмета или фоновой полосе
- Сетка предметов адаптивная

## Критерии приёмки

1. Все предметы кейса отображаются на странице
2. Каждый предмет имеет корректный цвет рамки/маркировки по редкости
3. Цветовая система соответствует глоссарию (5 уровней)
4. Сетка адаптивна и не ломается на малых экранах
