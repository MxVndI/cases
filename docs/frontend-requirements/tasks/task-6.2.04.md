# TASK-6.2.04

**Название:** Блокировать кнопку при недостаточном балансе  
**Эпик:** [Epic 6: Ферма (кликер)](../epics/epic-06-farm.md)  
**User Story:** [US-6.2: Покупка улучшений](../user-stories/us-6.2.md)  
**Статус:** Не начата  
**Исполнитель:** Николай Сгонник

## Описание

Кнопка покупки улучшения должна быть заблокирована, если баланс фермы меньше стоимости улучшения.

## Детали реализации

- Сравнить баланс фермы со стоимостью каждого улучшения
- Disabled + пониженная непрозрачность при недостаточном балансе
- Обновлять при каждом изменении баланса

## Критерии приёмки

1. Кнопка заблокирована при недостатке средств
2. Разблокируется при достаточном балансе
