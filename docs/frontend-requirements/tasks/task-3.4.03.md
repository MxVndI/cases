**User Story:** [US-3.4: Продажа предмета из результата](../user-stories/us-3.4.md)

**Исполнитель:** Максим Небывалов

## Описание

Реализовать добавление выигранного предмета в инвентарь пользователя при нажатии кнопки «Забрать» на экране результата.

## Детали реализации

- При клике «Забрать» — добавить предмет в массив инвентаря пользователя
- Закрыть оверлей
- Предмет должен быть доступен на странице профиля (вкладка инвентарь)
- В мок-режиме — сохранить в localStorage или state

## Критерии приёмки

1. Предмет добавляется в инвентарь
2. Оверлей закрывается
3. Предмет виден на странице профиля
