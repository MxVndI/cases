# TASK-3.1.04

**Название:** Отобразить указатель по центру рила  
**Эпик:** [Epic 3: Открытие кейсов](../epics/epic-03-case-opening.md)  
**User Story:** [US-3.1: Одиночное открытие кейса](../user-stories/us-3.1.md)  
**Статус:** Не начата  
**Исполнитель:** Максим Небывалов

## Описание

Добавить визуальный указатель (треугольник или линию) по центру контейнера рулетки, показывающий, на какой предмет укажет рил после остановки.

## Детали реализации

- Стилизовать указатель как треугольник сверху и/или снизу рила
- Указатель фиксирован по центру контейнера (не прокручивается)
- Использовать контрастный цвет (например, жёлтый или белый)
- Z-index указателя выше рила

## Критерии приёмки

1. Указатель виден по центру рулетки
2. Указатель не прокручивается вместе с рилом
3. Указатель корректно указывает на выигрышный слот после остановки
