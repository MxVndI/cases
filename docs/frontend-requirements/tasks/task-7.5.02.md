# TASK-7.5.02

**Название:** Предвыбрать текущие предметы кейса в компоненте выбора  
**Эпик:** [Epic 7: Администрирование](../epics/epic-07-admin.md)  
**User Story:** [US-7.5: Редактирование кейса](../user-stories/us-7.5.md)  
**Статус:** Не начата  
**Исполнитель:** Данил Косенко

## Описание

В компоненте выбора предметов предварительно отметить предметы, которые уже входят в кейс.

## Детали реализации

- Получить список предметов текущего кейса
- Установить чекбоксы для этих предметов
- Администратор может добавить или убрать предметы

## Критерии приёмки

1. Текущие предметы кейса отмечены чекбоксами
2. Можно добавить или убрать предметы
