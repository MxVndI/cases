**Исполнитель:** Иван Бачурин

## Описание

Создать панель фильтров для каталога кейсов на главной странице. Панель позволяет фильтровать кейсы по категории, ценовому диапазону и редкости предметов, а также сортировать результаты по различным параметрам.

## Детали реализации

- Расположить панель фильтров над сеткой карточек кейсов
- Реализовать Dropdown-селекторы для категории (Оружие, Ножи, Перчатки, Агенты, Наклейки) и сортировки (по цене возр./убыв., по популярности)
- Добавить фильтр по ценовому диапазону (ползунок или два поля ввода)
- Добавить мультивыбор по редкости (common, rare, epic, legendary, exotic)
- Использовать компоненты shadcn/ui: DropdownMenu, Checkbox, Input
- Фильтрация выполняется на стороне клиента из массива dummy-data

## Критерии приёмки

1. Панель фильтров отображается над карточками кейсов
2. Фильтрация по категории корректно сужает выборку
3. Сортировка по цене работает в обоих направлениях
4. Фильтр по редкости поддерживает мультивыбор
5. При комбинации фильтров результаты пересекаются (AND-логика)
6. Адаптивная вёрстка: фильтры корректно отображаются на мобильных устройствах
