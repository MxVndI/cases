## Описание

Создать компонент `FilterPanel` для фильтрации кейсов на главной странице: ценовой диапазон, сортировка, мультивыбор редкости, фильтр по тегам и статусу (admin).

## Детали реализации

- Компонент `FilterPanel` над сеткой карточек кейсов
- Фильтр **ценового диапазона** (price range): ползунок или два поля «от»/«до» в CHC
- **Сортировка** (sort): по цене возр./убыв., по названию
- **Мультивыбор редкости** (rarity): common, rare, epic, legendary, exotic
- **Фильтр по тегам** (tag filter): выбор тегов для фильтрации кейсов
- **Фильтр статуса** (admin): active/disabled — виден только админам
- Использовать компоненты shadcn/ui: DropdownMenu, Checkbox, Input, Select
- Фильтры комбинируются (AND-логика)

## Критерии приёмки

1. Компонент `FilterPanel` отображается над карточками
2. Фильтр по ценовому диапазону работает
3. Сортировка по цене/названию работает
4. Мультивыбор редкости и фильтр по тегам работают
5. Комбинация фильтров даёт AND-логику
6. Адаптивная вёрстка на мобильных
