# TASK-6.2.01

**Название:** Реализовать панель улучшений с карточками  
**Эпик:** [Epic 6: Ферма (кликер)](../epics/epic-06-farm.md)  
**User Story:** [US-6.2: Покупка улучшений](../user-stories/us-6.2.md)  
**Статус:** Не начата  
**Исполнитель:** Николай Сгонник

## Описание

Создать боковую или нижнюю панель с карточками доступных улучшений для кликера.

## Детали реализации

- Панель с карточками улучшений: «Сила клика», «Автокликер», «Множитель», «Скорость»
- Каждая карточка: иконка, название, текущий уровень, стоимость
- Вертикальный или горизонтальный список
- Панель не перекрывает кнопку кликера

## Критерии приёмки

1. Панель улучшений видна на странице фермы
2. Карточки улучшений содержат: название, уровень, стоимость
