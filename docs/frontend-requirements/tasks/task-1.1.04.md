# TASK-1.1.04

**Название:** Обеспечить анимацию появления контента и hover-эффекты на карточках  
**Эпик:** [Epic 1: Просмотр контента](../epics/epic-01-browsing.md)  
**User Story:** [US-1.1: Просмотр главной страницы](../user-stories/us-1.1.md)  
**Статус:** Не начата  
**Исполнитель:** Иван Бачурин

## Описание

Добавить плавные анимации для улучшения пользовательского опыта: анимацию появления карточек при загрузке страницы и интерактивные hover-эффекты при наведении курсора.

## Детали реализации

- Использовать Framer Motion для анимации появления карточек (fade-in + slide-up)
- Задать staggerChildren для последовательного появления карточек (каждая следующая с небольшой задержкой)
- При наведении — увеличение масштаба карточки (scale: 1.05) и появление тени
- Добавить transition для плавности изменений
- Анимация не должна влиять на производительность при большом количестве карточек

## Критерии приёмки

1. Карточки появляются с плавной анимацией при загрузке страницы
2. Карточки появляются последовательно с задержкой (stagger-эффект)
3. При наведении карточка увеличивается и получает тень
4. Анимации плавные, без рывков (60 fps)
5. На мобильных устройствах hover-эффекты корректно обрабатываются
