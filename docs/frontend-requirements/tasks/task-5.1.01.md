# TASK-5.1.01

**Название:** Реализовать карточку профиля (аватар, никнейм, email, дата регистрации)  
**Эпик:** [Epic 5: Профиль пользователя](../epics/epic-05-profile.md)  
**User Story:** [US-5.1: Просмотр обзора профиля](../user-stories/us-5.1.md)  
**Статус:** Не начата  
**Исполнитель:** Иван Бачурин

## Описание

Создать карточку профиля для страницы личного кабинета (`/profile`) с основной информацией о текущем пользователе.

## Детали реализации

- Аватар (заглушка с первой буквой никнейма или сгенерированный)
- Никнейм, email, дата регистрации
- Стилизовать: тёмная карточка с градиентом и тенью
- Данные из AuthContext (текущий пользователь)

## Критерии приёмки

1. Карточка отображает аватар, никнейм, email и дату регистрации
2. Данные корректно берутся из контекста авторизации
