**Название:** Реализовать перенаправление на OAuth-провайдер

**User Story:** [US-2.3: Авторизация через OAuth](../user-stories/us-2.3.md)  
**Статус:** Не начата  
**Исполнитель:** Николай Сгонник

## Описание

При клике на кнопку OAuth перенаправить пользователя на страницу авторизации соответствующего провайдера.

## Детали реализации

- По клику на Discord — перенаправление на URL авторизации Discord OAuth2
- По клику на Яндекс — перенаправление на URL авторизации Яндекс OAuth
- URL формируется через backend-эндпоинт `/api/auth/{provider}/login`
- В мок-режиме — симулировать перенаправление

## Критерии приёмки

1. Клик по кнопке Discord инициирует OAuth-поток
2. Клик по кнопке Яндекс инициирует OAuth-поток
3. Перенаправление на корректный URL провайдера
