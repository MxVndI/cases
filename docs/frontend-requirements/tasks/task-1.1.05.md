# TASK-1.1.05

**Название:** Добавить кнопку «Сбросить фильтры» с отображением количества активных фильтров  
**Эпик:** [Epic 1: Просмотр контента](../epics/epic-01-browsing.md)  
**User Story:** [US-1.1: Просмотр главной страницы](../user-stories/us-1.1.md)  
**Статус:** Не начата  
**Исполнитель:** Иван Бачурин

## Описание

Добавить кнопку сброса всех активных фильтров с индикатором количества применённых фильтров, чтобы пользователь мог быстро вернуться к полному каталогу.

## Детали реализации

- Расположить кнопку в правой части панели фильтров или под ней
- Отображать бейдж с числом активных фильтров (например, «Сбросить (3)»)
- При отсутствии активных фильтров кнопка скрыта или неактивна
- По клику все фильтры сбрасываются в значения по умолчанию
- Сетка кейсов обновляется до полного каталога

## Критерии приёмки

1. Кнопка «Сбросить фильтры» отображается при наличии хотя бы одного активного фильтра
2. Бейдж корректно показывает количество активных фильтров
3. Клик по кнопке сбрасывает все фильтры в значение по умолчанию
4. Кнопка скрыта или неактивна, когда ни один фильтр не применён
