# TASK-5.1.04

**Название:** Реализовать блок статистики: инвентарь и кейсы  
**Эпик:** [Epic 5: Профиль пользователя](../epics/epic-05-profile.md)  
**User Story:** [US-5.1: Просмотр обзора профиля](../user-stories/us-5.1.md)  
**Статус:** Не начата  
**Исполнитель:** Иван Бачурин

## Описание

На вкладке «Обзор» отобразить блок статистики с основными показателями: количество предметов в инвентаре, их суммарная стоимость, количество открытых кейсов.

## Детали реализации

- Карточки: «Предметов в инвентаре», «Стоимость инвентаря», «Кейсов открыто»
- Иконки из Lucide React для каждой метрики
- Данные из state/dummy-data

## Критерии приёмки

1. Блок статистики с тремя показателями отображается
2. Значения корректны
