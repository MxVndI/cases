## Описание

Добавить кнопку для создания нового кейса, открывающую диалог создания.

## Детали реализации

- Кнопка «+ Добавить кейс» в верхней части вкладки
- По клику — открыть диалог создания (US-7.4)
- Стилизация: primary кнопка

## Критерии приёмки

1. Кнопка «Добавить кейс» видна
2. По клику открывается диалог создания
