# TASK-7.7.01

**Название:** Реализовать проверку роли при рендеринге компонента  
**Эпик:** [Epic 7: Администрирование](../epics/epic-07-admin.md)  
**User Story:** [US-7.7: Ограничение доступа к панели](../user-stories/us-7.7.md)  
**Статус:** Не начата  
**Исполнитель:** Данил Косенко

## Описание

При загрузке страницы `/admin` проверить роль текущего пользователя. Если не admin — показать экран ограничения доступа.

## Детали реализации

- Проверить role из AuthContext
- Если role !== "admin" — показать компонент AccessDenied
- Для гостя — перенаправить на `/login`
- Для пользователя с role = "user" — показать «Доступ запрещён»

## Критерии приёмки

1. Гость перенаправляется на `/login`
2. Обычный пользователь видит «Доступ запрещён»
3. Администратор видит панель управления
