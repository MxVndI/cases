# TASK-1.3.01

**Название:** Реализовать страницу с информацией о кейсе  
**Эпик:** [Epic 1: Просмотр контента](../epics/epic-01-browsing.md)  
**User Story:** [US-1.3: Просмотр деталей кейса](../user-stories/us-1.3.md)  
**Статус:** Не начата  
**Исполнитель:** Иван Бачурин

## Описание

Создать страницу деталей кейса (`/cases/$caseId`), отображающую полную информацию о выбранном кейсе: изображение, название, описание, стоимость и кнопку открытия.

## Детали реализации

- Извлечь `caseId` из параметров маршрута с помощью TanStack Router
- Найти соответствующий кейс в dummy-data по ID
- Отобразить крупное изображение кейса, название и описание
- Показать стоимость кейса в CaseHubCoin
- Добавить кнопку «Открыть кейс» (для авторизованных пользователей)
- Обработать случай неверного `caseId` (перенаправление на 404 или каталог)

## Критерии приёмки

1. Страница корректно загружается по маршруту `/cases/$caseId`
2. Отображаются: изображение, название, описание и стоимость кейса
3. Кнопка «Открыть кейс» видна для авторизованных пользователей
4. При неверном ID отображается сообщение «Кейс не найден»
