# TASK-7.4.01

**Название:** Реализовать диалог создания кейса  
**Эпик:** [Epic 7: Администрирование](../epics/epic-07-admin.md)  
**User Story:** [US-7.4: Создание нового кейса](../user-stories/us-7.4.md)  
**Статус:** Не начата  
**Исполнитель:** Данил Косенко

## Описание

Создать модальный диалог для создания нового кейса с табами/секциями для деталей кейса, выбора предметов и настройки шансов выпадения.

## Детали реализации

- Использовать Dialog из shadcn/ui
- Организовать содержимое в табы/секции: детали кейса, выбор предметов, шансы выпадения (drop chances)
- Редактор drop chances с автоматическим расчётом (auto-calculate)
- Загрузка изображения кейса в S3/RustFS (макс 5MB)
- Кнопки «Создать» и «Отмена»
- Диалог достаточно большой для удобной работы

## Критерии приёмки

1. Диалог создания открывается с табами/секциями
2. Содержит форму, выбор предметов, редактор drop chances и загрузку изображения
3. Можно закрыть без сохранения
