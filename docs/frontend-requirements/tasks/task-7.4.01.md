## Описание

Создать модальный диалог для создания нового кейса с формой и компонентом выбора предметов.

## Детали реализации

- Использовать Dialog из shadcn/ui
- Содержит форму с полями и компонент выбора предметов
- Кнопки «Создать» и «Отмена»
- Диалог должен быть достаточно большим для удобной работы

## Критерии приёмки

1. Диалог создания открывается
2. Содержит форму и выбор предметов
3. Можно закрыть без сохранения
