# TASK-3.4.01

**Название:** Реализовать функцию продажи из экрана результата  
**Эпик:** [Epic 3: Открытие кейсов](../epics/epic-03-case-opening.md)  
**User Story:** [US-3.4: Продажа предмета из результата](../user-stories/us-3.4.md)  
**Статус:** Не начата  
**Исполнитель:** Максим Небывалов

## Описание

Реализовать логику продажи выигранного предмета прямо с экрана результата открытия. Нажатие кнопки «Продать» начисляет стоимость предмета на баланс.

## Детали реализации

- При клике «Продать» на оверлее результата — начислить стоимость предмета
- Обновить баланс в AuthContext/state
- Закрыть оверлей после продажи
- Предмет не попадает в инвентарь

## Критерии приёмки

1. Стоимость предмета начисляется на баланс
2. Оверлей закрывается после продажи
3. Баланс обновляется в хедере
