# TASK-7.1.02

**Название:** Реализовать поиск по никнейму и email  
**Эпик:** [Epic 7: Администрирование](../epics/epic-07-admin.md)  
**User Story:** [US-7.1: Просмотр списка пользователей](../user-stories/us-7.1.md)  
**Статус:** Не начата  
**Исполнитель:** Максим Небывалов

## Описание

Добавить поле поиска на вкладке «Пользователи» для фильтрации по никнейму или email.

## Детали реализации

- Поле ввода с иконкой поиска и placeholder «Поиск по никнейму или email»
- Фильтрация в реальном времени (при вводе)
- Поиск по подстроке (case-insensitive)
- Debounce 300ms для оптимизации

## Критерии приёмки

1. Поиск фильтрует список пользователей
2. Фильтрация работает по никнейму и email
3. Поиск регистронезависимый
