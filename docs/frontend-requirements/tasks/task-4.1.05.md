## Описание

Настроить маршрут `/balance` с защитой авторизации и навигацией.

## Детали реализации

- Маршрут `/balance` зарегистрирован в TanStack Router
- Inline `beforeLoad` auth guard: проверка авторизации перед загрузкой, редирект на `/login` при отсутствии сессии
- Кнопка «На главную» в верхней части страницы
- Навигация на `/` без перезагрузки

## Критерии приёмки

1. Маршрут `/balance` доступен только авторизованным пользователям
2. Неавторизованные перенаправляются на `/login` (inline `beforeLoad` guard)
3. Кнопка «На главную» работает без перезагрузки
