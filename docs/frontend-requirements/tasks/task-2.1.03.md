# TASK-2.1.03

**Название:** Реализовать отправку данных на сервер  
**Эпик:** [Epic 2: Регистрация и авторизация](../epics/epic-02-auth.md)  
**User Story:** [US-2.1: Регистрация нового пользователя](../user-stories/us-2.1.md)  
**Статус:** Не начата  
**Исполнитель:** Николай Сгонник

## Описание

Реализовать логику отправки данных формы регистрации на backend. В текущей реализации — мок-режим с localStorage.

## Детали реализации

- При успешной валидации собрать данные формы
- В мок-режиме: сохранить данные пользователя в localStorage
- Обработать успешный ответ: перенаправление на главную
- Обработать ошибку: отобразить сообщение (например, «Email уже занят»)
- Добавить индикатор загрузки на кнопку при отправке

## Критерии приёмки

1. Данные формы отправляются при нажатии кнопки (или сохраняются в localStorage)
2. При успешной регистрации пользователь перенаправляется на главную
3. При ошибке отображается сообщение
4. Во время отправки кнопка блокируется и показывает индикатор загрузки
