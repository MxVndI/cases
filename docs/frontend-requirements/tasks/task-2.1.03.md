# TASK-2.1.03

**Название:** Реализовать шаг 2 регистрации — никнейм, OTP-код и кнопка «Зарегистрироваться»  
**Эпик:** [Epic 2: Регистрация и авторизация](../epics/epic-02-auth.md)  
**User Story:** [US-2.1: Регистрация нового пользователя](../user-stories/us-2.1.md)  
**Статус:** Не начата  
**Исполнитель:** Николай Сгонник

## Описание

После получения OTP-кода на email (шаг 1) отобразить шаг 2: поле ввода никнейма и 6-значный OTP-код. При нажатии «Зарегистрироваться» отправляется `POST /api/auth/email/login/finish` с `{code}`. Бэкенд проверяет код, устанавливает cookie `sid` и создаёт аккаунт при первом входе.

## Детали реализации

- Поле ввода никнейма (text) — задаётся при регистрации
- Компонент `input-otp` (shadcn/ui) для ввода 6-значного кода
- Кнопка «Зарегистрироваться» — отправляет `POST /api/auth/email/login/finish` с кодом
- Индикатор загрузки на кнопке при отправке
- При успешном ответе — обновить `AuthContext` через `refetchUser()`
- При ошибке — отобразить сообщение «Неверный код» под OTP-полем
- TTL кода — 10 минут

## Критерии приёмки

1. Шаг 2 отображает поле никнейма и 6-значный OTP-ввод
2. Кнопка «Зарегистрироваться» отправляет код на бэкенд
3. Во время отправки кнопка блокируется и показывает индикатор загрузки
4. При ошибке отображается сообщение под OTP-полем
