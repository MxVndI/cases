# TASK-2.1.03

**Название:** Реализовать отправку данных на сервер  
**Эпик:** [Epic 2: Регистрация и авторизация](../epics/epic-02-auth.md)  
**User Story:** [US-2.1: Регистрация нового пользователя](../user-stories/us-2.1.md)  
**Статус:** Не начата  
**Исполнитель:** Николай Сгонник

## Описание

Реализовать логику отправки данных формы регистрации.

## Детали реализации

**Текущее (мок-режим):**
- При успешной валидации вызывать `mockAuth.register(nickname, email)` — данные сохраняются в `localStorage`
- Обновить `AuthContext` через `refetchUser()`
- Перенаправить на `/profile`

**При интеграции с реальным бэкендом:**
- Отдельного API-эндпоинта регистрации в бэкенде нет
- Страница редиректирует на `/login` для выбора метода входа (OAuth или email-код)
- Аккаунт создаётся автоматически при первом входе
- Добавить индикатор загрузки на кнопку при отправке

## Критерии приёмки

1. Данные формы отправляются/сохраняются при нажатии кнопки
2. При успешной регистрации пользователь перенаправляется
3. Во время отправки кнопка блокируется и показывает индикатор загрузки
