# TASK-7.5.03

**Название:** Обновлять данные кейса в списке после сохранения  
**Эпик:** [Epic 7: Администрирование](../epics/epic-07-admin.md)  
**User Story:** [US-7.5: Редактирование кейса](../user-stories/us-7.5.md)  
**Статус:** Не начата  
**Исполнитель:** Данил Косенко

## Описание

После сохранения изменений обновить данные кейса в списке без перезагрузки.

## Детали реализации

- Обновить объект кейса в массиве данных
- Закрыть диалог
- Список отражает обновлённые данные

## Критерии приёмки

1. Изменения видны в списке после сохранения
2. Диалог закрывается
