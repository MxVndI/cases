# TASK-7.2.01

**Название:** Реализовать кнопку блокировки/разблокировки для каждого пользователя  
**Эпик:** [Epic 7: Администрирование](../epics/epic-07-admin.md)  
**User Story:** [US-7.2: Блокировка и разблокировка пользователей](../user-stories/us-7.2.md)  
**Статус:** Не начата  
**Исполнитель:** Максим Небывалов

## Описание

В каждой строке пользователя добавить кнопку для переключения статуса: заблокировать активного или разблокировать заблокированного.

## Детали реализации

- Кнопка «Заблокировать» (красная) для active пользователей
- Кнопка «Разблокировать» (зелёная) для blocked пользователей
- Текст и иконка меняются в зависимости от текущего статуса

## Критерии приёмки

1. Кнопка видна в каждой строке пользователя
2. Текст/цвет кнопки соответствует текущему статусу
