**Название:** Реализовать функцию выхода (очистка сессии/токена)  
**Эпик:** [Epic 2: Регистрация и авторизация](../epics/epic-02-auth.md)

**Статус:** Не начата

## Описание

Реализовать функциональность выхода из системы: очистку состояния авторизации и сессионных данных.

## Детали реализации

- Создать функцию logout в AuthContext
- Очистить cookie/localStorage (в мок-режиме — очистить localStorage)
- Сбросить состояние пользователя в AuthContext (user = null, isAuthenticated = false)
- Опционально: отправить запрос на backend для инвалидации сессии

## Критерии приёмки

1. При вызове logout пользователь теряет статус авторизации
2. Сессионные данные очищены из хранилища
3. Состояние AuthContext сброшено
