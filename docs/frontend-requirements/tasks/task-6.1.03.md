# TASK-6.1.03

**Название:** Отобразить текущий баланс фермы и доход в секунду  
**Эпик:** [Epic 6: Ферма (кликер)](../epics/epic-06-farm.md)  
**User Story:** [US-6.1: Заработок монет кликами](../user-stories/us-6.1.md)  
**Статус:** Не начата  
**Исполнитель:** Николай Сгонник

## Описание

Отобразить текущий баланс пользователя (из `paymentApi.getBalance`) и 4 плитки статистики на странице фермы.

## Детали реализации

- Баланс CHC крупным шрифтом с иконкой, данные из `paymentApi.getBalance`
- 4 stat-плитки:
  - **Total Clicks** — общее количество кликов
  - **Per-Click Earnings** — текущий доход за клик (`base × click_power × multiplier`)
  - **Auto Rate** — доход автокликера в секунду
  - **Auto Interval** — интервал срабатывания автокликера
- Значения обновляются в реальном времени при работе автокликера и при кликах

## Критерии приёмки

1. Баланс CHC отображается крупно, данные из `paymentApi.getBalance`
2. 4 stat-плитки видны: Total Clicks, Per-Click Earnings, Auto Rate, Auto Interval
3. Значения обновляются в реальном времени
