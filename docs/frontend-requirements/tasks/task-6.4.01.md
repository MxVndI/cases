# TASK-6.4.01

**Название:** Сохранять состояние фермы в localStorage при каждом изменении  
**Эпик:** [Epic 6: Ферма (кликер)](../epics/epic-06-farm.md)  
**User Story:** [US-6.4: Сохранение прогресса](../user-stories/us-6.4.md)  
**Статус:** Не начата  
**Исполнитель:** Николай Сгонник

## Описание

Сохранять полное состояние фермы (баланс, уровни улучшений) в localStorage при любом изменении, чтобы прогресс не терялся.

## Детали реализации

- При каждом изменении баланса или уровня — сохранять в localStorage
- Ключ: `casehub_farm_state`
- Формат: JSON {balance, clickLevel, autoClickerLevel, multiplierLevel, speedLevel}
- Использовать useEffect или debounce для оптимизации частых записей

## Критерии приёмки

1. Состояние сохраняется в localStorage
2. При каждом клике/покупке сохранение срабатывает
