# TASK-6.4.01

**Название:** Синхронизировать состояние фермы с сервером  
**Эпик:** [Epic 6: Ферма (кликер)](../epics/epic-06-farm.md)

## Описание

Состояние фермы синхронизируется с сервером через `farmApi.syncFarm`. Сервер хранит данные в Redis.

## Детали реализации

- Вызывать `farmApi.syncFarm` для синхронизации состояния с сервером
- Отправлять `auto_clicker_level`, `speed_level` и другие уровни улучшений
- Сервер хранит состояние в Redis
- Не использовать localStorage для персистентности

## Критерии приёмки

1. Состояние фермы синхронизируется с сервером через `farmApi.syncFarm`
2. Уровни улучшений передаются на сервер
