# TASK-3.3.03

**Название:** Реализовать экран результатов мульти-открытия со списком предметов  
**Эпик:** [Epic 3: Открытие кейсов](../epics/epic-03-case-opening.md)  
**User Story:** [US-3.3: Мульти-открытие кейсов](../user-stories/us-3.3.md)  
**Статус:** Не начата  
**Исполнитель:** Максим Небывалов

## Описание

Создать экран, отображающий все выигранные предметы при мульти-открытии в виде сетки карточек.

## Детали реализации

- Оверлей с сеткой карточек (3 или 5 штук)
- Каждая карточка: изображение предмета, название, редкость, стоимость
- Цветовая маркировка по редкости
- Под каждой карточкой — кнопка «Продать» с суммой
- Общая сумма выигрыша отображается сверху

## Критерии приёмки

1. Отображаются все выигранные предметы
2. Каждый предмет имеет кнопку продажи
3. Общая сумма выигрыша видна
4. Цветовая маркировка соответствует редкости
