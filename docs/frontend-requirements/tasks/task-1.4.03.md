**Исполнитель:** Иван Бачурин

## Описание

Добавить в профиль пользователя список его последних выигрышей, показывая какие предметы из каких кейсов были получены.

## Детали реализации

- Создать компонент списка выигрышей под статистикой
- Каждая запись: предмет (иконка + название), кейс, дата
- Цвет рамки предмета по редкости
- Ограничить отображение 5-10 последними записями
- При пустом списке — сообщение «Нет выигрышей»

## Критерии приёмки

1. Список отображает последние выигрыши пользователя
2. Каждая запись содержит: предмет, кейс, дату
3. Цветовая маркировка редкости применена
4. При отсутствии данных отображается пустое состояние
