# TASK-4.3.02

**Название:** Добавить сортировку (по умолчанию, цена возрастание, цена убывание)  
**Эпик:** [Epic 4: Инвентарь и баланс](../epics/epic-04-inventory-balance.md)

**Исполнитель:** Данил Косенко

## Описание

Добавить в панель фильтров инвентаря возможность сортировки предметов по стоимости.

## Детали реализации

- Dropdown с вариантами: «По умолчанию», «Цена ↑», «Цена ↓»
- Сортировка применяется к массиву предметов на клиенте
- При смене сортировки — мгновенное обновление сетки

## Критерии приёмки

1. Dropdown сортировки работает
2. Предметы перестраиваются при смене сортировки
