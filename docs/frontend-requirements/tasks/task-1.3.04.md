# TASK-1.3.04

**Название:** Для гостя — заблокировать или скрыть функциональность открытия  
**Эпик:** [Epic 1: Просмотр контента](../epics/epic-01-browsing.md)  
**User Story:** [US-1.3: Просмотр деталей кейса](../user-stories/us-1.3.md)  
**Статус:** Не начата  
**Исполнитель:** Иван Бачурин

## Описание

Ограничить доступ гостя к функции открытия кейса. Кнопка «Открыть кейс» должна быть либо заблокирована с пояснением, либо заменена призывом к авторизации.

## Детали реализации

- Проверить статус авторизации из AuthContext
- Для неавторизованного пользователя: заблокировать кнопку (disabled) или скрыть
- Показать текст-пояснение: «Войдите, чтобы открыть кейс» со ссылкой на `/login`
- Для авторизованного пользователя кнопка активна и ведёт на маршрут открытия

## Критерии приёмки

1. Гость не может нажать кнопку «Открыть кейс»
2. Гость видит пояснение с призывом авторизоваться
3. Ссылка на страницу входа ведёт на `/login`
4. Авторизованный пользователь видит активную кнопку
