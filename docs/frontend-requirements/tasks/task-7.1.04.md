## Описание

Добавить фильтр для отображения пользователей по роли: все, пользователи, администраторы.

## Детали реализации

- DropdownMenu или кнопки: «Все», «Пользователи», «Администраторы»
- Фильтрация по полю role: all, user, admin
- Комбинируется с остальными фильтрами

## Критерии приёмки

1. Фильтр по роли работает
2. Комбинируется с поиском и фильтром по статусу
