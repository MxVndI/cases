# TASK-7.3.03

**Название:** Добавить кнопки редактирования и удаления для каждого кейса  
**Эпик:** [Epic 7: Администрирование](../epics/epic-07-admin.md)  
**User Story:** [US-7.3: Просмотр списка кейсов](../user-stories/us-7.3.md)  
**Статус:** Не начата  
**Исполнитель:** Максим Небывалов

## Описание

В каждой строке/карточке кейса добавить кнопки «Редактировать» и «Удалить».

## Детали реализации

- Кнопка «Редактировать» с иконкой карандаша
- Кнопка «Удалить» с иконкой корзины (красный цвет)
- По клику — открытие соответствующих диалогов

## Критерии приёмки

1. Кнопки редактирования и удаления видны
2. Каждая открывает соответствующий диалог
