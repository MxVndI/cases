# TASK-4.3.05

**Название:** Реализовать кнопку «Сбросить фильтры»  
**Эпик:** [Epic 4: Инвентарь и баланс](../epics/epic-04-inventory-balance.md)  
**User Story:** [US-4.3: Фильтрация и сортировка инвентаря](../user-stories/us-4.3.md)  
**Статус:** Не начата  
**Исполнитель:** Данил Косенко

## Описание

Добавить кнопку для сброса всех фильтров инвентаря в значения по умолчанию.

## Детали реализации

- Кнопка «Сбросить» в панели фильтров
- По клику: сбросить выбор редкости, сортировку на «По умолчанию»
- Кнопка скрыта или disabled, если нет активных фильтров

## Критерии приёмки

1. Клик сбрасывает все фильтры
2. Кнопка недоступна, если фильтры не применены
