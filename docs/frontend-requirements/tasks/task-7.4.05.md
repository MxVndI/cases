# TASK-7.4.05

**Название:** Добавить превью предмета при наведении (в режиме дерева)  
**Эпик:** [Epic 7: Администрирование](../epics/epic-07-admin.md)  
**User Story:** [US-7.4: Создание нового кейса](../user-stories/us-7.4.md)  
**Статус:** Не начата  
**Исполнитель:** Данил Косенко

## Описание

При наведении на предмет в item picker показывать карточку-превью с подробной информацией.

## Детали реализации

- Tooltip или popover при hover на предмете (в обоих режимах — tree и gallery)
- Карточка-превью содержит: изображение предмета, название, редкость (с цветом), стоимость в CHC, тип оружия
- Появляется с небольшой задержкой (200ms)
- Исчезает при уходе курсора

## Критерии приёмки

1. Превью-карточка появляется при наведении
2. Содержит изображение, редкость, стоимость и тип оружия
3. Исчезает при уходе курсора
