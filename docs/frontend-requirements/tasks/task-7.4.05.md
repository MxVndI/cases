# TASK-7.4.05

**Название:** Добавить превью предмета при наведении (в режиме дерева)  
**Эпик:** [Epic 7: Администрирование](../epics/epic-07-admin.md)  
**User Story:** [US-7.4: Создание нового кейса](../user-stories/us-7.4.md)  
**Статус:** Не начата  
**Исполнитель:** Данил Косенко

## Описание

В режиме дерева при наведении на название предмета показывать всплывающее превью с изображением и характеристиками.

## Детали реализации

- Tooltip или popover при hover в режиме дерева
- Содержит: изображение предмета, редкость, стоимость
- Появляется с небольшой задержкой (200ms)
- Исчезает при уходе курсора

## Критерии приёмки

1. Превью появляется при наведении
2. Содержит изображение и характеристики
3. Исчезает при уходе курсора
