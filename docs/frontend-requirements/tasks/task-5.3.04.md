# TASK-5.3.04

**Название:** Добавить визуальную обратную связь: «Сохранено!» (2 секунды)  
**Эпик:** [Epic 5: Профиль пользователя](../epics/epic-05-profile.md)

## Описание

После успешного сохранения показать кратковременное сообщение «Сохранено!», исчезающее через 2 секунды.

## Детали реализации

- Тост или инлайн-сообщение «Сохранено!» зелёного цвета
- Автоматическое исчезновение через 2 секунды
- Анимация fade-in/fade-out

## Критерии приёмки

1. Сообщение «Сохранено!» появляется после успешного сохранения
2. Сообщение исчезает через ~2 секунды
