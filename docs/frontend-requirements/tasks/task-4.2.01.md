# TASK-4.2.01

**Название:** Реализовать сетку карточек предметов с адаптивной разметкой  
**Эпик:** [Epic 4: Инвентарь и баланс](../epics/epic-04-inventory-balance.md)  
**User Story:** [US-4.2: Просмотр инвентаря](../user-stories/us-4.2.md)  
**Статус:** Не начата  
**Исполнитель:** Данил Косенко

## Описание

На вкладке «Инвентарь» в профиле создать адаптивную сетку карточек предметов, принадлежащих пользователю.

## Детали реализации

- CSS Grid с адаптивными брейкпоинтами: 1-4 колонки
- Каждая карточка: изображение предмета, рамка по редкости
- Данные из массива инвентаря пользователя
- Анимация появления карточек (Framer Motion)

## Критерии приёмки

1. Сетка предметов инвентаря адаптивна
2. Карточки имеют цветовую маркировку по редкости
3. Анимация появления при загрузке
