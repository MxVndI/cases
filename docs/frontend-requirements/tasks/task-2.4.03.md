# TASK-2.4.03

**Название:** Обновить состояние хедера (переключение на гостевой вид)  
**Эпик:** [Epic 2: Регистрация и авторизация](../epics/epic-02-auth.md)  
**User Story:** [US-2.4: Выход из системы](../user-stories/us-2.4.md)  
**Статус:** Не начата  
**Исполнитель:** Николай Сгонник

## Описание

После выхода хедер должен мгновенно переключиться на гостевой вид: вместо имени пользователя и баланса показать кнопки «Войти»/«Регистрация».

## Детали реализации

- Хедер реагирует на изменение состояния авторизации в AuthContext
- Для гостя отображаются кнопки «Войти» и «Регистрация»
- Для авторизованного: никнейм, баланс, аватар, кнопка выхода
- Переключение происходит без перезагрузки страницы

## Критерии приёмки

1. Хедер мгновенно обновляется после выхода
2. Кнопки «Войти»/«Регистрация» видны для гостя
3. Имя, баланс и аватар скрыты для гостя
