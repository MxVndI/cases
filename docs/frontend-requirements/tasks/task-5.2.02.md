# TASK-5.2.02

**Название:** Для каждой записи отобразить: предмет, кейс, дату, доход, расход  
**Эпик:** [Epic 5: Профиль пользователя](../epics/epic-05-profile.md)  
**User Story:** [US-5.2: Просмотр истории открытий](../user-stories/us-5.2.md)  
**Статус:** Не начата  
**Исполнитель:** Иван Бачурин

## Описание

Каждая запись в истории открытий должна содержать полную информацию: название предмета, кейс, дату, стоимость открытия (расход) и стоимость предмета (потенциальный доход).

## Детали реализации

- Столбцы/поля: предмет (иконка + название), кейс, дата, расход (цена кейса), доход (стоимость предмета)
- Стоимости с иконкой CaseHubCoin
- Цвет расхода — красный, доход — зелёный

## Критерии приёмки

1. Каждая запись содержит все указанные поля
2. Цвета доходов/расходов различаются
