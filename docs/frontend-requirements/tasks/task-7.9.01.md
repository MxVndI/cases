# TASK-7.9.01: CRUD редкостей и тегов

**User Story:** [US-7.9: CRUD справочников](../user-stories/us-7.9.md)

## Описание

На вкладке «Редкости» панели администратора реализованы два раздела:

1. **Редкости (Rarities):** Список всех редкостей (`adminApi.getRarities`). Каждая отображает: название, цвет (цветовой индикатор). Создание/редактирование через диалог с полями: название, цвет (color picker). Удаление с подтверждением. API: `adminApi.createRarity`, `updateRarity`, `deleteRarity`.

2. **Теги (Tags):** Список всех тегов (`adminApi.getCaseTags`). Каждый отображает название. Создание/редактирование через диалог с полем: название. Удаление с подтверждением. API: `adminApi.createCaseTag`, `updateCaseTag`, `deleteCaseTag`.

## Критерии приёмки

- [ ] Список редкостей с цветовыми индикаторами
- [ ] CRUD для редкостей (создание, редактирование, удаление с подтверждением)
- [ ] Список тегов
- [ ] CRUD для тегов (создание, редактирование, удаление с подтверждением)
- [ ] Тост-уведомления при успешных операциях
