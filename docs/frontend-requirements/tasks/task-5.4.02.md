# TASK-5.4.02

**Название:** Реализовать переключатель анимации CountUp для чисел  
**Эпик:** [Epic 5: Профиль пользователя](../epics/epic-05-profile.md)  
**User Story:** [US-5.4: Настройки предпочтений](../user-stories/us-5.4.md)  
**Статус:** Не начата  
**Исполнитель:** Иван Бачурин

## Описание

На вкладке «Настройки» профиля добавить toggle-переключатель для анимации CountUp (плавный счётчик чисел). По умолчанию включён (ON). Значение хранится в `PreferencesContext` и `localStorage`.

## Детали реализации

- Toggle-компонент (shadcn/ui Switch) с подписью «Анимация чисел»
- Значение по умолчанию: ON (включён)
- При переключении — обновить `PreferencesContext` и `localStorage`
- Влияет на компонент CountUp (баланс, цены и т.д.)

## Критерии приёмки

1. Toggle-переключатель отображается на вкладке «Настройки»
2. По умолчанию включён
3. Переключение мгновенно влияет на анимацию чисел
