# TASK-5.4.02

**Название:** Добавить валидацию совпадения паролей  
**Эпик:** [Epic 5: Профиль пользователя](../epics/epic-05-profile.md)  
**User Story:** [US-5.4: Смена пароля](../user-stories/us-5.4.md)  
**Статус:** Не начата  
**Исполнитель:** Иван Бачурин

## Описание

Проверить, что «Новый пароль» и «Подтверждение пароля» совпадают, перед отправкой формы.

## Детали реализации

- Сравнить значения полей при попытке отправки
- При несовпадении — показать ошибку «Пароли не совпадают»
- Блокировать отправку при ошибке

## Критерии приёмки

1. Форма не отправляется при несовпадении паролей
2. Ошибка отображается под соответствующим полем
