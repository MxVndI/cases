# TASK-7.8.01: Список предметов с фильтрами

**User Story:** [US-7.8: CRUD предметов](../user-stories/us-7.8.md)

## Описание

На вкладке «Предметы» панели администратора отображается таблица/список всех предметов (Items). Данные загружаются через `adminApi.getItems()`. Каждый предмет отображает: название, цену (CHC), изображение (thumbnail), редкость (цветовая метка), оружие/тип. Доступны фильтры: по редкости (мультиселект), по оружию, по диапазону цены, текстовый поиск по названию.

## Критерии приёмки

- [ ] Таблица предметов загружается при переключении на вкладку «Предметы»
- [ ] Каждый предмет показывает: изображение, название, цену в CHC, редкость (цвет), оружие
- [ ] Фильтрация по редкости, оружию, цене, названию работает
- [ ] Пустое состояние при отсутствии предметов
