# TASK-7.9.02: CRUD типов оружия и оружия

**User Story:** [US-7.9: CRUD справочников](../user-stories/us-7.9.md)

## Описание

На вкладке «Оружие» панели администратора реализованы два раздела:

1. **Типы оружия (WeaponTypes):** Список всех типов оружия (`adminApi.getWeaponTypes`). Создание/редактирование через диалог с полем: название. Удаление с подтверждением. API: `adminApi.createWeaponType`, `updateWeaponType`, `deleteWeaponType`.

2. **Оружие (Weapons):** Список всего оружия (`adminApi.getWeapons`). Каждое отображает: название, тип оружия. Создание/редактирование через диалог с полями: название, селектор типа оружия (из справочника WeaponTypes). Удаление с подтверждением. API: `adminApi.createWeapon`, `updateWeapon`, `deleteWeapon`.

## Критерии приёмки

- [ ] Список типов оружия
- [ ] CRUD для типов оружия (создание, редактирование, удаление с подтверждением)
- [ ] Список оружия с указанием типа
- [ ] CRUD для оружия (создание, редактирование с селектором типа, удаление с подтверждением)
- [ ] Тост-уведомления при успешных операциях
