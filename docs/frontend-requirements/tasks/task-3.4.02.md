# TASK-3.4.02

**Название:** Обновить баланс пользователя после продажи  
**Эпик:** [Epic 3: Открытие кейсов](../epics/epic-03-case-opening.md)  
**User Story:** [US-3.4: Продажа предмета из результата](../user-stories/us-3.4.md)  
**Статус:** Не начата  
**Исполнитель:** Максим Небывалов

## Описание

Обеспечить мгновенное обновление отображения баланса пользователя во всех местах (хедер, страница баланса) после продажи предмета.

## Детали реализации

- Обновить state баланса в AuthContext или глобальном state
- Хедер реагирует на изменение состояния и обновляет отображаемое значение
- При использовании TanStack Query — инвалидировать query баланса

## Критерии приёмки

1. Баланс в хедере обновляется мгновенно после продажи
2. Все компоненты, отображающие баланс, получают обновлённое значение
