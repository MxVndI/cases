# TASK-3.3.02

**Название:** Реализовать одновременную генерацию нескольких результатов  
**Эпик:** [Epic 3: Открытие кейсов](../epics/epic-03-case-opening.md)  
**User Story:** [US-3.3: Мульти-открытие кейсов](../user-stories/us-3.3.md)  
**Статус:** Не начата  
**Исполнитель:** Максим Небывалов

## Описание

При мульти-открытии (x3 или x5) сгенерировать соответствующее количество случайных результатов и списать совокупную стоимость с баланса.

## Детали реализации

- Принять множитель (3 или 5) как параметр функции открытия
- Вызвать генерацию случайного предмета N раз
- Сформировать массив результатов
- Списать стоимость * множитель с баланса
- Пропустить анимацию рулетки для мульти-открытия

## Критерии приёмки

1. Генерируется корректное количество результатов (3 или 5)
2. Баланс списывается на правильную сумму
3. Каждый результат — случайный предмет из кейса
