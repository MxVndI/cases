## Описание

На вкладке «История» отобразить полный список всех открытий кейсов пользователем в хронологическом порядке.

## Детали реализации

- Список записей, отсортированный по дате (новые сверху)
- Компонент-строка для каждой записи
- Загрузка данных из state/dummy-data

## Критерии приёмки

1. Полный список открытий отображается
2. Записи отсортированы по дате (новые сверху)
