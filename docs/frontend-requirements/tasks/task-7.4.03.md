# TASK-7.4.03

**Название:** Реализовать компонент выбора предметов (два режима: дерево и галерея)  
**Эпик:** [Epic 7: Администрирование](../epics/epic-07-admin.md)  
**User Story:** [US-7.4: Создание нового кейса](../user-stories/us-7.4.md)  
**Статус:** Не начата  
**Исполнитель:** Данил Косенко

## Описание

Создать компонент выбора предметов (item picker) с двумя режимами: tree view (Tree) и галерея (Gallery). Предметы отображаются с цветами редкости и группировкой по типу оружия.

## Детали реализации

- Режим **Tree view**: группировка по типу оружия (weapon type) → предметы
- Режим **Gallery**: сетка карточек предметов
- Переключатель режимов (toggle иконки)
- Карточки предметов с цветами редкости (рамка/подсветка)
- Чекбокс выбора на каждом предмете
- Счётчик выбранных предметов

## Критерии приёмки

1. Два режима: Tree view и Gallery
2. Переключение между режимами работает
3. Предметы отображаются с цветами редкости и группировкой по weapon type
4. Можно выбирать предметы, счётчик отображается
