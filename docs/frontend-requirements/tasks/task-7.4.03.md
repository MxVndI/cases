# TASK-7.4.03

**Название:** Реализовать компонент выбора предметов (два режима: дерево и галерея)  
**Эпик:** [Epic 7: Администрирование](../epics/epic-07-admin.md)  
**User Story:** [US-7.4: Создание нового кейса](../user-stories/us-7.4.md)  
**Статус:** Не начата  
**Исполнитель:** Данил Косенко

## Описание

Создать компонент с двумя режимами просмотра доступных предметов: иерархическое дерево и галерея с карточками.

## Детали реализации

- Режим «Дерево»: группировка по типу оружия → предметы
- Режим «Галерея»: сетка карточек предметов
- Переключатель режимов (иконки)
- Чекбокс выбора на каждом предмете
- Счётчик выбранных предметов

## Критерии приёмки

1. Два режима просмотра доступны
2. Переключение между режимами работает
3. Можно выбирать предметы чекбоксами
4. Счётчик выбранных отображается
