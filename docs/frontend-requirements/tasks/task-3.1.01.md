# TASK-3.1.01

**Название:** Реализовать генерацию рила из 60 слотов со случайной расстановкой предметов  
**Эпик:** [Epic 3: Открытие кейсов](../epics/epic-03-case-opening.md)  
**User Story:** [US-3.1: Одиночное открытие кейса](../user-stories/us-3.1.md)  
**Статус:** Не начата  
**Исполнитель:** Максим Небывалов

## Описание

Генерировать массив из 60 элементов (слотов) для анимации рулетки. Предметы из кейса распределяются случайным образом по слотам, при этом выигрышный предмет помещается на фиксированную позицию (позиция 50).

## Детали реализации

- Принять массив предметов кейса на вход функции
- Сгенерировать массив из 60 слотов, заполнив случайными предметами из кейса
- Поместить заранее определённый выигрышный предмет на позицию 50
- Учитывать вероятности (веса) предметов при заполнении остальных слотов
- Функция должна быть чистой и вызываться при каждом новом открытии

## Критерии приёмки

1. Массив содержит ровно 60 элементов
2. Каждый элемент — объект предмета из кейса
3. Выигрышный предмет находится на позиции 50
4. Остальные позиции заполнены случайными предметами
