# TASK-7.4.06

**Название:** Валидация обязательных полей  
**Эпик:** [Epic 7: Администрирование](../epics/epic-07-admin.md)  
**User Story:** [US-7.4: Создание нового кейса](../user-stories/us-7.4.md)  
**Статус:** Не начата  
**Исполнитель:** Данил Косенко

## Описание

Перед созданием кейса проверить обязательные поля и корректность данных: название, цена, хотя бы один предмет, сумма drop chances.

## Детали реализации

- Проверить: название не пустое, цена > 0 (CHC), выбран >= 1 предмет
- Drop chances (шансы выпадения) должны суммироваться до валидного значения
- Автоматический расчёт (auto-calculate) суммы drop chances
- Отобразить ошибки под полями
- Кнопка «Создать» disabled при невалидном состоянии

## Критерии приёмки

1. Кейс не создаётся без заполнения обязательных полей
2. Предупреждение если drop chances не суммируются корректно
3. Ошибки валидации видны
