# TASK-1.2.03

**Название:** Реализовать логику переключения между каталогом и дочерним маршрутом (Outlet)  
**Эпик:** [Epic 1: Просмотр контента](../epics/epic-01-browsing.md)  
**User Story:** [US-1.2: Просмотр каталога кейсов](../user-stories/us-1.2.md)  
**Статус:** Не начата  
**Исполнитель:** Иван Бачурин

## Описание

Настроить маршрутизацию так, чтобы страница каталога (`/cases`) поддерживала дочерние маршруты через механизм Outlet. При переходе на `/cases/$caseId` каталог заменяется содержимым дочернего маршрута.

## Детали реализации

- Использовать `<Outlet />` из TanStack Router в компоненте маршрута `/cases`
- При отсутствии дочернего маршрута отображать каталог кейсов
- При наличии дочернего маршрута (`/cases/$caseId`) отображать Outlet с деталями кейса
- Обеспечить корректную работу кнопки «Назад» в браузере

## Критерии приёмки

1. На `/cases` отображается каталог кейсов
2. На `/cases/123` каталог заменяется деталями кейса
3. Кнопка «Назад» возвращает на каталог корректно
4. Переходы между каталогом и деталями работают без перезагрузки
