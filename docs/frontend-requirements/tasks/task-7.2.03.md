# TASK-7.2.03

**Название:** Реализовать диалог подтверждения блокировки  
**Эпик:** [Epic 7: Администрирование](../epics/epic-07-admin.md)  
**User Story:** [US-7.2: Блокировка и разблокировка пользователей](../user-stories/us-7.2.md)  
**Статус:** Не начата  
**Исполнитель:** Максим Небывалов

## Описание

При нажатии «Заблокировать» показать диалог подтверждения с предупреждением.

## Детали реализации

- Использовать Dialog из shadcn/ui
- Текст: «Вы уверены, что хотите заблокировать пользователя {nickname}?»
- Кнопки «Заблокировать» и «Отмена»

## Критерии приёмки

1. Диалог подтверждения появляется
2. Содержит имя пользователя
3. Действие выполняется только после подтверждения
