## Описание

Создать панель вкладок для навигации между секциями профиля: Обзор, История, Инвентарь и Настройки.

## Детали реализации

- Горизонтальная панель вкладок внутри страницы `/profile`
- Вкладки: «Обзор», «История», «Инвентарь», «Настройки»
- Активная вкладка визуально выделена
- Переключение вкладок не вызывает перезагрузку
- Использовать хранение активной вкладки в state или URL query

## Критерии приёмки

1. Четыре вкладки видны на странице профиля
2. Переключение работает без перезагрузки
3. Активная вкладка визуально выделена
