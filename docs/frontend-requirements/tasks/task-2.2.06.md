**Название:** Реализовать редирект для уже авторизованных пользователей

**Статус:** Не начата  
**Исполнитель:** Николай Сгонник

## Описание

Если авторизованный пользователь переходит на `/login`, автоматически перенаправить его на главную — повторная авторизация бессмысленна.

## Детали реализации

- Проверить статус авторизации из AuthContext при загрузке компонента
- Если авторизован — `navigate({ to: "/" })` до рендера формы

## Критерии приёмки

1. Авторизованный пользователь перенаправляется с `/login` на `/`
2. Форма входа не мелькает перед перенаправлением
