# TASK-6.1.02

**Название:** Начислять монеты за каждый клик (с учётом улучшений)

**User Story:** [US-6.1: Заработок монет кликами](../user-stories/us-6.1.md)  
**Статус:** Не начата  
**Исполнитель:** Николай Сгонник

## Описание

При каждом клике начислять пользователю монеты CaseHubCoin. Сумма начисления зависит от текущих улучшений (базовый доход * множитель).

## Детали реализации

- Базовый доход за клик: 1 монета
- Формула: доход = базовый_доход * (1 + уровень_улучшения_клика * 0.5) * множитель
- Обновлять баланс фермы в state
- Учитывать купленные улучшения

## Критерии приёмки

1. Каждый клик увеличивает баланс фермы
2. Сумма начисления корректно учитывает улучшения
