# TASK-4.3.06

**Название:** Обработать пустое состояние после фильтрации  
**Эпик:** [Epic 4: Инвентарь и баланс](../epics/epic-04-inventory-balance.md)  
**User Story:** [US-4.3: Фильтрация и сортировка инвентаря](../user-stories/us-4.3.md)  
**Статус:** Не начата  
**Исполнитель:** Данил Косенко

## Описание

Если после применения фильтров нет подходящих предметов, отобразить информативное сообщение вместо пустой сетки.

## Детали реализации

- Проверить результат фильтрации на пустоту
- Если пусто — показать компонент EmptyState (переиспользуемый)
- Текст: «Нет предметов по выбранным фильтрам»
- Кнопка «Сбросить фильтры» под текстом

## Критерии приёмки

1. При пустом результате отображается пустое состояние
2. Текст информативен и предлагает сбросить фильтры
