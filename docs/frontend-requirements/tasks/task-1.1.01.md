## Описание

Необходимо реализовать горизонтальный конвейер (бегущую строку), отображающий последние выигрыши пользователей. Конвейер автоматически прокручивается в бесконечном цикле, создавая эффект непрерывного потока данных о выигрышах на платформе.

## Детали реализации

- Использовать CSS-анимацию `@keyframes` или Framer Motion для плавной горизонтальной прокрутки
- Дублировать набор элементов для создания бесшовного перехода при зацикливании
- Каждый элемент конвейера содержит: иконку предмета, название предмета, название кейса, никнейм пользователя
- Цвет рамки/подсветки элемента соответствует редкости предмета (common — серый, rare — синий, epic — фиолетовый, legendary — оранжевый, exotic — красный)
- При наведении курсора прокрутка приостанавливается
- Конвейер располагается в верхней части главной страницы, под хедером

## Критерии приёмки

1. Конвейер автоматически прокручивается без пауз и рывков
2. Прокрутка визуально бесшовная — нет пустых мест при переходе цикла
3. При наведении мыши прокрутка приостанавливается, при уходе — возобновляется
4. Каждый элемент содержит: иконку предмета, название, кейс, никнейм
5. Отображается не менее 10 последних выигрышей из dummy-data
6. Цветовая маркировка рамок соответствует редкости предмета
