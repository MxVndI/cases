## Описание

Реализовать горизонтальный конвейер последних выигрышей с автоматическим обновлением через SSE (Server-Sent Events). Данные поступают в реальном времени через `casesApi.streamWins` (используя EventSource).

## Детали реализации

- Подключение к SSE через `casesApi.streamWins` с использованием `EventSource`
- Конвейер автоматически обновляется при поступлении новых выигрышей
- Использовать CSS-анимацию `@keyframes` или Framer Motion для плавной прокрутки
- Дублировать набор элементов для бесшовного перехода
- Каждый элемент: иконка предмета, название, кейс, никнейм
- Цвет рамки по редкости (common — серый, rare — синий, epic — фиолетовый, legendary — оранжевый, exotic — красный)
- При наведении курсора прокрутка приостанавливается
- Конвейер расположен в верхней части главной, под хедером
- Закрывать соединение EventSource при размонтировании

## Критерии приёмки

1. Конвейер получает данные через SSE (`casesApi.streamWins` / EventSource)
2. Новые выигрыши автоматически появляются в конвейере
3. Прокрутка бесшовная и плавная
4. При наведении мыши прокрутка приостанавливается
5. Цветовая маркировка рамок соответствует редкости предмета
