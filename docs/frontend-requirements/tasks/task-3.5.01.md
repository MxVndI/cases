# TASK-3.5.01

**Название:** Реализовать альтернативный визуальный стиль рулетки  
**Эпик:** [Epic 3: Открытие кейсов](../epics/epic-03-case-opening.md)  
**User Story:** [US-3.5: Альтернативная страница открытия](../user-stories/us-3.5.md)  
**Статус:** Не начата  
**Исполнитель:** Максим Небывалов

## Описание

Создать альтернативную страницу открытия кейса (`/cases/$caseId/open`) с другим визуальным стилем рулетки — например, вертикальная прокрутка или карусель.

## Детали реализации

- Создать компонент страницы для маршрута `/cases/$caseId/open`
- Реализовать визуально отличающуюся рулетку (вертикальная или круговая)
- Стилизация: иной цветовой акцент, другая анимация
- Использовать тот же набор данных (предметы кейса)

## Критерии приёмки

1. Альтернативная страница открытия доступна по маршруту `/cases/$caseId/open`
2. Визуальный стиль явно отличается от основного
3. Рулетка функциональна и работает корректно
