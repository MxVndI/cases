# TASK-7.8.03: Удаление предмета

**User Story:** [US-7.8: CRUD предметов](../user-stories/us-7.8.md)

## Описание

Кнопка «Удалить» в строке предмета открывает диалог подтверждения с названием предмета. При подтверждении вызывается `adminApi.deleteItem(itemId)`. После успешного удаления предмет убирается из списка и показывается тост-уведомление.

## Критерии приёмки

- [ ] Кнопка «Удалить» отображается для каждого предмета
- [ ] Диалог подтверждения показывает название удаляемого предмета
- [ ] После подтверждения предмет удаляется из API и из списка
- [ ] Тост-уведомление об успешном удалении
