# TASK-1.3.03

**Название:** Показывать стоимость каждого предмета  
**Эпик:** [Epic 1: Просмотр контента](../epics/epic-01-browsing.md)  
**User Story:** [US-1.3: Просмотр деталей кейса](../user-stories/us-1.3.md)  
**Статус:** Не начата  
**Исполнитель:** Иван Бачурин

## Описание

Дополнить карточки предметов кейса отображением их стоимости в CaseHubCoin, чтобы пользователь мог оценить потенциальный выигрыш.

## Детали реализации

- Добавить поле стоимости в каждую карточку предмета
- Форматировать стоимость с иконкой валюты CaseHubCoin
- Выровнять информацию в карточке: название, редкость, стоимость

## Критерии приёмки

1. Каждый предмет в списке кейса отображает стоимость в CaseHubCoin
2. Стоимость форматирована и содержит иконку валюты
3. Макет карточки предмета аккуратный и не перегружен
