## Описание

На альтернативной странице открытия показать результат в модальном окне (dialog) вместо полноэкранного оверлея.

## Детали реализации

- Использовать компонент Dialog из shadcn/ui
- Диалог содержит: предмет, название, редкость, стоимость
- Кнопки «Забрать» и «Продать» внутри диалога
- Анимация появления диалога

## Критерии приёмки

1. Результат показывается в модальном окне
2. Модальное окно содержит все необходимые данные
3. Кнопки действий внутри диалога работают корректно
