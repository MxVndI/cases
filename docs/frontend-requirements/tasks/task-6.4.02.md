# TASK-6.4.02

**Название:** Восстанавливать состояние с сервера при загрузке  
**Эпик:** [Epic 6: Ферма (кликер)](../epics/epic-06-farm.md)  
**User Story:** [US-6.4: Сохранение прогресса](../user-stories/us-6.4.md)  
**Статус:** Не начата  
**Исполнитель:** Николай Сгонник

## Описание

При загрузке страницы фермы вызывать `farmApi.syncFarm` для получения сохранённого состояния с сервера, включая offline-заработок.

## Детали реализации

- При монтировании компонента вызвать `farmApi.syncFarm`
- Сервер возвращает текущее состояние + накопленные offline-заработки
- Установить state из ответа сервера
- Пересчитать все производные значения (доход/клик, auto rate)

## Критерии приёмки

1. При возвращении на ферму прогресс восстановлен с сервера через `farmApi.syncFarm`
2. Offline-заработок учтён
3. Баланс и уровни восстановлены
