# TASK-6.4.02

**Название:** Восстанавливать состояние при загрузке страницы  
**Эпик:** [Epic 6: Ферма (кликер)](../epics/epic-06-farm.md)  
**User Story:** [US-6.4: Сохранение прогресса](../user-stories/us-6.4.md)  
**Статус:** Не начата  
**Исполнитель:** Николай Сгонник

## Описание

При загрузке страницы фермы восстановить сохранённое состояние из localStorage.

## Детали реализации

- При монтировании компонента — прочитать localStorage
- Распарсить JSON и установить state
- Пересчитать все производные значения (доход/клик, доход/сек)

## Критерии приёмки

1. При возвращении на ферму прогресс сохранён
2. Баланс и уровни восстановлены
