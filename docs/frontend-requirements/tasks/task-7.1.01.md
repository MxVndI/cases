# TASK-7.1.01

**Название:** Реализовать панель вкладок (Пользователи, Кейсы)  
**Эпик:** [Epic 7: Администрирование](../epics/epic-07-admin.md)  
**User Story:** [US-7.1: Просмотр списка пользователей](../user-stories/us-7.1.md)  
**Статус:** Не начата  
**Исполнитель:** Максим Небывалов

## Описание

Создать страницу администрирования (`/admin`) с панелью из двух вкладок: «Пользователи» и «Кейсы».

## Детали реализации

- Создать страницу-компонент для маршрута `/admin`
- Две вкладки: «Пользователи» (по умолчанию) и «Кейсы»
- Активная вкладка визуально выделена
- Содержимое переключается без перезагрузки

## Критерии приёмки

1. Страница `/admin` отображает две вкладки
2. Переключение работает без перезагрузки
3. По умолчанию открыта вкладка «Пользователи»
