# TASK-3.3.05

**Название:** Блокировать кнопки при недостаточном балансе  
**Эпик:** [Epic 3: Открытие кейсов](../epics/epic-03-case-opening.md)  
**User Story:** [US-3.3: Мульти-открытие кейсов](../user-stories/us-3.3.md)  
**Статус:** Не начата  
**Исполнитель:** Максим Небывалов

## Описание

Блокировать кнопки мульти-открытия (x3, x5), если текущий баланс пользователя меньше совокупной стоимости открытия.

## Детали реализации

- При рендере: сравнить баланс с ценой * множитель
- Если баланс < итого → кнопка disabled, пониженная непрозрачность
- Добавить tooltip или подсказку «Недостаточно средств»
- Обновлять блокировку при изменении баланса

## Критерии приёмки

1. Кнопки заблокированы при недостаточном балансе
2. Пользователь понимает причину блокировки
3. При увеличении баланса кнопки автоматически разблокируются
