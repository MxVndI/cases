# TASK-4.4.04

**Название:** Обновить баланс после продажи  
**Эпик:** [Epic 4: Инвентарь и баланс](../epics/epic-04-inventory-balance.md)  
**User Story:** [US-4.4: Продажа предмета из инвентаря](../user-stories/us-4.4.md)  
**Статус:** Не начата  
**Исполнитель:** Данил Косенко

## Описание

После продажи предмета из инвентаря обновить баланс пользователя на сумму стоимости проданного предмета.

## Детали реализации

- Начислить стоимость предмета на баланс в AuthContext/state
- Обновить суммарную стоимость инвентаря
- Баланс в хедере обновляется мгновенно
- Обновить статистику на странице баланса (если данные кешированы)

## Критерии приёмки

1. Баланс увеличивается на стоимость проданного предмета
2. Суммарная стоимость инвентаря уменьшается
3. Баланс в хедере обновлён
