# TASK-4.4.02

**Название:** Добавить кнопку отмены подтверждения  
**Эпик:** [Epic 4: Инвентарь и баланс](../epics/epic-04-inventory-balance.md)  
**User Story:** [US-4.4: Продажа предмета из инвентаря](../user-stories/us-4.4.md)  
**Статус:** Не начата  
**Исполнитель:** Данил Косенко

## Описание

На этапе подтверждения продажи добавить кнопку «Отмена», чтобы пользователь мог передумать.

## Детали реализации

- Рядом с кнопкой «Подтвердить» показать кнопку «Отмена»
- Клик на «Отмена» возвращает кнопку в исходное состояние «Продать»

## Критерии приёмки

1. Кнопка «Отмена» видна на этапе подтверждения
2. Клик на «Отмена» сбрасывает процесс продажи
