# TASK-7.5.01

**Название:** Реализовать предзаполнение формы данными существующего кейса  
**Эпик:** [Epic 7: Администрирование](../epics/epic-07-admin.md)  
**User Story:** [US-7.5: Редактирование кейса](../user-stories/us-7.5.md)  
**Статус:** Не начата  
**Исполнитель:** Данил Косенко

## Описание

При открытии диалога редактирования кейса заполнить форму текущими данными кейса.

## Детали реализации

- Получить данные кейса по ID
- Установить value полей: название, цена, описание, категория
- Заголовок диалога: «Редактирование кейса: {название}»

## Критерии приёмки

1. Форма предзаполнена текущими данными
2. Заголовок содержит название кейса
