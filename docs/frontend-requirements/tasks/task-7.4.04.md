## Описание

В компоненте выбора предметов добавить фильтры для быстрого нахождения нужных предметов.

## Детали реализации

- Поиск по названию (text input)
- Фильтр по редкости (мультивыбор чекбоксами)
- Фильтр по типу оружия (dropdown)
- Диапазон цен (два поля: «от» и «до»)
- Все фильтры комбинируются

## Критерии приёмки

1. Фильтры работают корректно
2. Комбинация фильтров даёт AND-логику
