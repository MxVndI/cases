## Описание

В компоненте выбора предметов (item picker) добавить фильтры для быстрого нахождения нужных предметов: по редкости, типу оружия, ценовому диапазону.

## Детали реализации

- Поиск по названию (text input)
- Фильтр по редкости (мультивыбор чекбоксами) — с цветовой маркировкой
- Фильтр по типу оружия (weapon type dropdown)
- Диапазон цен (два поля: «от» и «до» в CHC)
- Все фильтры комбинируются (AND-логика)

## Критерии приёмки

1. Фильтры по редкости, типу оружия и цене работают корректно
2. Комбинация фильтров даёт AND-логику
