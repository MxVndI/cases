# TASK-5.1.02

**Название:** Добавить бейдж «Администратор» для пользователей с ролью admin  
**Эпик:** [Epic 5: Профиль пользователя](../epics/epic-05-profile.md)  
**User Story:** [US-5.1: Просмотр обзора профиля](../user-stories/us-5.1.md)  
**Статус:** Не начата  
**Исполнитель:** Иван Бачурин

## Описание

Если текущий пользователь имеет роль admin, отобразить соответствующий бейдж на его карточке профиля.

## Детали реализации

- Проверить role пользователя из AuthContext
- Если admin — показать бейдж с текстом «Администратор» и иконкой щита
- Стилизовать бейдж: акцентный цвет (фиолетовый или золотой)

## Критерии приёмки

1. Бейдж виден для пользователей с ролью admin
2. Для обычных пользователей бейдж не отображается
