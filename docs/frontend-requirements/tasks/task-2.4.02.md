# TASK-2.4.02

**Название:** После выхода выполнить перенаправление на главную  
**Эпик:** [Epic 2: Регистрация и авторизация](../epics/epic-02-auth.md)  
**User Story:** [US-2.4: Выход из системы](../user-stories/us-2.4.md)  
**Статус:** Не начата  
**Исполнитель:** Николай Сгонник

## Описание

После успешного выхода из системы перенаправить пользователя на главную страницу.

## Детали реализации

- После вызова logout() выполнить `navigate({ to: "/" })`
- Убедиться, что перенаправление происходит после полной очистки состояния

## Критерии приёмки

1. После выхода пользователь оказывается на главной странице
2. Никаких артефактов авторизованного состояния не осталось
