# TASK-3.1.07

**Название:** Списать стоимость кейса с баланса при открытии  
**Эпик:** [Epic 3: Открытие кейсов](../epics/epic-03-case-opening.md)  
**User Story:** [US-3.1: Одиночное открытие кейса](../user-stories/us-3.1.md)  
**Статус:** Не начата  
**Исполнитель:** Максим Небывалов

## Описание

При нажатии кнопки «Открыть кейс» списать стоимость кейса с баланса пользователя. Если средств недостаточно — заблокировать открытие.

## Детали реализации

- Перед запуском рулетки проверить баланс >= стоимость кейса
- Списать сумму из баланса в AuthContext/state
- Если недостаточно средств — показать сообщение «Недостаточно средств»
- Обновить отображение баланса в хедере

## Критерии приёмки

1. Баланс уменьшается на стоимость кейса при открытии
2. При недостаточном балансе открытие блокируется
3. Баланс в хедере обновляется мгновенно
