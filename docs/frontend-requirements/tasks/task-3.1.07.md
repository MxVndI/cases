# TASK-3.1.07

**Название:** Списать стоимость кейса с баланса при открытии  
**Эпик:** [Epic 3: Открытие кейсов](../epics/epic-03-case-opening.md)  
**User Story:** [US-3.1: Одиночное открытие кейса](../user-stories/us-3.1.md)  
**Статус:** Не начата  
**Исполнитель:** Максим Небывалов

## Описание

При нажатии кнопки «Открыть кейс» списать стоимость кейса с баланса пользователя. Если средств недостаточно — заблокировать открытие.

## Детали реализации

**Текущее (мок-режим):**
- Перед запуском рулетки проверить баланс >= стоимость кейса в `mockAuth.getBalance()`
- Списать сумму через `mockAuth.updateBalance(-price)`
- Если недостаточно средств — показать сообщение «Недостаточно средств»
- Обновить отображение баланса в хедере через `refetchUser()`

**При интеграции с реальным бэкендом:**
- Запрос на открытие: `GET /api/cases/open/{id}` с cookie `sid` — бэкенд авторизует и возвращает UID пользователя
- Проверка баланса и списание выполняются на стороне бэкенда через Payment Service
- Получить текущий баланс: `GET /payment/balance/{user_id}`
- После открытия обновить баланс через повторный запрос баланса

## Критерии приёмки

1. Баланс уменьшается на стоимость кейса при открытии
2. При недостаточном балансе открытие блокируется с информационным сообщением
3. Баланс в хедере обновляется после списания
