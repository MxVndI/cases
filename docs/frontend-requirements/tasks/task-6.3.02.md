# TASK-6.3.02

**Название:** Учитывать уровни автокликера, множителя и скорости  
**Эпик:** [Epic 6: Ферма (кликер)](../epics/epic-06-farm.md)  
**User Story:** [US-6.3: Автоматический заработок](../user-stories/us-6.3.md)  
**Статус:** Не начата  
**Исполнитель:** Николай Сгонник

## Описание

Формула пассивного дохода должна учитывать уровни всех улучшений: автокликер, множитель, скорость.

## Детали реализации

- Доход в секунду = базовый_автодоход * (1 + уровень_автокликера * 0.5) * множитель
- Множитель зависит от уровня улучшения «Множитель»
- Скорость влияет на частоту тиков (частота = 1 + уровень_скорости * 0.2 с)
- Пересчитывать при изменении уровней

## Критерии приёмки

1. Пассивный доход корректно учитывает все улучшения
2. При покупке улучшений доход мгновенно пересчитывается
