## Описание

Добавить фильтр-переключатель для отображения пользователей по статусу: все, активные, заблокированные.

## Детали реализации

- Кнопки-переключатели или DropdownMenu: «Все», «Активные», «Заблокированные»
- Фильтрация по полю status: all, active, blocked
- Комбинируется с поиском

## Критерии приёмки

1. Фильтр по статусу работает
2. Комбинируется с текстовым поиском
