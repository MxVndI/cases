# TASK-1.4.04

**Название:** Обработать случай «пользователь не найден»  
**Эпик:** [Epic 1: Просмотр контента](../epics/epic-01-browsing.md)  
**User Story:** [US-1.4: Просмотр профиля другого игрока](../user-stories/us-1.4.md)  
**Статус:** Не начата  
**Исполнитель:** Иван Бачурин

## Описание

Реализовать обработку ситуации, когда запрошенный `userId` не найден. Вместо ошибки пользователь видит информативное сообщение.

## Детали реализации

- Проверить наличие пользователя в данных по переданному `userId`
- При отсутствии — отобразить компонент-заглушку
- Заглушка содержит: иконку, заголовок «Пользователь не найден», описание, ссылку на главную

## Критерии приёмки

1. При несуществующем `userId` отображается экран «Пользователь не найден»
2. Нет необработанных ошибок в консоли
3. Есть ссылка для возврата на главную страницу
