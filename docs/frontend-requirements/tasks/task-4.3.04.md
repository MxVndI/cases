# TASK-4.3.04

**Название:** Отобразить количество активных фильтров на кнопке  
**Эпик:** [Epic 4: Инвентарь и баланс](../epics/epic-04-inventory-balance.md)  
**User Story:** [US-4.3: Фильтрация и сортировка инвентаря](../user-stories/us-4.3.md)  
**Статус:** Не начата  
**Исполнитель:** Данил Косенко

## Описание

На кнопке «Фильтры» показать бейдж с количеством активных фильтров.

## Детали реализации

- Подсчитать количество активных: выбранные редкости + сортировка (если не по умолчанию)
- Бейдж с числом рядом с иконкой фильтров
- При 0 фильтров бейдж скрыт

## Критерии приёмки

1. Бейдж корректно подсчитывает активные фильтры
2. При 0 — бейдж не виден
