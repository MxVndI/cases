# TASK-5.4.04

**Название:** Сохранять изменения предпочтений в localStorage мгновенно  
**Эпик:** [Epic 5: Профиль пользователя](../epics/epic-05-profile.md)  
**User Story:** [US-5.4: Настройки предпочтений](../user-stories/us-5.4.md)  
**Статус:** Не начата  
**Исполнитель:** Иван Бачурин

## Описание

При переключении любого toggle (курсор, CountUp) изменение должно мгновенно сохраняться в `localStorage` без отдельной кнопки «Сохранить».

## Детали реализации

- При каждом изменении toggle — синхронно обновить `PreferencesContext` и `localStorage`
- Не требуется отдельная кнопка сохранения
- Использовать `useEffect` или обработчик onChange для персистентности

## Критерии приёмки

1. Переключение toggle мгновенно сохраняется в localStorage
2. После перезагрузки страницы toggle отображает сохранённое значение
