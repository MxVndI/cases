# TASK-3.1.03

**Название:** Обеспечить остановку на выигрышном предмете (позиция 50)

**User Story:** [US-3.1: Одиночное открытие кейса](../user-stories/us-3.1.md)  
**Статус:** Не начата  
**Исполнитель:** Максим Небывалов

## Описание

Гарантировать, что анимация рила всегда останавливается точно по центру на элементе в позиции 50 массива — это выигрышный предмет.

## Детали реализации

- Рассчитать offset прокрутки: (50 * ширина_слота) - (ширина_контейнера / 2) + (ширина_слота / 2)
- Учесть отступы между слотами при расчёте
- Центр указателя должен совпадать с центром выигрышного слота
- Тестировать на разных размерах экрана

## Критерии приёмки

1. Рил останавливается точно на позиции 50
2. Выигрышный предмет находится по центру указателя
3. Корректная работа на десктопных и мобильных экранах
