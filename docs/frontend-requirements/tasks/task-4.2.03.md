# TASK-4.2.03

**Название:** Рассчитывать и отображать суммарную стоимость инвентаря  
**Эпик:** [Epic 4: Инвентарь и баланс](../epics/epic-04-inventory-balance.md)  
**User Story:** [US-4.2: Просмотр инвентаря](../user-stories/us-4.2.md)  
**Статус:** Не начата  
**Исполнитель:** Данил Косенко

## Описание

Над сеткой инвентаря отобразить суммарную стоимость всех предметов в инвентаре.

## Детали реализации

- Подсчитать сумму стоимостей всех предметов
- Отобразить в формате «Стоимость инвентаря: 1,234 CC»
- Обновлять при продаже предмета
- При пустом инвентаре — 0

## Критерии приёмки

1. Суммарная стоимость инвентаря видна
2. Расчёт корректный
3. Обновляется при продаже предмета
