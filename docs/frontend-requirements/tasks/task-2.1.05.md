# TASK-2.1.05

**Название:** Реализовать редирект после успешной регистрации и для авторизованных пользователей  
**Эпик:** [Epic 2: Регистрация и авторизация](../epics/epic-02-auth.md)  
**User Story:** [US-2.1: Регистрация нового пользователя](../user-stories/us-2.1.md)  
**Статус:** Не начата  
**Исполнитель:** Николай Сгонник

## Описание

После успешной регистрации (OTP подтверждён) перенаправить пользователя на `/`. Также, если уже авторизованный пользователь открывает `/register`, автоматически перенаправить на `/`.

## Детали реализации

- После успешного `POST /api/auth/email/login/finish` и обновления `AuthContext` — `navigate({ to: "/" })`
- При загрузке компонента проверить статус авторизации из `AuthContext`
- Если пользователь уже авторизован — `navigate({ to: "/" })` до рендера формы

## Критерии приёмки

1. После успешной регистрации пользователь перенаправляется на `/`
2. Авторизованный пользователь автоматически перенаправляется с `/register` на `/`
3. Форма регистрации не мелькает перед перенаправлением
