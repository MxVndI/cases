# TASK-2.1.05

**Название:** Реализовать редирект на главную для уже авторизованных пользователей  
**Эпик:** [Epic 2: Регистрация и авторизация](../epics/epic-02-auth.md)  
**User Story:** [US-2.1: Регистрация нового пользователя](../user-stories/us-2.1.md)  
**Статус:** Не начата  
**Исполнитель:** Николай Сгонник

## Описание

Если авторизованный пользователь переходит на страницу регистрации, он должен быть автоматически перенаправлен на главную — повторная регистрация бессмысленна.

## Детали реализации

- При загрузке компонента проверить статус авторизации из AuthContext
- Если пользователь авторизован — выполнить `navigate({ to: "/" })`
- Перенаправление должно произойти до рендера формы

## Критерии приёмки

1. Авторизованный пользователь автоматически перенаправляется с `/register` на `/`
2. Форма регистрации не мелькает перед перенаправлением
