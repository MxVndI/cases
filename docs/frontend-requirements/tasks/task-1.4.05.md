# TASK-1.4.05

**User Story:** [US-1.4: Просмотр профиля другого игрока](../user-stories/us-1.4.md)  
**Статус:** Не начата  
**Исполнитель:** Иван Бачурин

## Описание

Создать универсальный компонент-заглушку для пустых состояний на странице профиля: когда нет выигрышей, нет инвентаря или другие данные отсутствуют.

## Детали реализации

- Создать переиспользуемый компонент EmptyState
- Принимает пропсы: иконка, заголовок, описание, необязательная ссылка/кнопка
- Стилизовать: центрирование, мягкие цвета, иконка сверху
- Использовать компонент в профиле пользователя для пустых секций

## Критерии приёмки

1. Компонент EmptyState отображается при отсутствии данных
2. Компонент принимает кастомные тексты и иконки
3. Компонент переиспользуем в разных местах приложения
