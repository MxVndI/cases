# TASK-4.1.02

**Название:** Реализовать блок статистики с четырьмя показателями  
**Эпик:** [Epic 4: Инвентарь и баланс](../epics/epic-04-inventory-balance.md)  
**User Story:** [US-4.1: Просмотр баланса и статистики](../user-stories/us-4.1.md)  
**Статус:** Не начата  
**Исполнитель:** Данил Косенко

## Описание

Создать блок статистики на странице баланса: общий доход, общий расход, количество открытых кейсов, количество проданных предметов.

## Детали реализации

- Четыре карточки: «Доход», «Расход», «Кейсов открыто», «Предметов продано»
- Каждая карточка: иконка (Lucide), значение, подпись
- Сетка 2x2 на десктопе, 1 колонка на мобильных
- Данные из dummy-data или state

## Критерии приёмки

1. Четыре карточки статистики отображаются
2. Каждая содержит иконку, значение и подпись
3. Адаптивная сетка 2x2 / 1 колонка
