# TASK-2.2.01

**Название:** Реализовать форму входа с полями: email и пароль  
**Эпик:** [Epic 2: Регистрация и авторизация](../epics/epic-02-auth.md)  
**User Story:** [US-2.2: Авторизация по email и паролю](../user-stories/us-2.2.md)  
**Статус:** Не начата  
**Исполнитель:** Николай Сгонник

## Описание

Создать страницу авторизации (`/login`) с формой входа, содержащей поля email и пароль.

## Детали реализации

- Создать страницу-компонент для маршрута `/login`
- Добавить поля: email и пароль
- Стилизовать форму аналогично регистрации: центрирование, карточка, логотип
- Кнопка «Войти»
- Использовать компоненты shadcn/ui для полей ввода

## Критерии приёмки

1. Страница `/login` отображает форму с 2 полями
2. Поля имеют подписи и placeholders
3. Кнопка «Войти» видна и стилизована
