**Название:** Добавить кнопку «Пропустить» поверх анимации рулетки  
**Эпик:** [Epic 3: Открытие кейсов](../epics/epic-03-case-opening.md)  
**User Story:** [US-3.2: Пропуск анимации](../user-stories/us-3.2.md)  
**Статус:** Не начата  
**Исполнитель:** Максим Небывалов

## Описание

Добавить кнопку «Пропустить» во время анимации рулетки, позволяющую пользователю мгновенно увидеть результат без ожидания.

## Детали реализации

- Кнопка появляется после начала анимации рула
- Расположить в правом верхнем углу или над рулеткой
- По клику — мгновенно завершить анимацию
- Кнопка исчезает после остановки рулетки

## Критерии приёмки

1. Кнопка «Пропустить» видна во время анимации
2. Клик мгновенно завершает анимацию
3. Кнопка исчезает после показа результата
