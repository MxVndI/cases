# TASK-7.1.05

**Название:** Реализовать список пользователей с информацией о каждом  
**Эпик:** [Epic 7: Администрирование](../epics/epic-07-admin.md)  
**User Story:** [US-7.1: Просмотр списка пользователей](../user-stories/us-7.1.md)  
**Статус:** Не начата  
**Исполнитель:** Максим Небывалов

## Описание

Отобразить список всех пользователей в табличном виде с ключевой информацией о каждом.

## Детали реализации

- Таблица или карточки с полями: никнейм, email, роль, статус, дата регистрации
- Бейджи для роли (admin/user) и статуса (active/blocked)
- Данные из dummy-data
- Поддержка фильтрации и поиска

## Критерии приёмки

1. Список пользователей отображается
2. Каждая запись содержит: никнейм, email, роль, статус, дату
3. Бейджи роли и статуса цветные
