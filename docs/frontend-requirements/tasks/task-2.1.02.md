## Описание

Реализовать клиентскую валидацию формы регистрации, проверяя заполненность всех полей и совпадение паролей перед отправкой.

## Детали реализации

- Проверить заполненность всех полей при попытке отправки
- Проверить совпадение полей «Пароль» и «Подтверждение пароля»
- Отображать ошибки валидации под соответствующими полями
- Блокировать кнопку «Зарегистрироваться» при наличии ошибок
- Валидация email: проверить наличие символа @ и домена

## Критерии приёмки

1. Форма не отправляется, если есть пустые поля
2. Отображается ошибка «Пароли не совпадают» при несовпадении
3. Ошибки валидации видны пользователю под полями
4. Кнопка заблокирована при невалидном состоянии формы
