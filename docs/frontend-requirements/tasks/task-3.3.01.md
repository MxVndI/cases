**User Story:** [US-3.3: Мульти-открытие кейсов](../user-stories/us-3.3.md)

**Исполнитель:** Максим Небывалов

## Описание

Добавить дополнительные кнопки для мульти-открытия кейсов: x3 и x5, расположенные рядом с кнопкой одиночного открытия.

## Детали реализации

- Разместить три кнопки: «Открыть x1», «Открыть x3», «Открыть x5»
- На каждой кнопке отображается итоговая стоимость (цена * множитель)
- Стилизация: x1 — основная, x3 и x5 — дополнительные
- Все кнопки отключены при недостаточном балансе

## Критерии приёмки

1. Три кнопки открытия видны на странице кейса
2. Стоимость на каждой кнопке корректна
3. Кнопки блокируются при недостаточном балансе
