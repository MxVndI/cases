# TASK-1.5.01

**Название:** Добавить условный рендеринг бейджа статуса (только для admin)  
**Эпик:** [Epic 1: Просмотр контента](../epics/epic-01-browsing.md)  
**User Story:** [US-1.5: Дополнительная информация для администратора](../user-stories/us-1.5.md)  
**Статус:** Не начата  
**Исполнитель:** Иван Бачурин

## Описание

На странице профиля другого пользователя добавить отображение бейджа со статусом аккаунта (`active`/`blocked`), видимого только для просматривающего администратора.

## Детали реализации

- Проверить роль текущего пользователя из AuthContext
- Если роль = admin, отобразить цветной бейдж рядом с никнеймом
- Зелёный бейдж «Активен» для `status: active`, красный «Заблокирован» для `blocked`
- Для обычных пользователей бейдж не рендерится

## Критерии приёмки

1. Администратор видит бейдж статуса на профиле другого пользователя
2. Бейдж корректно отражает текущий статус (active/blocked)
3. Обычный пользователь или гость не видит бейдж
