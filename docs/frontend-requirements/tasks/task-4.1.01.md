# TASK-4.1.01

**Название:** Реализовать карточку баланса с крупным отображением суммы  
**Эпик:** [Epic 4: Инвентарь и баланс](../epics/epic-04-inventory-balance.md)  
**User Story:** [US-4.1: Просмотр баланса и статистики](../user-stories/us-4.1.md)  
**Статус:** Не начата  
**Исполнитель:** Данил Косенко

## Описание

На странице баланса (`/balance`) отобразить карточку с текущим балансом CHC (CaseHubCoin) крупным шрифтом. Данные из `paymentApi.getBalance`. Анимация появления через CountUp.

## Детали реализации

- Создать страницу-компонент для маршрута `/balance`
- Баланс CHC крупным шрифтом с иконкой CaseHubCoin
- Данные из `paymentApi.getBalance`
- Анимация появления через CountUp (счётчик от 0 до текущего значения)
- Стилизовать карточку: градиентный фон или акцентный цвет

## Критерии приёмки

1. Баланс CHC отображается крупным шрифтом, данные из `paymentApi.getBalance`
2. Иконка CaseHubCoin видна рядом с суммой
3. CountUp-анимация при появлении
