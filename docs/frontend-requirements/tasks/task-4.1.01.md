# TASK-4.1.01

**Название:** Реализовать карточку баланса с крупным отображением суммы  
**Эпик:** [Epic 4: Инвентарь и баланс](../epics/epic-04-inventory-balance.md)  
**User Story:** [US-4.1: Просмотр баланса и статистики](../user-stories/us-4.1.md)  
**Статус:** Не начата  
**Исполнитель:** Данил Косенко

## Описание

На странице баланса (`/balance`) отобразить карточку с текущим балансом пользователя крупным шрифтом, с иконкой CaseHubCoin и анимацией появления.

## Детали реализации

- Создать страницу-компонент для маршрута `/balance`
- Отобразить баланс крупным шрифтом с иконкой монеты
- Анимация появления при загрузке (Framer Motion)
- Стилизовать карточку: градиентный фон или акцентный цвет
- Данные баланса из AuthContext/state

## Критерии приёмки

1. Баланс отображается крупным шрифтом
2. Иконка CaseHubCoin видна рядом с суммой
3. Анимация появления плавная
