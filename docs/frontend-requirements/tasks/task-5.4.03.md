**User Story:** [US-5.4: Настройки предпочтений](../user-stories/us-5.4.md)  
**Статус:** Не начата  
**Исполнитель:** Иван Бачурин

## Описание

При загрузке приложения `PreferencesContext` должен читать сохранённые настройки из `localStorage` и применять их. Если настроек нет — использовать значения по умолчанию (cursor: ON, countup: ON).

## Детали реализации

- `PreferencesContext` инициализируется из `localStorage` при монтировании
- Ключи localStorage: `pref_cursor`, `pref_countup` (или единый объект `preferences`)
- Значения по умолчанию: `{ cursor: true, countup: true }`
- При отсутствии данных в localStorage — использовать defaults

## Критерии приёмки

1. Предпочтения восстанавливаются при перезагрузке страницы
2. При первом визите применяются значения по умолчанию (оба ON)
