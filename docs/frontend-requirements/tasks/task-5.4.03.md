# TASK-5.4.03

**Название:** Блокировать кнопку при невалидных данных  
**Эпик:** [Epic 5: Профиль пользователя](../epics/epic-05-profile.md)  
**User Story:** [US-5.4: Смена пароля](../user-stories/us-5.4.md)  
**Статус:** Не начата  
**Исполнитель:** Иван Бачурин

## Описание

Кнопка «Сменить пароль» должна быть заблокирована, если хотя бы одно поле пустое или пароли не совпадают.

## Детали реализации

- Проверять все три поля на заполненность
- Проверять совпадение новых паролей
- Кнопка disabled при невалидном состоянии

## Критерии приёмки

1. Кнопка активна только при корректно заполненных полях
