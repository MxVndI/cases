# TASK-4.4.01

**Название:** Реализовать двухшаговый процесс продажи (клик, затем подтверждение)  
**Эпик:** [Epic 4: Инвентарь и баланс](../epics/epic-04-inventory-balance.md)  
**User Story:** [US-4.4: Продажа предмета из инвентаря](../user-stories/us-4.4.md)  
**Статус:** Не начата  
**Исполнитель:** Данил Косенко

## Описание

Реализовать продажу предмета из инвентаря в два шага: первый клик по «Продать» показывает подтверждение, второй — продаёт предмет.

## Детали реализации

- Первый клик — кнопка меняется на «Подтвердить» (красный/акцентный цвет)
- Второй клик — выполняет продажу
- Таймаут: если не подтвердить за 3 секунды, кнопка возвращается в исходное состояние
- Блокировать множественные клики во время обработки

## Критерии приёмки

1. Продажа требует двух кликов (защита от случайного нажатия)
2. Кнопка визуально меняется при подтверждении
3. Таймаут возвращает кнопку в исходное состояние
