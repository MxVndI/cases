# TASK-2.1.01

**Название:** Реализовать форму регистрации с полями: никнейм, email, пароль, подтверждение пароля  
**Эпик:** [Epic 2: Регистрация и авторизация](../epics/epic-02-auth.md)  
**User Story:** [US-2.1: Регистрация нового пользователя](../user-stories/us-2.1.md)  
**Статус:** Не начата  
**Исполнитель:** Николай Сгонник

## Описание

Создать страницу регистрации (`/register`) с формой, содержащей все необходимые поля для создания нового аккаунта.

## Детали реализации

- Создать страницу-компонент для маршрута `/register`
- Добавить поля ввода: никнейм, email, пароль, подтверждение пароля
- Использовать компоненты Input и Label из shadcn/ui
- Стилизовать форму: центрирование, карточка с тёмным фоном, логотип CaseHub сверху
- Добавить кнопку «Зарегистрироваться»

## Критерии приёмки

1. Страница `/register` отображает форму с 4 полями
2. Все поля имеют корректные подписи (labels)
3. Кнопка отправки присутствует и стилизована
4. Форма центрирована на странице
