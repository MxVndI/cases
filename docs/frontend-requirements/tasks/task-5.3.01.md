# TASK-5.3.01

**Название:** Реализовать форму редактирования профиля: никнейм (редактируемое) и email (только чтение)  
**Эпик:** [Epic 5: Профиль пользователя](../epics/epic-05-profile.md)  
**User Story:** [US-5.3: Редактирование профиля](../user-stories/us-5.3.md)  
**Статус:** Не начата  
**Исполнитель:** Иван Бачурин

## Описание

На вкладке «Настройки» создать форму редактирования профиля. Поле никнейма — редактируемое (text). Поле email — только для чтения (disabled/readOnly), т.к. email нельзя сменить.

## Детали реализации

- Поле никнейма: Input (text), редактируемое
- Поле email: Input (email), readOnly/disabled, визуально приглушено
- Использовать компоненты Input и Label из shadcn/ui
- Кнопка «Сохранить»

## Критерии приёмки

1. Форма отображается на вкладке «Настройки»
2. Никнейм редактируется, email только для чтения
3. Поля имеют подписи
