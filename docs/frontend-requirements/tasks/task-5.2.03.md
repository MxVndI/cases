**Исполнитель:** Иван Бачурин

## Описание

В списке истории открытий иконка/рамка предмета должна быть окрашена в цвет соответствующей редкости.

## Детали реализации

- Применить цвет рамки по маппингу: common → серый, rare → синий, epic → фиолетовый, legendary → оранжевый, exotic → красный
- Цвет применяется к border или background иконки предмета

## Критерии приёмки

1. Цветовая маркировка корректна для всех уровней редкости
2. Маркировка применяется к каждой записи
