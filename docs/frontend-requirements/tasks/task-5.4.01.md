# TASK-5.4.01

**Название:** Реализовать форму с полями: текущий пароль, новый пароль, подтверждение  
**Эпик:** [Epic 5: Профиль пользователя](../epics/epic-05-profile.md)  
**User Story:** [US-5.4: Смена пароля](../user-stories/us-5.4.md)  
**Статус:** Не начата  
**Исполнитель:** Иван Бачурин

## Описание

На вкладке «Настройки» (под формой профиля) создать форму смены пароля с тремя полями.

## Детали реализации

- Поля: «Текущий пароль», «Новый пароль», «Подтверждение пароля»
- Все поля типа password
- Кнопка «Сменить пароль»
- Визуально отделить от формы редактирования профиля

## Критерии приёмки

1. Форма с тремя полями отображается
2. Поля имеют тип password (ввод скрыт)
