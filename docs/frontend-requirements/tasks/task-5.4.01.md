## Описание

На вкладке «Настройки» профиля добавить toggle-переключатель для кастомного GSAP-курсора. По умолчанию включён (ON). Значение хранится в `PreferencesContext` и `localStorage`.

## Детали реализации

- Toggle-компонент (shadcn/ui Switch) с подписью «Кастомный курсор»
- Значение по умолчанию: ON (включён)
- При переключении — обновить `PreferencesContext` и `localStorage`
- Курсор управляется через GSAP в `__root.tsx`

## Критерии приёмки

1. Toggle-переключатель отображается на вкладке «Настройки»
2. По умолчанию включён
3. Переключение мгновенно влияет на отображение курсора
