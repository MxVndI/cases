# TASK-3.3.04

**Название:** Обеспечить продажу отдельных предметов из результатов мульти-открытия  
**Эпик:** [Epic 3: Открытие кейсов](../epics/epic-03-case-opening.md)  
**User Story:** [US-3.3: Мульти-открытие кейсов](../user-stories/us-3.3.md)  
**Статус:** Не начата  
**Исполнитель:** Максим Небывалов

## Описание

На экране мульти-открытия позволить пользователю продать каждый предмет индивидуально, нажав кнопку «Продать» на карточке.

## Детали реализации

- Кнопка «Продать» под каждой карточкой предмета
- При продаже: предмет помечается как «Продан», кнопка заменяется на галочку
- Баланс обновляется мгновенно после каждой продажи
- Добавить кнопку «Продать всё» для массовой продажи

## Критерии приёмки

1. Каждый предмет можно продать индивидуально
2. Сумма продажи начисляется на баланс
3. Проданный предмет визуально помечен
4. Кнопка «Продать всё» работает корректно
