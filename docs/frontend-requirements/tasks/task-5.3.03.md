## Описание

При нажатии «Сохранить» открывается OTP-диалог. Сначала отправляется `POST /api/user/profile/update/start` — бэкенд отправляет 6-значный код на email. Пользователь вводит код, затем отправляется `POST /api/user/profile/update/finish` с новым никнеймом и кодом.

## Детали реализации

- Клик «Сохранить» → `POST /api/user/profile/update/start` → OTP-диалог (shadcn/ui Dialog)
- OTP-диалог: компонент `input-otp` для 6-значного кода + кнопка «Подтвердить»
- Кнопка «Подтвердить» → `POST /api/user/profile/update/finish` с `{nickname, code}`
- При успехе — обновить `AuthContext`, закрыть диалог
- При ошибке — отобразить «Неверный код» в диалоге
- Индикатор загрузки на кнопках

## Критерии приёмки

1. Клик «Сохранить» отправляет запрос и открывает OTP-диалог
2. 6-значный OTP вводится в диалоге
3. После подтверждения никнейм обновляется
4. При неверном коде — ошибка в диалоге
