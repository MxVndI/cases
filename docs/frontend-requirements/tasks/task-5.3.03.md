**Название:** Реализовать отправку данных на сервер  
**Эпик:** [Epic 5: Профиль пользователя](../epics/epic-05-profile.md)

**Исполнитель:** Иван Бачурин

## Описание

Реализовать сохранение изменённых данных профиля. В мок-режиме — обновить state/localStorage.

## Детали реализации

- Собрать данные формы при клике «Сохранить»
- Обновить состояние пользователя в AuthContext
- В мок-режиме — сохранить в localStorage
- Индикатор загрузки на кнопке

## Критерии приёмки

1. Данные сохраняются при нажатии «Сохранить»
2. Обновлённые данные видны в профиле
