# TASK-6.2.02

**Название:** Для каждого улучшения: отобразить текущий уровень, стоимость, описание эффекта  
**Эпик:** [Epic 6: Ферма (кликер)](../epics/epic-06-farm.md)  
**User Story:** [US-6.2: Покупка улучшений](../user-stories/us-6.2.md)  
**Статус:** Не начата  
**Исполнитель:** Николай Сгонник

## Описание

Карточка каждого улучшения должна отображать: текущий уровень, стоимость следующего уровня, описание эффекта. При достижении максимального уровня показывать «MAX».

## Детали реализации

- Уровень: «Уровень N»
- Стоимость следующего уровня: «N CHC» с иконкой
- Описание эффекта: например «+50% к доходу за клик»
- При максимальном уровне отображать «MAX» вместо стоимости, кнопка покупки заблокирована
- Визуально различать доступные (хватает CHC) и недоступные улучшения

## Критерии приёмки

1. Каждая карточка содержит уровень, стоимость следующего уровня и описание эффекта
2. При максимальном уровне отображается «MAX»
3. Доступные и недоступные улучшения визуально различаются
