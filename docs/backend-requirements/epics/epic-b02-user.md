# Epic B2: Управление пользователями

**Описание:** Микросервис пользователей отвечает за хранение и управление данными пользователей: создание при первом входе, получение профиля, обновление данных. Взаимодействует с auth-сервисом через Redis Streams RPC. Данные хранятся в MongoDB (Beanie ODM).

**Роли:** Пользователь  
**Связанные маршруты:** /api/user/v1/*  
**Зависимости:** Epic B1: Аутентификация — для валидации сессий
