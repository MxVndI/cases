# Epic B5: Администрирование (API)

**Описание:** API для административной панели: просмотр всех пользователей с фильтрацией, поиском и пагинацией, блокировка/разблокировка пользователей, проверка прав администратора через middleware.

**Роли:** Администратор  
**Связанные маршруты:** /api/admin/*  
**Зависимости:** Epic B1: Аутентификация — для проверки сессии и роли
