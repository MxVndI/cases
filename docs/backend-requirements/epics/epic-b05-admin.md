# Epic B5: Администрирование (API)

**Описание:** API для административной панели. На текущий момент реализован сервис-BFF (Backend for Frontend), который предоставляет локальную аутентификацию по логину/паролю (статический секрет в конфиге) и проксирует CRUD кейсов к Cases Service. Управление пользователями (просмотр, блокировка) — в стадии разработки.

**Роли:** Администратор  
**Связанные маршруты:** /api/admin/*  
**Зависимости:** Epic B3: Кейсы — кейсовые операции проксируются через Admin Service к Cases Service

> **Текущая реализация:** Admin Service реализован как BFF. Аутентификация — статическая: `POST /login/` принимает `{login, password}` и возвращает `secret`-токен, который подставляется при запросах к Cases Service. Роутер пользователей (`/users`) определён, но маршруты не реализованы — это задачи данного эпика.
