# Epic B3: Управление кейсами

**Описание:** Сервис управления кейсами обеспечивает полный жизненный цикл кейсов: создание, редактирование, удаление (для администраторов через токен), получение списка кейсов и их содержимого, открытие кейса с авторизацией через cookie. Игровая логика (выбор предмета по вероятностям, списание баланса, добавление в инвентарь, история открытий) реализована частично и продолжается в рамках отдельных задач.

**Роли:** Гость, Пользователь, Администратор  
**Связанные маршруты:** /api/cases/*, /api/items/*  
**Зависимости:** Epic B4: Инвентарь — для добавления предметов после открытия; Epic B1: Auth — для проверки cookie при открытии кейса

> **Примечание об архитектуре:** Предметы (Items) хранятся отдельно от кейсов. Отдельного эндпоинта `/cases/{id}/items` нет — содержимое кейса с вероятностями возвращается в поле `case_content` при `GET /cases/{id}`. Мутации (POST/PATCH/DELETE) защищены статическим `token`, передаваемым в теле запроса (не через cookie/JWT).
