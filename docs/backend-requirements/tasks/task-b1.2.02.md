## Описание

Реализовать генерацию одноразового 6-символьного кода и сохранение в Redis с TTL.

## Детали реализации

- Использовать shortuuid.ShortUUID().random(length=6)
- Сохранить через RedisService.create(prefix="cvid:", key=str(uuid), value=code, ttl=600)
- UUID используется как ключ для связи с cookie

## Критерии приёмки

1. Код длиной 6 символов
2. Код сохранён в Redis с TTL 10 минут
3. Код уникален для каждого запроса
