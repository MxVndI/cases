# TASK-B4.3.03

**Название:** Удалять/помечать предмет как sold  
**Эпик:** [Epic B4: Инвентарь и баланс](../epics/epic-b04-inventory.md)  
**User Story:** [B-US-4.3: Продажа предметов](../user-stories/b-us-4.3.md)  
**Статус:** Не начата  
**Исполнитель:** Владимир Таран

## Описание

После продажи пометить предмет как sold (не удалять физически для истории).

## Детали реализации

- Обновить status: active → sold
- Установить sold_at = now()
- Предмет перестаёт появляться в активном инвентаре

## Критерии приёмки

1. Статус меняется на sold
2. Предмет не виден в активном инвентаре
3. Запись сохраняется для истории
