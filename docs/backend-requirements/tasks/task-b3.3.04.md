## Описание

Атомарно списать стоимость кейса с баланса пользователя.

## Детали реализации

- Использовать MongoDB findOneAndUpdate с $inc: {balance: -price}
- Проверить, что результат balance >= 0
- При race condition (баланс стал отрицательным) — откатить

## Критерии приёмки

1. Баланс уменьшается на цену кейса
2. Атомарность гарантирована
3. Race condition обрабатывается
