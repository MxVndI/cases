## Описание

Получение детальной информации о пользователе по ID для админ-панели.

## Детали реализации

- GET /admin/users/{userId}
- Middleware admin
- Вернуть полные данные пользователя
- 404 если не найден

## Критерии приёмки

1. Данные пользователя возвращаются
2. 404 для несуществующего
3. 403 для не-admin
