# TASK-B3.1.04

**Название:** Реализовать эндпоинт PUT /cases/{id} (admin)  
**Эпик:** [Epic B3: Управление кейсами](../epics/epic-b03-cases.md)  
**User Story:** [B-US-3.1: CRUD кейсов](../user-stories/b-us-3.1.md)  
**Статус:** Не начата  
**Исполнитель:** Андрей Пикулев

## Описание

Защищённый эндпоинт для обновления существующего кейса.

## Детали реализации

- PUT /cases/{id}, тело: обновляемые поля
- Middleware admin
- Найти кейс по ID, обновить поля
- 404 если не найден

## Критерии приёмки

1. Кейс обновляется
2. 404 для несуществующего ID
3. 403 для не-admin
