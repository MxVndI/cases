## Описание

Защищённый эндпоинт для обновления существующего кейса.

## Детали реализации

- `PATCH /cases/`, тело: `UpdateCase` (содержит `id: UUID` + обновляемые поля)
- ID кейса передаётся в теле запроса, а не в пути
- Авторизация через `token` (в теле, не в заголовках): поле исключается из сохраняемых данных
- Обновляются только переданные (не None) поля через `.items()`
- Возвращает UUID обновлённого кейса или None если не найден

## Критерии приёмки

1. Кейс обновляется при корректном `id` и валидном токене
2. Поля, не переданные в запросе, остаются без изменений
3. Неверный токен → 403
