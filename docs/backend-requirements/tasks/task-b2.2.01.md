## Описание

REST API эндпоинт для частичного обновления профиля текущего пользователя.

## Детали реализации

- Создать роут PATCH /v1/users/me
- Принять SimpleUpdateRequest(email, nickname)
- Dependency get_current_user_id
- Обновить только переданные (не None) поля
- Сохранить в MongoDB

## Критерии приёмки

1. Профиль обновляется частично
2. Не переданные поля не изменяются
3. 401 для неавторизованного
