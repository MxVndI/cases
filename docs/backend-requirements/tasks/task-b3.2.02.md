## Описание

Публичный эндпоинт для получения списка предметов конкретного кейса.

## Детали реализации

- GET /cases/{case_id}/items
- Найти кейс по ID
- Вернуть список предметов с полной информацией
- 404 если кейс не найден

## Критерии приёмки

1. Предметы кейса возвращаются
2. Доступен без авторизации
3. 404 для несуществующего кейса
