## Описание

Публичные эндпоинты для работы с предметами. Предметы хранятся отдельно от кейсов и связываются через `case_content`.

## Детали реализации

- `GET /items/` — список всех предметов (`list[ItemResponse]`), без авторизации
- `GET /items/{id}` — один предмет по UUID (`ItemResponse | None`), без авторизации
- Содержимое конкретного кейса возвращается в поле `case_content` при `GET /cases/{id}` — список пар `(ItemResponse, drop_chance: float)`
- Отдельного эндпоинта `GET /cases/{id}/items` нет: предметы кейса приходят вместе с данными кейса

## Критерии приёмки

1. `GET /items/` возвращает все предметы
2. `GET /cases/{id}` включает `case_content` с предметами и их вероятностями
3. Доступны без авторизации
