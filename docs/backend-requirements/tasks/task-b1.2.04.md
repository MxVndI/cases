# TASK-B1.2.04

**Название:** Реализовать эндпоинт POST /email/login/finish  
**Эпик:** [Epic B1: Аутентификация и авторизация](../epics/epic-b01-auth.md)  
**User Story:** [B-US-1.2: Авторизация по email (код подтверждения)](../user-stories/b-us-1.2.md)  
**Статус:** Не начата  
**Исполнитель:** Никита Миков

## Описание

Создать эндпоинт для подтверждения кода: проверка с Redis, создание сессии при совпадении.

## Детали реализации

- Принять LoginFinishRequest(code) и cookies (email, cvid)
- Получить реальный код из Redis по ключу cvid:{cvid}
- Сравнить введённый код с сохранённым
- При совпадении — вызвать register_user(email, "email")
- При несовпадении — redirect на /auth-error

## Критерии приёмки

1. Корректный код → авторизация
2. Некорректный код → /auth-error
3. Истёкший код → /auth-error
