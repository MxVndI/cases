## Описание

Эндпоинт для перевода заработанных монет фермы в основной баланс пользователя.

## Детали реализации

- POST /farm/collect, тело: {amount: N}
- Авторизация обязательна
- Проверить: amount <= farm_balance
- Списать из farm_balance, начислить в основной balance

## Критерии приёмки

1. Монеты переводятся
2. farm_balance уменьшается
3. Основной balance увеличивается
