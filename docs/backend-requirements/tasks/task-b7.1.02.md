## Описание

Эндпоинт для загрузки текущего прогресса фермы пользователя.

## Детали реализации

- GET /farm/state — авторизация обязательна
- Найти FarmState по user_id
- Если не найден — вернуть default (все уровни = 0, баланс = 0)

## Критерии приёмки

1. Прогресс возвращается
2. Default для нового пользователя
3. 401 без авторизации
