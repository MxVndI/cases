## Описание

Защищённый эндпоинт для открытия кейса. Текущая реализация проверяет авторизацию и возвращает UID пользователя; полная игровая логика (рандом, списание, инвентарь) реализуется в следующих задачах.

## Детали реализации

- `GET /cases/open/{id}` — путь: `id: UUID` (ID кейса)
- Авторизация через cookie `sid` → запрос к auth service (`/verify_user/{ssid}?token=...`)
- Текущий возврат: UID авторизованного пользователя
- Для полной логики необходимо дополнить: проверка баланса, взвешенный рандом, списание, инвентарь

## Критерии приёмки

1. Эндпоинт возвращает UID при наличии валидного cookie `sid`
2. 401/403 при отсутствии или невалидном `sid`
3. 404 если кейс не найден (при полной реализации)
