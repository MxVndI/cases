**Исполнитель:** Андрей Пикулев

## Описание

Защищённый эндпоинт для открытия кейса: проверка баланса, рандом, списание, добавление в инвентарь.

## Детали реализации

- POST /cases/{case_id}/open
- Авторизация обязательна
- Вызвать сервис открытия кейса
- Вернуть выпавший предмет

## Критерии приёмки

1. Кейс открывается при достаточном балансе
2. 400 при недостаточном балансе
3. 404 для несуществующего кейса
