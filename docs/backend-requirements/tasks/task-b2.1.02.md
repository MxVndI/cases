## Описание

Метод, который ищет пользователя по email. Если не найден — создаёт нового с default-значениями.

## Детали реализации

- User.find_one(User.email == email)
- Если None — создать User(email=email), await data.save()
- Вернуть User

## Критерии приёмки

1. Существующий пользователь возвращается
2. Новый пользователь создаётся и возвращается
3. Default nickname генерируется для нового
