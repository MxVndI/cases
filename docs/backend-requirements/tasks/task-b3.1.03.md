## Описание

Защищённый эндпоинт для создания кейса (только admin).

## Детали реализации

- POST /cases, тело: {name, price, items, category}
- Middleware проверки роли admin
- Валидация: name не пустой, price > 0, items не пустой
- Создать Case и сохранить

## Критерии приёмки

1. Кейс создаётся при валидных данных
2. 403 для не-admin
3. 400 при невалидных данных
