## Описание

После верификации OAuth создать сессию: запросить данные пользователя через RPC, создать Session в MongoDB, кешировать в Redis.

## Детали реализации

- Отправить RPC на user.rpc: {email, action: "get"}
- Получить данные пользователя (или null при таймауте)
- Создать Session(email, auth_source, custom_data={user: data})
- Сохранить через SessionRepo (MongoDB + Redis cache)

## Критерии приёмки

1. Сессия создаётся в MongoDB
2. Сессия кешируется в Redis
3. Данные пользователя сохранены в custom_data
4. При таймауте RPC сессия создаётся без данных
