# TASK-B2.2.03

**Название:** Обновить данные в MongoDB и обновить сессию  
**Эпик:** [Epic B2: Управление пользователями](../epics/epic-b02-user.md)  
**User Story:** [B-US-2.2: Обновление профиля пользователя](../user-stories/b-us-2.2.md)  
**Статус:** Не начата  
**Исполнитель:** Никита Григоренко

## Описание

После обновления профиля в MongoDB обновить данные пользователя в сессии через RPC.

## Детали реализации

- Сохранить обновлённого пользователя в MongoDB
- Отправить обновлённые данные в сессию через Auth Service
- Установить last_updated = now()

## Критерии приёмки

1. Данные обновлены в MongoDB
2. Сессия содержит актуальные данные
3. last_updated обновлён
