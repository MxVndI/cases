# TASK-B5.2.02

**Название:** Проверять, что целевой пользователь не admin  
**Эпик:** [Epic B5: Администрирование (API)](../epics/epic-b05-admin.md)  
**User Story:** [B-US-5.2: Блокировка и разблокировка (admin)](../user-stories/b-us-5.2.md)  
**Статус:** Не начата  
**Исполнитель:** Никита Миков

## Описание

Запретить блокировку пользователей с ролью admin.

## Детали реализации

- Загрузить целевого пользователя
- Проверить role != "admin"
- HTTPException 400: "Cannot block admin user"

## Критерии приёмки

1. Admin нельзя заблокировать
2. Корректное сообщение об ошибке
