## Описание

Создать эндпоинт, инициирующий OAuth-поток: формирует URL авторизации провайдера и перенаправляет пользователя.

## Детали реализации

- Создать роут GET /{provider}/login с параметром provider: Literal["yandex", "discord"]
- Получить SSO-объект из sso_dict по provider
- Вызвать sso.get_login_redirect()
- Вернуть redirect-ответ на URL провайдера

## Критерии приёмки

1. Эндпоинт доступен для yandex и discord
2. Перенаправление на корректный URL провайдера
3. При невалидном провайдере — 422
