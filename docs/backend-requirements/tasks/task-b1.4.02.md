**Название:** Обрабатывать RPC-запросы на валидацию sid

## Описание

В обработчике auth.rpc: извлечь sid, верифицировать подпись, вернуть данные сессии.

## Детали реализации

- Извлечь sid из msg.get("sid")
- Вызвать verify_session(sid) → UUID
- Получить сессию по UUID
- Вернуть session.model_dump()

## Критерии приёмки

1. Валидный sid → данные сессии
2. Невалидный sid → None
3. Истёкшая сессия → None
