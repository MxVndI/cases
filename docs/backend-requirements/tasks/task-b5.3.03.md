## Описание

Логировать все попытки доступа к admin-эндпоинтам от не-администраторов.

## Детали реализации

- logger.warning(f"Unauthorized admin access attempt: user_id={uid}")
- Включить: user_id, endpoint, timestamp
- Уровень: WARNING

## Критерии приёмки

1. Попытки логируются
2. Лог содержит user_id и endpoint
