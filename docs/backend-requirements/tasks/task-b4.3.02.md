# TASK-B4.3.02

**Название:** Начислять стоимость при продаже  
**Эпик:** [Epic B4: Инвентарь и баланс](../epics/epic-b04-inventory.md)  
**User Story:** [B-US-4.3: Продажа предметов](../user-stories/b-us-4.3.md)  
**Статус:** Не начата  
**Исполнитель:** Владимир Таран

## Описание

При продаже предмета начислить его стоимость на баланс пользователя.

## Детали реализации

- Получить price предмета из Item
- Вызвать BalanceService.credit(user_id, price)
- Атомарность: списание + начисление в одной транзакции

## Критерии приёмки

1. Баланс увеличивается на стоимость предмета
2. Операция атомарна
