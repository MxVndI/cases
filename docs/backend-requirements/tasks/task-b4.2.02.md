## Описание

Эндпоинт для получения инвентаря пользователя.

## Детали реализации

- GET /user_inventory/{userId}
- Авторизация обязательна
- Найти все InventoryItem по user_id со status=active
- Джойн с Item для полных данных о предмете

## Критерии приёмки

1. Инвентарь возвращается
2. Только active предметы
3. 401 без авторизации
