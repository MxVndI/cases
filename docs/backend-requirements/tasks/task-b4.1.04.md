## Описание

Гарантировать транзакционность финансовых операций с балансом.

## Детали реализации

- Использовать MongoDB $inc оператор (атомарный)
- Для сложных операций — MongoDB transactions
- Проверка balance >= amount через $where или findOneAndUpdate filter

## Критерии приёмки

1. Concurrent операции не приводят к отрицательному балансу
2. Нет потерянных обновлений
