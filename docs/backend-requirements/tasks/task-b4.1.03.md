## Описание

Создать BalanceService с атомарными методами credit и debit.

## Детали реализации

- credit(user_id, amount): $inc balance +amount
- debit(user_id, amount): $inc balance -amount с проверкой >= 0
- Использовать findOneAndUpdate для атомарности

## Критерии приёмки

1. Начисление увеличивает баланс
2. Списание уменьшает баланс
3. Отрицательный баланс невозможен
