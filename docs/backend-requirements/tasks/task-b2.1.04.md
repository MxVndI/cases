## Описание

REST API эндпоинт для получения профиля текущего авторизованного пользователя.

## Детали реализации

- Создать роут GET /v1/users/me
- Dependency get_current_user_id: извлечь sid → RPC auth.rpc → user_id
- Вызвать UserService.get_user_by_id(uid)
- Вернуть User или 404

## Критерии приёмки

1. Авторизованный пользователь получает свой профиль
2. 401 при отсутствии/невалидном sid
3. 404 если пользователь не найден
