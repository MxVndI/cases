**Название:** Реализовать связь кейс-предметы с drop_chance  
**Эпик:** [Epic B3: Управление кейсами](../epics/epic-b03-cases.md)  
**User Story:** [B-US-3.2: Содержимое кейса (предметы)](../user-stories/b-us-3.2.md)  
**Статус:** Не начата  
**Исполнитель:** Андрей Пикулев

## Описание

Реализовать хранение связей между кейсом и предметами, включая вероятность выпадения.

## Детали реализации

- Embedded документ или отдельная коллекция: case_id, item_id, drop_chance
- Сумма drop_chance для кейса ≈ 100%
- drop_chance определяет вес предмета при рандоме

## Критерии приёмки

1. Связи хранятся и читаются
2. drop_chance используется при открытии
