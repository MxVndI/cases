## Описание

Атомарно перевести монеты из баланса фермы в основной баланс пользователя.

## Детали реализации

- Уменьшить farm_balance в FarmState
- Увеличить balance в User
- Обе операции в одной транзакции (или sequential с проверкой)

## Критерии приёмки

1. Перевод атомарный
2. Нет потери средств
3. Нет дублирования
