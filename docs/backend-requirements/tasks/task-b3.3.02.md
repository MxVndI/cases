**Исполнитель:** Андрей Пикулев

## Описание

Реализовать взвешенный случайный выбор предмета из кейса на основе drop_chance.

## Детали реализации

- Загрузить все предметы кейса с drop_chance
- Нормализовать вероятности (сумма = 1.0)
- Использовать random.choices(items, weights=chances, k=1)
- Вернуть выбранный предмет

## Критерии приёмки

1. Выбор случайный, но соответствует вероятностям
2. При многократных вызовах распределение соответствует drop_chance
3. Корректно работает с любым количеством предметов
