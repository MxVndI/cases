# TASK-B3.4.02

**Название:** Сохранять открытия в Redis List (maxlen)  
**Эпик:** [Epic B3: Управление кейсами](../epics/epic-b03-cases.md)  
**User Story:** [B-US-3.4: Последние открытия](../user-stories/b-us-3.4.md)  
**Статус:** Не начата  
**Исполнитель:** Андрей Пикулев

## Описание

При каждом открытии кейса добавлять запись в Redis list с ограничением длины.

## Детали реализации

- LPUSH recently_opened {json}
- LTRIM recently_opened 0 49 (хранить последние 50)
- Данные: user, item, case, date

## Критерии приёмки

1. Список не превышает 50 записей
2. Новые записи добавляются в начало
