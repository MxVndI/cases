## Описание

При блокировке пользователя инвалидировать все его активные сессии.

## Детали реализации

- Найти все сессии по email заблокированного
- Удалить из Redis и MongoDB
- Заблокированный не сможет продолжить работу

## Критерии приёмки

1. Сессии удалены
2. Пользователь разлогинен
3. Новый вход заблокирован (проверка status)
