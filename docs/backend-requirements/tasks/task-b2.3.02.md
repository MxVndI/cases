## Описание

Обработать RPC-запрос action="get": получить пользователя по email (с автосозданием).

## Детали реализации

- Проверить msg.get("action") == "get"
- Извлечь email из msg.get("email")
- Вызвать UserService.get_user_by_email(email)
- Вернуть user.model_dump()

## Критерии приёмки

1. Существующий пользователь возвращается
2. Новый пользователь создаётся
3. Ответ — валидный JSON
