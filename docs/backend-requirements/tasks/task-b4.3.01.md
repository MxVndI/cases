# TASK-B4.3.01

**Название:** Реализовать эндпоинт POST /user_inventory/{itemId}/sell  
**Эпик:** [Epic B4: Инвентарь и баланс](../epics/epic-b04-inventory.md)  
**User Story:** [B-US-4.3: Продажа предметов](../user-stories/b-us-4.3.md)  
**Статус:** Не начата  
**Исполнитель:** Владимир Таран

## Описание

Эндпоинт для продажи предмета из инвентаря.

## Детали реализации

- POST /user_inventory/{itemId}/sell
- Авторизация обязательна
- Проверить владение предметом
- Проверить status = active
- Начислить стоимость, пометить sold

## Критерии приёмки

1. Предмет продаётся
2. Баланс увеличивается
3. 403 для чужого предмета
4. 400 для уже проданного
