# TASK-B3.3.03

**Название:** Проверять баланс перед открытием  
**Эпик:** [Epic B3: Управление кейсами](../epics/epic-b03-cases.md)  
**User Story:** [B-US-3.3: Открытие кейса (игровая логика)](../user-stories/b-us-3.3.md)  
**Статус:** Не начата  
**Исполнитель:** Андрей Пикулев

## Описание

Перед открытием кейса проверить, что баланс пользователя >= стоимости кейса.

## Детали реализации

- Получить баланс пользователя
- Сравнить с ценой кейса
- Если недостаточно → HTTPException 400
- Сообщение: "Insufficient balance"

## Критерии приёмки

1. Открытие блокируется при недостатке средств
2. Сообщение об ошибке информативно
