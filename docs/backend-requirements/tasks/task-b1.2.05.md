# TASK-B1.2.05

**Название:** Валидировать код из cookie (cvid) с Redis  
**Эпик:** [Epic B1: Аутентификация и авторизация](../epics/epic-b01-auth.md)  
**User Story:** [B-US-1.2: Авторизация по email (код подтверждения)](../user-stories/b-us-1.2.md)  
**Статус:** Не начата  
**Исполнитель:** Никита Миков

## Описание

Реализовать логику проверки: извлечь cvid из cookie, получить код из Redis, сравнить.

## Детали реализации

- Извлечь cvid из Cookie (Pydantic model)
- Запросить Redis: GET cvid:{cvid}
- Сравнить значение с присланным кодом
- После валидации удалить ключ из Redis

## Критерии приёмки

1. Код проверяется корректно
2. Ключ удаляется после использования
3. Отсутствующий ключ обрабатывается
