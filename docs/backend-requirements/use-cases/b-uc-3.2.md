# B-UC-3.2: Открытие кейса пользователем

**Эпик:** [Epic B3: Управление кейсами](../epics/epic-b03-cases.md)

## Описание

Открытие кейса пользователем

## Акторы

- **Первичный:** Пользователь
- **Система:** Case Service

## Предусловия

Пользователь авторизован, выбрал кейс для открытия

## Основной сценарий

1. Фронтенд отправляет POST /api/cases/{case_id}/open
2. Case Service проверяет авторизацию
3. Case Service загружает кейс и его предметы с вероятностями
4. Проверяется баланс >= цена кейса
5. Генерируется случайный предмет на основе взвешенных вероятностей
6. Списывается стоимость кейса с баланса (атомарная операция)
7. Предмет добавляется в инвентарь пользователя
8. Открытие записывается в историю
9. Запись добавляется в recently_opened (Redis list)
10. Возвращается выпавший предмет

## Постусловия

Баланс уменьшен, предмет в инвентаре, запись в истории

## Альтернативные сценарии

1. Недостаточно средств → 400
2. Кейс не найден → 404
3. Кейс пуст (нет предметов) → 400
