# B-UC-4.1: Продажа предмета из инвентаря

**Эпик:** [Epic B4: Инвентарь и баланс](../epics/epic-b04-inventory.md)

## Описание

Продажа предмета из инвентаря

## Акторы

- **Первичный:** Пользователь
- **Система:** Inventory Service

## Предусловия

Пользователь авторизован, имеет предмет в инвентаре

## Основной сценарий

1. Фронтенд отправляет POST /api/user_inventory/{itemId}/sell
2. Inventory Service проверяет авторизацию
3. Проверяется, что предмет принадлежит пользователю
4. Проверяется, что предмет имеет статус active (не продан)
5. Начисляется стоимость предмета на баланс пользователя
6. Статус предмета меняется на sold
7. Возвращается обновлённый баланс

## Постусловия

Предмет продан, баланс увеличен

## Альтернативные сценарии

1. Предмет не принадлежит пользователю → 403
2. Предмет уже продан → 400
3. Предмет не найден → 404
