# B-UC-1.2: Авторизация по email

**Эпик:** [Epic B1: Аутентификация и авторизация](../epics/epic-b01-auth.md)

## Описание

Авторизация по email

## Акторы

- **Первичный:** Гость
- **Система:** Auth Service

## Предусловия

Гость находится на странице входа по email

## Основной сценарий

1. Гость вводит email и нажимает «Войти»
2. Фронтенд отправляет POST /email/login/start с email
3. Auth Service генерирует UUID (cvid) и 6-символьный код
4. Код сохраняется в Redis с ключом cvid:{uuid}, TTL 10 минут
5. Auth Service отправляет код на email через SMTP (MailSender)
6. Устанавливаются cookies: email и cvid
7. Пользователь перенаправляется на форму ввода кода
8. Гость вводит код и нажимает «Подтвердить»
9. Фронтенд отправляет POST /email/login/finish с кодом
10. Auth Service считывает cvid из cookie, проверяет код в Redis
11. При совпадении — создаётся сессия (как в UC-B1.1)

## Постусловия

Пользователь авторизован, cookie sid установлен

## Альтернативные сценарии

1. Неверный код → перенаправление на /auth-error
2. Истёк TTL кода (10 мин) → ключ удалён из Redis, ошибка
3. Ошибка отправки email → 500
