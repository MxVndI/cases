# B-UC-3.1: Создание кейса администратором

**Эпик:** [Epic B3: Управление кейсами](../epics/epic-b03-cases.md)

## Описание

Создание кейса администратором

## Акторы

- **Первичный:** Администратор
- **Система:** Case Service

## Предусловия

Администратор авторизован и открыл панель управления кейсами

## Основной сценарий

1. Администратор заполняет форму: название, цена, предметы, категория
2. Фронтенд отправляет POST /api/cases с JWT/cookie и данными
3. Middleware проверяет роль admin
4. Case Service валидирует данные (название, цена > 0, предметы не пустые)
5. Создаётся документ Case в MongoDB
6. Для каждого предмета сохраняется связь case_id → item_id с drop_chance
7. Возвращается созданный кейс

## Постусловия

Кейс создан и доступен для просмотра/открытия

## Альтернативные сценарии

1. Невалидные данные → 400 с описанием ошибок
2. Нет прав admin → 403
3. Сумма вероятностей != 100% → предупреждение
