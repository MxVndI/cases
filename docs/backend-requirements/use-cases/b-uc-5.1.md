# B-UC-5.1: Управление пользователями (admin)

**Эпик:** [Epic B5: Администрирование (API)](../epics/epic-b05-admin.md)

## Описание

Управление пользователями (admin)

## Акторы

- **Первичный:** Администратор
- **Система:** Admin Service

## Предусловия

Администратор авторизован и открыл панель управления

## Основной сценарий

1. Фронтенд отправляет GET /api/admin/users с параметрами фильтрации
2. Middleware проверяет роль admin
3. Admin Service формирует запрос к MongoDB с фильтрами (status, role, search)
4. Применяется пагинация (offset/limit)
5. Возвращается список пользователей
6. Для блокировки: POST /api/admin/users/{userId} с {block: true}
7. Admin Service проверяет, что целевой пользователь не admin
8. Обновляется статус пользователя
9. Инвалидируются сессии заблокированного

## Постусловия

Администратор просматривает и управляет пользователями

## Альтернативные сценарии

1. Нет прав admin → 403
2. Попытка заблокировать admin → 400
