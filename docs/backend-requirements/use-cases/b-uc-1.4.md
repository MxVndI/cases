# B-UC-1.4: Logout и верификация профиля

**Эпик:** [Epic B1: Аутентификация и авторизация](../epics/epic-b01-auth.md)

## Акторы
- Авторизованный пользователь

## Предусловия
- Пользователь авторизован (cookie `sid` установлен)

## Основной сценарий: Logout

1. Пользователь отправляет `POST /logout`
2. Система извлекает `sid` из cookie
3. Система верифицирует подпись сессии (HMAC-SHA256)
4. Система удаляет сессию из MongoDB (через SessionService)
5. Система очищает cookie `sid` (для корневого пути и домена)
6. Система возвращает `{ok: true}`

## Альтернативный сценарий: Верификация профиля

1. Пользователь отправляет `POST /profile/update/start`
2. Система извлекает `sid`, верифицирует сессию, получает email пользователя
3. Система генерирует код верификации и отправляет на email
4. Система устанавливает cookie `cvid` с идентификатором верификации
5. Пользователь вводит код и отправляет `POST /profile/update/finish`
6. Система проверяет код из cookie `cvid` с Redis
7. Система возвращает подтверждение

## Постусловия
- **Logout:** Сессия удалена, cookie очищен, пользователь разлогинен
- **Верификация:** Код подтверждён, профиль можно обновить
