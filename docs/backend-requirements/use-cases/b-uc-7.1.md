# B-UC-7.1: Синхронизация прогресса фермы

**Эпик:** [Epic B7: Ферма — бэкенд](../epics/epic-b07-farm.md)

## Описание

Синхронизация прогресса фермы

## Акторы

- **Первичный:** Пользователь
- **Система:** Farm Service

## Предусловия

Пользователь авторизован и играет на ферме

## Основной сценарий

1. Фронтенд отправляет GET /api/farm/state для загрузки прогресса
2. Farm Service возвращает текущее состояние (или default для нового игрока)
3. Пользователь играет, фронтенд периодически отправляет POST /api/farm/state
4. Farm Service валидирует данные (античит: проверка скорости начисления)
5. Состояние сохраняется в MongoDB
6. При сборе монет: POST /api/farm/collect
7. Монеты переводятся в основной баланс пользователя

## Постусловия

Прогресс фермы синхронизирован, монеты переведены в баланс

## Альтернативные сценарии

1. Данные подозрительны (античит) → сброс до последнего валидного состояния
2. Farm state не найден → создаётся default state
