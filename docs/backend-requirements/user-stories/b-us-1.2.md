# B-US-1.2: Авторизация по email (код подтверждения)

**Эпик:** [Epic B1: Аутентификация и авторизация](../epics/epic-b01-auth.md)  
**Роль:** Гость

## User Story

Как гость, я хочу авторизоваться по email с помощью одноразового кода, чтобы войти без пароля через подтверждение на почте.

## Описание

Auth Service генерирует 6-символьный код, сохраняет в Redis с TTL 10 мин, отправляет на email через SMTP. Пользователь вводит код, Auth Service проверяет его через Redis и создаёт сессию.
