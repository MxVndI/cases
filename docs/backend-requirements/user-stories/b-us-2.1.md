# B-US-2.1: Создание и получение пользователя

**Эпик:** [Epic B2: Управление пользователями](../epics/epic-b02-user.md)  
**Роль:** Пользователь

## User Story

Как пользователь, я хочу, чтобы мой профиль создавался автоматически при первом входе и я мог получить свои данные.

## Описание

User Service хранит пользователей в MongoDB (Beanie). При первом запросе по email — автосоздание с default nickname. API эндпоинт GET /v1/users/me возвращает профиль текущего пользователя.
