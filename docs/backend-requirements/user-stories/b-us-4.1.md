# B-US-4.1: Управление балансом

**Эпик:** [Epic B4: Инвентарь и баланс](../epics/epic-b04-inventory.md)  
**Роль:** Пользователь

## User Story

Как пользователь, я хочу видеть свой баланс и иметь надёжную систему начисления/списания CaseHubCoin.

## Описание

Баланс хранится как поле модели User. Операции с балансом атомарны (MongoDB findOneAndUpdate). Сервис предоставляет методы для начисления и списания.
