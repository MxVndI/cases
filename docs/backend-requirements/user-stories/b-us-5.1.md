# B-US-5.1: Просмотр пользователей (admin)

**Эпик:** [Epic B5: Администрирование (API)](../epics/epic-b05-admin.md)  
**Роль:** Администратор

## User Story

Как администратор, я хочу видеть список всех пользователей с возможностью фильтрации и поиска.

## Описание

Admin API предоставляет эндпоинт со списком пользователей с фильтрацией по статусу/роли, поиском по email/nickname и пагинацией.
