# B-US-1.5: Верификация профиля и logout

**Эпик:** [Epic B1: Аутентификация и авторизация](../epics/epic-b01-auth.md)

**Как** авторизованный пользователь,  
**я хочу** иметь возможность выйти из системы и подтверждать свою личность при обновлении профиля,  
**чтобы** обеспечить безопасность аккаунта.

## Критерии приёмки

- [ ] `POST /logout` удаляет сессию из MongoDB, очищает cookie `sid` (для всех доменов)
- [ ] `POST /profile/update/start` отправляет код верификации на email текущего пользователя
- [ ] `POST /profile/update/finish` проверяет код из cookie `cvid` и возвращает подтверждение
- [ ] `GET /me` возвращает данные текущего пользователя по cookie `sid`
- [ ] `GET /verify_user/{ssid}?token=...` позволяет другим сервисам верифицировать сессию по token
