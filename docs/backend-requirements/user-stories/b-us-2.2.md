# B-US-2.2: Обновление профиля пользователя

**Эпик:** [Epic B2: Управление пользователями](../epics/epic-b02-user.md)  
**Роль:** Пользователь

## User Story

Как пользователь, я хочу обновлять свой профиль (никнейм, email, trade link), чтобы другие видели актуальную информацию.

## Описание

User Service предоставляет эндпоинт для частичного обновления профиля. Валидация входных данных через Pydantic-схемы.

## Задачи

| Код | Название |
|-----|----------|
| [TASK-B2.2.01](../tasks/task-b2.2.01.md) | Реализовать эндпоинт PATCH /v1/users/me |
| [TASK-B2.2.02](../tasks/task-b2.2.02.md) | Валидировать входные данные (SimpleUpdateRequest) |
| [TASK-B2.2.03](../tasks/task-b2.2.03.md) | Обновить данные в MongoDB и обновить сессию |
