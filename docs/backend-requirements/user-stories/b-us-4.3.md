# B-US-4.3: Продажа предметов

**Эпик:** [Epic B4: Инвентарь и баланс](../epics/epic-b04-inventory.md)  
**Роль:** Пользователь

## User Story

Как пользователь, я хочу продавать предметы из инвентаря за CaseHubCoin.

## Описание

При продаже: проверяется владение предметом, стоимость начисляется на баланс, статус предмета меняется на sold. Операции атомарны.

| [TASK-B4.3.03](../tasks/task-b4.3.03.md) | Удалять/помечать предмет как sold |
