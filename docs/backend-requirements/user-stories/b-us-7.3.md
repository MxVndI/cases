# B-US-7.3: Ежедневный бонус

**Эпик:** [Epic B7: Ферма — бэкенд](../epics/epic-b07-farm.md)

**Как** авторизованный пользователь,  
**я хочу** получать ежедневный бонус в 100 CHC,  
**чтобы** иметь дополнительный источник внутренней валюты.

## Критерии приёмки

- [ ] `POST /bonus/daily` (Payment Service) начисляет 100 CHC при первом вызове за 24 часа
- [ ] Повторный вызов в течение 24 часов возвращает `{success: false, message: "Бонус уже получен сегодня"}`
- [ ] Cooldown хранится в Redis (SET_EX, TTL 86400 сек)
- [ ] Аутентификация через cookie `sid` → Auth Service `/verify_user/{ssid}`
- [ ] Транзакция: system (UUID nil) → user, currency CHC, описание "Ежедневный бонус"

## Задачи

| Код | Название |
|-----|----------|
| TASK-B7.3.01 | Реализовать POST /bonus/daily (100 CHC, 24ч cooldown в Redis) |
