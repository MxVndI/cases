# B-US-1.1: OAuth авторизация (Discord, Яндекс)

**Эпик:** [Epic B1: Аутентификация и авторизация](../epics/epic-b01-auth.md)  
**Роль:** Гость

## User Story

Как гость, я хочу авторизоваться через OAuth-провайдер (Discord или Яндекс), чтобы быстро получить доступ к платформе без создания пароля.

## Описание

Auth Service обеспечивает вход через OAuth с помощью библиотеки fastapi-sso. При первом входе запрашивается или создаётся пользователь через RPC к User Service. После авторизации создаётся подписанная сессия и устанавливается cookie.
