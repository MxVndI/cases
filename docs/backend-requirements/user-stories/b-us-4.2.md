# B-US-4.2: Управление инвентарём

**Эпик:** [Epic B4: Инвентарь и баланс](../epics/epic-b04-inventory.md)  
**Роль:** Пользователь

## User Story

Как пользователь, я хочу видеть свой инвентарь предметов.

## Описание

Инвентарь хранится как коллекция InventoryItem в MongoDB. Каждый предмет привязан к user_id. Эндпоинт возвращает список с агрегацией суммарной стоимости.
