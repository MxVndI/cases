# B-US-3.2: Содержимое кейса (предметы)

**Эпик:** [Epic B3: Управление кейсами](../epics/epic-b03-cases.md)  
**Роль:** Гость

## User Story

Как гость, я хочу видеть список предметов кейса, чтобы оценить потенциальный выигрыш.

## Описание

Case Service хранит предметы (Item) и связи кейс-предметы с вероятностями. Публичный эндпоинт возвращает список предметов кейса.
