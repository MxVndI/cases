# B-US-5.4: Проксирование CRUD и загрузка файлов

**Эпик:** [Epic B5: Администрирование (BFF)](../epics/epic-b05-admin.md)

**Как** администратор,  
**я хочу** управлять всеми сущностями (кейсы, предметы, редкости, теги, оружие, типы оружия) и загружать изображения через единый API,  
**чтобы** не взаимодействовать напрямую с внутренними сервисами.

## Критерии приёмки

- [ ] Admin Service проксирует CRUD кейсов к Cases Service (`/admin/cases/*`)
- [ ] Admin Service проксирует CRUD предметов к Cases Service (`/admin/items/*`)
- [ ] Admin Service проксирует CRUD редкостей, тегов, оружия, типов оружия к Cases Service
- [ ] `POST /admin/upload/image` загружает изображение в S3 (RustFS): ограничение 5 МБ, типы png/jpeg/webp/gif
- [ ] StorageService использует boto3 для S3-совместимого хранилища
- [ ] Все проксируемые запросы включают межсервисный токен
- [ ] Все эндпоинты защищены dependency `require_admin`
