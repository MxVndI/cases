# B-US-7.1: Сохранение и загрузка прогресса фермы

**Эпик:** [Epic B7: Ферма — бэкенд](../epics/epic-b07-farm.md)  
**Роль:** Пользователь

## User Story

Как пользователь, я хочу, чтобы прогресс фермы сохранялся на сервере.

## Описание

Серверное хранение состояния фермы (баланс, уровни улучшений) в MongoDB. Валидация данных для предотвращения читерства.
