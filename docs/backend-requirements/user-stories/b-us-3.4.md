# B-US-3.4: Последние открытия

**Эпик:** [Epic B3: Управление кейсами](../epics/epic-b03-cases.md)  
**Роль:** Гость

## User Story

Как гость, я хочу видеть последние открытия кейсов на платформе.

## Описание

Case Service хранит последние N открытий в Redis List для быстрого доступа. Публичный эндпоинт возвращает список с информацией: пользователь, предмет, кейс, дата.
