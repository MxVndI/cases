# B-US-3.3: Открытие кейса (игровая логика)

**Эпик:** [Epic B3: Управление кейсами](../epics/epic-b03-cases.md)  
**Роль:** Пользователь

## User Story

Как пользователь, я хочу открывать кейсы и получать случайные предметы.

## Описание

Case Service реализует алгоритм взвешенного случайного выбора предмета. Проверяет баланс, списывает стоимость, добавляет предмет в инвентарь и записывает в историю. Все операции атомарны.
