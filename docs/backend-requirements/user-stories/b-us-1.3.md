# B-US-1.3: Управление сессиями

**Эпик:** [Epic B1: Аутентификация и авторизация](../epics/epic-b01-auth.md)  
**Роль:** Система

## User Story

Как система, я должна управлять сессиями пользователей — создавать, хранить, кешировать и верифицировать.

## Описание

Сессии хранятся в MongoDB (Beanie Document) и кешируются в Redis для быстрого доступа. Session ID подписывается HMAC-SHA256 для безопасности cookie. TTL сессии — 30 дней.
