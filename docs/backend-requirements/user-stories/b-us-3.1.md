# B-US-3.1: CRUD кейсов

**Эпик:** [Epic B3: Управление кейсами](../epics/epic-b03-cases.md)  
**Роль:** Администратор

## User Story

Как администратор, я хочу создавать, редактировать и удалять кейсы через API.

## Описание

Case Service предоставляет REST API для полного управления кейсами. Публичный GET доступен всем, мутации защищены статическим `token` (передаётся в теле запроса, исключается из ответа). Управление кейсами осуществляется через Admin Service (BFF).
