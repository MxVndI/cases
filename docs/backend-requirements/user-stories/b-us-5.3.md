# B-US-5.3: Проверка прав администратора

**Эпик:** [Epic B5: Администрирование (API)](../epics/epic-b05-admin.md)  
**Роль:** Система

## User Story

Как система, я должна проверять права администратора перед выполнением защищённых операций.

## Описание

Middleware/dependency для всех admin-эндпоинтов. Проверяет role пользователя из сессии. Возвращает 403 для не-администраторов.
